## 4. Repeat-After-Me: Black-Box Adaptive Visual Prompt Injection  🆕

- **키워드**: visual prompt injection, black-box attack, PII leakage, agent security
- **출처**: arxiv recent
- **arxiv abstract**: [2609.04533](https://arxiv.org/abs/2609.04533) (v1)
- **PDF**: [arxiv.org/pdf/2609.04533](https://arxiv.org/pdf/2609.04533.pdf)
- **핵심 요약**: 상용 VLM에서 긴 도구 호출이나 개인정보 유출을 유도하는 시각적 프롬프트 주입은 기존 방식으로 어렵다. 저자들은 블랙박스 적응형 공격 Repeat-After-Me를 제안했다. 공개 모델에서는 공격 성공률이 80%를 넘었고, GPT-5.5에서는 47%를 넘었다. 실제 OpenClaw 배포에서도 도구 정의 파일 변조와 후속 민감 행동 가능성을 확인했다.

## 5. Necessary or Sufficient? Evaluating LLM Explanations With Behavioural Evidence  🆕

- **키워드**: explanation faithfulness, behavioral intervention, necessity, sufficiency
- **출처**: arxiv recent
- **arxiv abstract**: [2609.05385](https://arxiv.org/abs/2609.05385) (v1)
- **PDF**: [arxiv.org/pdf/2609.05385](https://arxiv.org/pdf/2609.05385.pdf)
- **핵심 요약**: 에이전트 감독에서 모델이 제시한 설명 요인이 실제 결정 행동과 일치하는지 평가한다. 통제된 블랙박스 개입으로 각 요인의 필요성과 충분성을 별도로 측정했다. 여덟 모델에서 설명 순위와 개입 점수의 상관은 과제별로 0.349에서 0.580 사이였다. 설명은 유용한 신호를 담지만, 가장 영향력 있는 세 요인을 안정적으로 식별하지 못했다.
