## 1. SecPO: Principled Adversarial Training for Prompt Injection Security  🆕

- **저자**: Sizhe Chen, Yibo Peng, Jaewon Chang, Chawin Sitawarin, David Wagner
- **키워드**: prompt injection, adversarial training, agent safety, preference optimization
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2610.41998](https://arxiv.org/abs/2610.41998) (v1)
- **PDF**: [arxiv.org/pdf/2610.41998](https://arxiv.org/pdf/2610.41998.pdf)
- **핵심 요약**: 기존 DPO 기반 방어가 취약한 참조 모델에 묶여 적응형 프롬프트 주입을 충분히 막지 못하는 문제를 다룬다. SecPO는 주입에 불변이면서 효용을 보존하는 이상적 참조 분포를 근사하고, 강한 best@240 공격을 생성하는 적대적 학습을 결합한다. 세 가지 적응형 공격에서 적대적 학습은 공격 성공률을 1.5–14.5배 낮췄고, SecPO 손실은 DPO 대비 추가로 2.4–4.6배 줄였다. AgentDojo의 AttackerMovesSecond에서 ASR@800은 78.8%에서 8.8%로 감소했으며, 9개 정상 효용 벤치마크에서는 뚜렷한 성능 저하가 없었다.

## 2. How Much Can Tool Calls Reveal About You? Privacy Leakage from Tool-Call Traces  🆕

- **저자**: Donghang Duan, Qingyu Liu, Yifei Liu, Na Zou, Xia Hu et al.
- **키워드**: tool-call privacy, MCP, profile inference, behavioral side channel
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2610.41885](https://arxiv.org/abs/2610.41885) (v1)
- **PDF**: [arxiv.org/pdf/2610.41885](https://arxiv.org/pdf/2610.41885.pdf)
- **핵심 요약**: 대화 내용이 없어도 MCP 도구 호출 기록만으로 사용자 속성을 추론할 수 있는지 평가한다. PrivacyTrace는 1,000개 합성 사용자 프로필과 25개 실제 MCP 서버에서 생성한 4,000개 에이전트 궤적을 제공한다. 네 개 LLM 공격자의 프로필 추론 성공률은 26.25%로, 사전분포 추측의 17.97%보다 높았다. 도구 인자와 반환 결과가 핵심 단서였고, 여러 세션의 기록 연결은 프로파일링 위험을 더 키웠다.

## 3. From Training Exposure to Membership Evidence: A Controlled Study of OLMo 2  🆕

- **저자**: Ali Banaei, Muhammad Shahab Shahzad, Gerald Q. Maguire Jr., Marco Chiesa, Dejan Kostić
- **키워드**: membership inference, training data leakage, counterfactual training, OLMo 2
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2610.41732](https://arxiv.org/abs/2610.41732) (v1)
- **PDF**: [arxiv.org/pdf/2610.41732](https://arxiv.org/pdf/2610.41732.pdf)
- **핵심 요약**: 사후 수집된 회원·비회원 데이터의 분포 차이가 멤버십 추론 성능을 왜곡하는 문제를 통제 실험으로 분석한다. 연구진은 OLMo 2 1B의 500억 토큰 중간 학습을 다시 실행하고, 7,814개 문서 쌍 중 하나를 동전 던지기로 삽입했다. 반사실적 참조를 사용한 비율 공격은 AUC 0.767이었지만, 1% FPR에서 개별 회원의 3.8%만 검출했다. 반면 같은 도메인의 문서 13쌍을 묶으면 5% 유의수준에서 학습 포함 여부를 80% 검정력으로 판별할 수 있어, 개별 추론과 집합 증거의 차이를 명확히 한다.

## 4. ANGLER: Verifier-Grounded Benchmarking with an Adaptive Attacker for Web Agents  🆕

- **저자**: Yini Huang, Aiwen LU, Zhen Sun, Yi Han, Yuzhi Zhao et al.
- **키워드**: web agents, adaptive red-teaming, prompt injection, agent safety
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2610.41272](https://arxiv.org/abs/2610.41272) (v1)
- **PDF**: [arxiv.org/pdf/2610.41272](https://arxiv.org/pdf/2610.41272.pdf)
- **핵심 요약**: 고정된 텍스트 공격만으로 웹 에이전트를 평가하면 실제 상태 변화와 적응형 공격의 위험을 놓치는 문제를 다룬다. REEF는 9개 실행형 웹사이트와 5개 공격 유형을 상태 기반 검증기로 평가하며, ANGLER는 이전 실행의 근접 실패를 이용해 공격을 변이한다. 8개 VLM 웹 에이전트에서 적응형 공격 성공률은 20.36%로, 비적응형 설정의 15.24%보다 높았다. 공격은 정상 작업 성공률도 61.9%에서 44.4%로 낮춰 보안과 효용을 함께 측정해야 함을 보여준다.

## 5. AgentShield: Fortifying Web Applications Against AI Agents and Agentic Browsers  🆕

- **저자**: Moiz Ali, Nafis Karim, Rownak Islam, Jyotirmay Chauhan, Dhruv Kuchhal et al.
- **키워드**: agentic browsers, behavioral fingerprinting, policy drift, web security
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2610.41181](https://arxiv.org/abs/2610.41181) (v1)
- **PDF**: [arxiv.org/pdf/2610.41181](https://arxiv.org/pdf/2610.41181.pdf)
- **핵심 요약**: 기존 안티봇 방어가 LLM 기반 브라우저 에이전트를 사람과 안정적으로 구분하지 못하는 문제를 실증적으로 조사한다. AgentShield는 동적 웹 폼과 세밀한 상호작용 원격측정을 이용해 에이전트의 지각–추론–행동 루프를 행동 지문으로 포착한다. 반복적인 작업 방해가 에이전트의 보호 규칙을 약화하는 Extinction-induced Policy Drift 공격도 제시한다. IEEE S&P 2027 게재 예정 연구로, 에이전트 전용 탐지와 방어적 프롬프트 주입의 실용 가능성을 보고한다.

- **출처**: arxiv recent
- **arxiv abstract**: [2610.41803](https://arxiv.org/abs/2610.41803) (v1)
- **PDF**: [arxiv.org/pdf/2610.41803](https://arxiv.org/pdf/2610.41803.pdf)
- **핵심 요약**: 에이전트 탈취 탐지기의 높은 AUROC가 희귀 공격, 미관측 도구, 다른 벤치마크에서도 유효한지 검증한다. AgentDrift와 AgentDojo에서 도구·행동·시퀀스·임베딩 기반 탐지기와 공개 LLM 모니터를 고정 임계값으로 비교했다. 공격 비율 2%에서 AUROC 0.879인 탐지기의 정밀도는 0.076에 그쳤다. AgentDrift 학습 탐지기는 AgentDojo에서 AUROC 0.47–0.52였으며, 단일 벤치마크 점수가 배치 환경의 경보 품질을 보장하지 않음을 보여준다.

## 10. When Safety Checks Become Privacy Risks: A Privacy-Preserving Paradigm for LLM Agent Safety Auditing  🆕

- **저자**: Yixiang Luo, Ziheng Ma, Ke Chang, Jian Wang, Jiqiang Liu
- **키워드**: privacy-preserving auditing, encrypted inference, tool-call safety, LLM agents
- **출처**: arxiv recent
- **arxiv abstract**: [2610.41401](https://arxiv.org/abs/2610.41401) (v1)
- **PDF**: [arxiv.org/pdf/2610.41401](https://arxiv.org/pdf/2610.41401.pdf)
- **핵심 요약**: 외부 감사자가 에이전트 도구 호출을 검사하는 과정에서 작업 설명과 사용자 데이터가 노출되는 문제를 다룬다. SealCall은 신뢰된 표현 생성, CKKS 암호화 유사도 계산, 감사 결과에 결합된 실행 제어를 분리한다. 1,252개 공개 이진 후보에서 평균 F1 0.840을 기록했고, 측정된 모든 사례에서 평문 감사 결정을 보존했다. 대표 설정의 암호화 점수 계산은 호출당 0.176초가 걸려, 반정직 감사자에 대한 개인정보 보호와 실용 지연의 절충을 제시한다.
