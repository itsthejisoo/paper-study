## 1. SlotGCG: Exploiting the Positional Vulnerability in LLMs for Jailbreak Attacks 🆕

- **저자**: Seungwon Jeong, Jiwoo Jeong, Hyeonjin Kim, Yunseok Lee, Woojin Lee (Dongguk University-Seoul)
- **키워드**: `jailbreak`, `adversarial attack`, `GCG`, `positional vulnerability`, `AI security`
- **출처**: ICLR 2026 (Conference Accept)
- **arxiv abstract**: [2606.05609](https://arxiv.org/abs/2606.05609) (v1)
- **PDF**: [arxiv.org/pdf/2606.05609](https://arxiv.org/pdf/2606.05609.pdf)

**핵심 요약** (3-5문장 한국어):
GCG 등 기존 gradient 기반 jailbreak는 adversarial 토큰을 프롬프트 끝(suffix)에만 삽입했지만, 어느 위치에 삽입하느냐에 따라 취약성이 크게 달라진다는 점은 미탐구 영역이었다. 본 논문은 프롬프트 내 삽입 가능한 위치(slot)별 취약도를 정량화하는 Vulnerable Slot Score(VSS)를 제안하고, VSS가 높은 슬롯을 우선 선택해 공격을 집중시키는 SlotGCG를 소개한다. 실험 결과 SlotGCG는 기존 GCG 대비 ASR(Attack Success Rate) 14% 향상, 수렴 속도 개선, 방어 우회 성능 42% 향상을 달성했다. ICLR 2026 Accept 논문으로, jailbreak 연구의 위치 편향(positional bias) 문제를 처음 체계적으로 다룬 연구다.

## 2. Confused ChatGPT: Cross-App Context Poisoning via First-Party APIs 🆕

- **저자**: Chao Wang, Somesh Jha, Zhiqiang Lin
- **키워드**: `prompt injection`, `context poisoning`, `LLM agent security`, `ChatGPT Apps`, `confused deputy`
- **출처**: arxiv recent (cs.CR Jun 2026)
- **arxiv abstract**: [2606.00485](https://arxiv.org/abs/2606.00485) (v1)
- **PDF**: [arxiv.org/pdf/2606.00485](https://arxiv.org/pdf/2606.00485.pdf)

**핵심 요약** (3-5문장 한국어):
2025년 10월 OpenAI가 출시한 ChatGPT Apps는 여러 third-party 앱이 하나의 채팅 컨텍스트를 공유하는 app-in-app 구조다. 본 논문은 이 구조에서 악성 앱이 공유 컨텍스트에 독성 정보를 주입하면, 사용자가 나중에 호출하는 다른 무관한 앱이 피해를 입는 "cross-app context poisoning" 취약점을 처음 발견·정의했다. 이 공격은 first-party API를 전달 경로로 쓰는 confused-deputy 공격으로, 2025년 12월 122개에서 2026년 5월 888개로 폭증한 생태계 전체에 영향을 미친다. 새 패러다임의 보안 위협을 이른 시기에 공개했다는 점에서 실무 파급력이 크다.

## 3. AgentRedBench: Dynamic Redteaming and Integration-Aware Defense for LLM Agents over SaaS Integrations 🆕

- **저자**: Hiskias Dingeto, William Leeney
- **키워드**: `red-teaming`, `prompt injection`, `agent security`, `SaaS integration`, `AGENTREDGUARD`
- **출처**: SNS (X/Reddit 화제), arxiv recent (cs.CR Jun 2026)
- **arxiv abstract**: [2606.02240](https://arxiv.org/abs/2606.02240) (v2)
- **PDF**: [arxiv.org/pdf/2606.02240](https://arxiv.org/pdf/2606.02240.pdf)

**핵심 요약** (3-5문장 한국어):
Gmail, Salesforce, Jira 등 24개 기업용 SaaS 통합 환경에서 LLM 에이전트를 대상으로 한 간접 프롬프트 인젝션 공격을 체계화한 벤치마크다. 215개 시나리오에 걸쳐 Anthropic, OpenAI, Google 포함 8개 모델을 평가한 결과, 방어 없는 ASR(공격 성공률)이 Claude Sonnet 4.6(32%)~Gemini 3 Flash(81%)에 달했다. 아울러 통합 다양성 기반으로 훈련된 가드 모델 AGENTREDGUARD를 함께 공개했으며, 이는 panel ASR을 69.9%→2.4%로 낮추고 FPR 0.37%를 달성해 Llama Guard 등 모든 오픈소스 베이스라인을 능가했다. 실 배포 환경의 agent 보안 위협을 가장 포괄적으로 측정한 벤치마크다.

## 4. "I Strongly Suspect This Website Is a Scam": Benchmarking PII Leakage and Detection without Defense in Autonomous Web Agents 🆕

- **저자**: Soham Roy, Sarthakbrata Halder, Arya Bharaty, Vaibhav Bhaskar, Yash Sinha, Dhruv Kumar, Srikant Panda, Murari Mandal
- **키워드**: `PII leakage`, `web agent`, `social engineering`, `privacy benchmark`, `autonomous agents`
- **출처**: arxiv recent (cs.CR Jun 2026)
- **arxiv abstract**: [2606.00497](https://arxiv.org/abs/2606.00497) (v1)
- **PDF**: [arxiv.org/pdf/2606.00497](https://arxiv.org/pdf/2606.00497.pdf)

**핵심 요약** (3-5문장 한국어):
자율 웹 에이전트가 소셜 엔지니어링 기반 사기 사이트에 접속할 경우 개인식별정보(PII)가 어느 정도 유출되는지 최초로 체계적으로 벤치마킹한 연구다. 8개 공격 벡터·16개 사이트 카테고리를 포함한 91개 시나리오(Scammer4U)를 구성하고, 사전 등록 방식으로 실험을 진행했다. 방어 지침 없는 상태에서 frontier 에이전트의 critical-tier PII 유출률이 54~93%에 달했으며, benign 트윈 사이트에서는 0%여서 유출이 공격에 직접 기인함을 확인했다. 에이전트 보급 시대의 개인정보 위협 크기를 수치로 입증한 중요한 벤치마크다.

## 5. Defenses & Enablers For Skill Injection Attacks on Terminal Based Agents 🆕

- **저자**: Yoshinari Fujinuma, Varun Gangal, Traian Rebedea, Makesh Narasimhan Sreedhar, Prasoon Varshney, Rebecca Qian, Anand Kannappan (Patronus AI · NVIDIA)
- **키워드**: `skill injection`, `agent security`, `prompt injection`, `guardian LLM`, `terminal agents`
- **출처**: arxiv recent (cs.CR Jun 2026)
- **arxiv abstract**: [2606.01567](https://arxiv.org/abs/2606.01567) (v1)
- **PDF**: [arxiv.org/pdf/2606.01567](https://arxiv.org/pdf/2606.01567.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 에이전트가 재사용 가능한 스킬 파일(task 절차를 기술한 문서)에 의존할 때 발생하는 skill injection 공격 — 스킬 파일에 악의적 명령을 삽입하는 공격 — 에 대한 방어 전략을 분석했다. 동적 가디언(에이전트가 스킬 파일에 접근할 때 중간 LLM이 검사)과 정적 가디언(빌드 시점에 스킬 파일을 사전 정제)으로 구성된 guardian-based 방어를 평가한 결과, 3종 에이전트 패밀리 모두에서 ASR이 절반 이상 감소하면서 유틸리티가 유지됐다. Patronus AI와 NVIDIA 연구진이 참여한 실용 중심 연구로, 현재 production 환경에서 사용되는 terminal 에이전트의 취약점을 직접적으로 다룬다.

## 6. PrivacyPeek: Auditing What LLM-Based Agents Acquire, Not Just What They Say 🆕

- **키워드**: `agent privacy`, `privacy audit`, `LLM agent`, `information acquisition`, `PII`
- **출처**: arxiv recent (cs.CR Jun 2026)
- **arxiv abstract**: [2606.00152](https://arxiv.org/abs/2606.00152) (v1)
- **PDF**: [arxiv.org/pdf/2606.00152](https://arxiv.org/pdf/2606.00152.pdf)

**핵심 요약** (3-5문장 한국어):
기존 LLM 에이전트 프라이버시 연구는 에이전트가 외부로 "출력"하는 정보에 집중했지만, 에이전트가 도구 호출과 컨텍스트 탐색 과정에서 몰래 "수집"하는 정보는 무시돼왔다. PrivacyPeek은 에이전트가 실제로 획득하는 데이터 — 호출한 API 응답, 인덱싱한 문서, 메모리에 저장한 내용 등 — 를 감사(audit)하는 새 프레임워크를 제안한다. 에이전트의 출력이 무해해 보여도 내부적으로는 과도한 개인정보를 수집할 수 있음을 실증하며, 에이전트 설계 시 정보 최소화 원칙의 필요성을 강조한다.

> 🔄 2026-08-10: v1 → v2 로 갱신됨. 변경점: 초록의 연구 내용은 유지됐지만 원고가 19쪽·그림 9개에서 21쪽·그림 17개로 확장됐다.

ICLR 2026 Agents in the Wild 워크숍 채택 논문으로, safety 평가의 커버리지 문제를 처음으로 진화 알고리즘 관점에서 접근한다.

## 9. The Invitation Trap: Proactive Availability Backdoor in LLMs via Conversational Induction 🆕

- **저자**: He Wang, Jun Feng, Hong Sun, Pengfei Zhang
- **키워드**: `backdoor`, `availability attack`, `LLM security`, `conversational induction`, `proactive backdoor`
- **출처**: arxiv recent (cs.CR Jun 2026)
- **arxiv abstract**: [2606.00654](https://arxiv.org/abs/2606.00654) (v1)
- **PDF**: [arxiv.org/pdf/2606.00654](https://arxiv.org/pdf/2606.00654.pdf)

**핵심 요약** (3-5문장 한국어):
기존 LLM backdoor는 독성 콘텐츠 생성을 유도하는 데 초점을 뒀지만, 본 논문은 LLM의 가용성(availability) 자체를 표적으로 삼는 새로운 유형의 backdoor를 제안한다. 공격자는 대화 유도(conversational induction)를 통해 LLM 내에 특정 트리거 패턴을 잠복시키고, 나중에 트리거가 발동되면 모델이 서비스 응답을 거부하거나 비정상 종료하도록 만든다. 기존 가용성 공격과 달리 "초대(invitation)" 메커니즘을 통해 공격자가 사전에 모델에 백도어를 삽입한다는 점에서 새로운 위협 모델을 제시한다.

## 10. Persona Attack: Incremental Memory Injection Jailbreak Attack against Large Language Models 🆕

- **저자**: Junyoung Park, Seongyong Ju, Sunghwan Park, Jaewoo Lee
- **키워드**: `jailbreak`, `memory injection`, `persona`, `incremental attack`, `AI security`
- **출처**: arxiv recent (cs.CR Jun 2026)
- **arxiv abstract**: [2606.00150](https://arxiv.org/abs/2606.00150) (v1)
- **PDF**: [arxiv.org/pdf/2606.00150](https://arxiv.org/pdf/2606.00150.pdf)

**핵심 요약** (3-5문장 한국어):
LLM에게 특정 페르소나를 점진적으로 주입해 안전 정렬(safety alignment)을 우회하는 jailbreak 기법을 제안한다. 단일 프롬프트로 직접 탈옥을 시도하는 대신, 여러 대화 턴에 걸쳐 대화 기억(memory)에 점진적으로 페르소나 관련 맥락을 누적시켜 모델이 제한 없이 응답하도록 유도한다. 이 "점진적 기억 주입" 방식은 일회성 공격에 강한 방어 체계도 우회할 수 있음을 실험으로 보여, 다중 턴 보안 평가의 중요성을 부각시킨다.
