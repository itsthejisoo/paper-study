## 1. The More It Says, the More You Pay: A Black-Box Audit of Provider-Side Token Inflation in LLM Services  🆕
- **저자**: Leilei Chen, Lan Zhang, Chen Tang, Pengcheng Sun, Jiewei Lai et al.
- **키워드**: provider-side token inflation, black-box audit, LLM API security
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.20370](https://arxiv.org/abs/2609.20370) (v1)
- **PDF**: [arxiv.org/pdf/2609.20370](https://arxiv.org/pdf/2609.20370.pdf)
- **핵심 요약**: 토큰 기반 LLM 서비스에서는 제공자가 출력 품질을 유지하면서 청구 토큰을 부풀릴 경제적 유인이 생길 수 있다. 연구는 질의, 프롬프트, 표현, 모델 수준의 다섯 가지 공격을 정의하고, 응답만으로 이를 감사하는 블랙박스 탐지기를 제안한다. 공격은 실험에서 출력 토큰을 10.2배 이상 늘렸고, 탐지기는 85.1% 탐지율과 2% 미만의 오탐률을 기록했다. 15개 상용 API를 감사해 7개 서비스에서 의심 신호를 보고하며, 가격 투명성과 독립 검증의 필요성을 제기한다.

## 2. ResumeShield: Channel Separation and an Open Benchmark for Indirect Prompt Injection in AI Resume Screening  🆕

- **출처**: arxiv recent / SNS

- **핵심 요약**: 이력서 심사 에이전트는 지원자가 문서에 숨긴 지시를 시스템 명령으로 오인할 수 있다. ResumeShield는 문서 내용을 비신뢰 데이터 채널로 분리하고, 104개 문서로 간접 프롬프트 주입 방어를 평가한다. 무방비 파이프라인은 모든 주입 사례에서 조작됐지만, 채널 분리 방어는 공격 성공을 막으면서 정밀도 1.0과 재현율 0.944를 기록했다. 단순 필터만 적용하면 공격의 16.7%가 남아, 입력 검열보다 권한과 채널 경계가 중요함을 보인다.

## 3. Silence Is Endorsement: Verification-Status Laundering in LLM Agent Pipelines  🆕
- **저자**: Yibo Hu
- **키워드**: verification-status laundering, agent pipeline, provenance
- **출처**: arxiv recent
- **arxiv abstract**: [2609.20211](https://arxiv.org/abs/2609.20211) (v1)
- **PDF**: [arxiv.org/pdf/2609.20211](https://arxiv.org/pdf/2609.20211.pdf)
- **핵심 요약**: 다단계 에이전트 파이프라인에서는 사실 내용이 유지돼도 검증되지 않았다는 상태가 요약 과정에서 사라질 수 있다. 연구는 이 검증 상태 세탁을 분리 측정하고, 후속 의사결정이 어떻게 위험한 승인을 내리는지 분석한다. 출처의 미검증 표시를 제거하면 위험 승인률이 Llama 3.1 8B에서 5%에서 60%로, Qwen 2.5 14B에서 9%에서 98%로 상승했다. 전체 파이프라인에서도 57%에서 81%의 실패율이 나타나, provenance를 자유 텍스트가 아닌 구조화된 상태로 전달해야 함을 보여준다.

## 10. PACT: Can Enterprise AI Assistants Be Trusted Under Pressure?  🆕
- **저자**: Mika Okamoto, Ansel Kaplan Erol
- **키워드**: enterprise agent safety, compliance benchmark, pressure testing
- **출처**: arxiv recent
- **arxiv abstract**: [2609.18605](https://arxiv.org/abs/2609.18605) (v1)
- **PDF**: [arxiv.org/pdf/2609.18605](https://arxiv.org/pdf/2609.18605.pdf)
- **핵심 요약**: 기업용 AI 에이전트는 사용자나 관리자의 압박 아래에서도 규정과 시스템 지시를 따라야 한다. PACT는 12개 규제 산업의 48개 다중 턴 시나리오에서 규칙 위반 지름길과 여러 압박 표현을 대조한다. 22개 모델을 여섯 가지 지표로 평가한 결과, 가장 강한 모델도 6%에서 10%의 항목에서 규칙 적용을 잘못했다. 일반적인 사용자 압박은 평균 위반율을 65% 높여, 배포 전 압박 기반 준수 평가와 별도 가드레일이 필요함을 보여준다.
