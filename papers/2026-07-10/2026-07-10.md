## 1. Overthink-Triggered Slowdown Attacks on LVLM-Based Robotic Systems

- **arXiv**: [2607.01518](https://arxiv.org/abs/2607.01518) | [PDF](https://arxiv.org/pdf/2607.01518)
- **저자**: Qiang Han, Jie Wu, Bo Chen
- **제출일**: 2026-07-01 | cs.CR, cs.RO
- **카테고리**: AI Security / Adversarial Attack

**요약**  
로봇 시스템에 탑재된 LVLM(Large Vision-Language Model)을 대상으로, 공격자가 물리 환경에 사람이 읽을 수 있는 텍스트를 삽입해 모델의 추론을 과도하게 유발(overthinking)하고 실시간 응답 지연을 발생시키는 공격을 제안한다. 이미지 분류나 프롬프트 변조 없이 시각적 장면 텍스트만으로 안전-크리티컬한 지연을 유발할 수 있음을 보여준다. 블랙박스 설정에서 동작하는 세 단계 트리거 식별 프레임워크를 제시하며, 여러 LVLM에 걸쳐 전이성을 검증했다 (17 pages, 10 figures).

## 2. Embedding Inference Attack

- **제출일**: 2026-07-01 | cs.CR, cs.IR, cs.LG
- **카테고리**: AI Privacy / Inference Attack

**요약**  
RAG/IR 시스템에서 공격자가 검색 결과(문서 집합, 순위·유사도 점수 없음)만 관찰 가능한 완전 블랙박스 설정에서도, 정교하게 설계된 질의(tailored queries)를 통해 시스템이 사용 중인 임베딩 모델을 후보 집합으로부터 식별할 수 있음을 보인다. reranker가 존재해도 판별력 있는 질의가 유효하며, LLM이 비정상 입력을 거부하는 경향도 우회된다. 실제 RAG 시스템에서 검증하고 유사도 임계값 등 완화 전략도 평가한다 (12 pages).

## 3. Has This Checkpoint Been Abliterated? A Two-Signal Audit and Its Failure Map

- **arXiv**: [2607.01854](https://arxiv.org/abs/2607.01854) | [PDF](https://arxiv.org/pdf/2607.01854)
- **저자**: Gabriel Hurtado
- **제출일**: 2026-07-01 | cs.CR, cs.AI
- **카테고리**: AI Security / Safety Interpretability

**요약**  
오픈 웨이트 LLM 체크포인트에서 거부(refusal) 메커니즘이 제거됐는지를 배포 전에 자동 탐지하는 감사 방법론을 제안한다. 두 신호—레퍼런스 대비 활성화 거부-갭(activation refusal-gap)과 베이스 모델 대비 가중치 복원 에너지(weight-recovery energy)—를 결합한 z-sum을 임계값 없이 사용한다. Qwen, DeepSeek-distilled, Llama, Gemma 등 273개 체크포인트 레지스트리에서 57개의 공개 어블리터레이션 vs. 37개의 정상 파인튜닝/병합/인스트럭션 튜닝을 AUROC 0.95로 분리하며, 단일 신호(0.84, 0.90) 대비 유의미한 향상을 보인다 (13 pages, 3 figures).

## 4. The Truth Stays in the Family: Enhancing Contextual Grounding via Inherited Truthful Heads in Model Lineages

- **arXiv**: [2606.15821](https://arxiv.org/abs/2606.15821) | [PDF](https://arxiv.org/pdf/2606.15821)
- **저자**: (ICML 2026)
- **제출일**: 2026-06 | cs.CL, cs.LG
- **카테고리**: LLM Interpretability

**요약**  
LLM 패밀리(베이스 → 인스트럭션 튜닝 → 멀티모달 변형) 전반에 걸쳐 컨텍스트 진실성(context-truthfulness) 점수가 높은 어텐션 헤드가 일관되게 보존된다는 사실을 발견한다. 이 "진실 헤드(truthful heads)"는 단순 파인튜닝에도 살아남으며, 이를 활용한 TruthProbe 소프트 게이팅을 제안해 컨텍스트 기반 답변 충실도를 향상시킨다. 회로 분석 관점에서 모델 계보 내 해석 가능 구조의 계승을 다루는 ICML 2026 논문이다.

## 5. SecureForge: Finding and Preventing Vulnerabilities in LLM-Generated Code via Prompt Optimization

- **arXiv**: [2605.08382](https://arxiv.org/abs/2605.08382) | [PDF](https://arxiv.org/pdf/2605.08382)
- **저자**: Stanford (Christopher Manning, Mykel Kochenderfer, Diyi Yang, Lisa Einstein et al.)
- **제출일**: 2026-05 | cs.CR, cs.CL
- **카테고리**: AI Security / Code Security

**요약**  
LLM 코딩 에이전트가 생성한 코드의 23%에서 보안 취약점이 발생한다는 문제를 다룬다. SecureForge는 시스템 프롬프트를 자동으로 감사·최적화하는 프레임워크로, Pareto 개선을 달성하며 보안 취약점을 최대 48%까지 감소시키면서 유닛 테스트 통과율은 유지한다. 스탠퍼드 소속 저자들이 작성했으며 SNS에서 높은 주목을 받은 논문이다.

## 9. AgentRaft: Automated Detection of Data Over-Exposure in LLM Agents

- **arXiv**: [2603.07557](https://arxiv.org/abs/2603.07557) | [PDF](https://arxiv.org/pdf/2603.07557)
- **저자**: Yixi Lin, Jiangrong Wu, Yuhong Nan (Sun Yat-sen Univ.), Xueqiang Wang (UCF), Xinyuan Zhang, Zibin Zheng
- **제출일**: 2026-03-08 | cs.CR, cs.AI
- **카테고리**: AI Privacy / Agent Security

**요약**  
LLM 에이전트가 사용자 의도와 기능 필요 범위를 초과해 민감 데이터를 전송하는 "데이터 과노출(DOE)" 위험을 최초로 체계화하고, 이를 자동 탐지하는 AgentRaft 프레임워크를 제안한다. 교차-툴 함수 호출 그래프 구축 → 고품질 테스트 프롬프트 합성 → 다중 LLM 투표 기반 런타임 오염 추적(taint tracking)의 세 모듈을 결합한다. 도구 상호작용 경로의 57.07%에서 DOE 발견; 150개 프롬프트 내에서 ~99% 커버리지 달성; 베이스라인 대비 탐지 정확도 87.24% 향상.

- **카테고리**: AI/Web Privacy (ACM CCS 2026)
