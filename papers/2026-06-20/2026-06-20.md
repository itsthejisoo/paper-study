## 1. NRT-Bench: Benchmarking Multi-Turn Red-Teaming of LLM Operator Agents in Safety-Critical Control Rooms 🆕

- **저자**: Hanwool Lee, Dasol Choi, Bokyeong Kim, Seung Geun Kim, Haon Park
- **키워드**: `red-teaming`, `LLM agent safety`, `jailbreak`, `adversarial robustness`, `multi-turn attack`, `safety-critical systems`
- **출처**: SNS/web search
- **arxiv abstract**: [2606.20408](https://arxiv.org/abs/2606.20408) (v1)
- **PDF**: [arxiv.org/pdf/2606.20408](https://arxiv.org/pdf/2606.20408.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 에이전트를 원자력 발전소 제어실 오퍼레이터로 배치할 때의 안전성을 적대적 멀티턴 공격 하에서 평가한 벤치마크 NRT-Bench를 제안한다. 5역할 오퍼레이터 팀(각각 서로 다른 LLM이 뒷받침)이 6개의 핵심 안전 기능(CSF)을 관리하는 플랜트를 운영하며, 4개 채널에 걸쳐 멀티턴 세션 동안 적대자가 메시지를 주입한다. 안전 판단을 LLM-judge가 아닌 objective signal(CSF 손실 여부)로 측정한다는 점에서 기존 벤치마크와 차별화된다. 4개의 최신 프론티어 모델을 평가한 결과 적응형 멀티턴 공격이 8.7~12.1%의 세션에서 최소 하나의 CSF를 손실시키는 데 성공하며, 모델별 취약점이 대부분 비중복적(disjoint)임을 확인했다.

## 2. PrivCode++: Latent-Conditioned Differentially Private Code Generation for Comprehensive Guarantees 🆕

- **저자**: Zheng Liu, Chen Gong, Terry Yue Zhuo, Zhou Yang, Kecen Li, Wenlong Meng, Xinwen Hou, Yu Liu, Xiaochen Li
- **키워드**: `differential privacy`, `code generation`, `training data leakage`, `LLM fine-tuning`, `PII`
- **출처**: arxiv cs.CR
- **arxiv abstract**: [2606.09145](https://arxiv.org/abs/2606.09145) (v1)
- **PDF**: [arxiv.org/pdf/2606.09145](https://arxiv.org/pdf/2606.09145.pdf)

**핵심 요약** (3-5문장 한국어):
LLM을 instruction-code 쌍으로 파인튜닝할 때 민감한 훈련 데이터가 memorization되어 유출될 수 있다. 기존 DP 코드 생성 방법은 코드 스니펫만 보호하고 프롬프트는 공개라고 가정하지만, 실제로는 프롬프트도 민감 정보를 포함할 수 있다. PrivCode++는 프롬프트와 코드 스니펫 모두를 민감 데이터로 취급하는 최초의 DP 코드 생성 프레임워크로, Privacy-Free Latent Conditioning 모듈을 통해 민감 데이터에 직접 접근 없이 효과적인 DP 파인튜닝과 데이터 합성을 지원한다. ICML 2026에 채택된 논문으로, 기존 DP 기준선보다 현저히 높은 유틸리티와 더 강한 프라이버시 보장을 동시에 달성한다.

- **출처**: arxiv cs.LG
- **arxiv abstract**: [2606.07978](https://arxiv.org/abs/2606.07978) (v1)

**핵심 요약** (3-5문장 한국어):
LLM의 사실적 지식이 레이어에 걸쳐 점진적으로 나타나는 것이 아니라 마지막 레이어(80% 이상 깊이)에서 갑자기 "결정화(crystallize)"됨을 발견한다. ## 7. Perplexity Can Miss SAE Feature Damage Under Quantization 🆕

- **저자**: Evan Duan (University of Michigan)
- **키워드**: `sparse autoencoder`, `quantization`, `mechanistic interpretability`, `feature damage`, `Gemma`, `LLM`
- **출처**: arxiv cs.LG
- **arxiv abstract**: [2606.03002](https://arxiv.org/abs/2606.03002) (v1)
- **PDF**: [arxiv.org/pdf/2606.03002](https://arxiv.org/pdf/2606.03002.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 양자화(quantization) 적합성을 perplexity나 다운스트림 정확도만으로 판단하는 관행에 의문을 제기한다. Gemma-2-2B에서 INT7 양자화는 perplexity를 개선하면서도 활성화된 SAE feature의 18.7%를 손상시키며, INT6에서는 sliding-window 평가 기준으로 오직 51.3%의 feature만 생존한다. 즉 "동작 동등성(behavioral parity)"이 "feature 충실도(feature fidelity)"를 보장하지 않으며, SAE 기반 해석 결과가 양자화 모델에서는 달라질 수 있음을 경고한다. 양자화된 모델에 원본 SAE를 그대로 적용하는 해석 가능성 연구에 중요한 시사점을 제공한다.

**핵심 요약** (3-5문장 한국어):

Qwen3-14B를 LogiQA 2.0, ARC-Challenge, αNLI 3개 벤치마크에서 평가한 결과 레이어 32/40에서 선형 프로브가 교차 검증 정확도 100%를 달성하지만, 이 분리가 포맷 교란 변수(소스 정체성, 선택지 수, 응답 길이)에 의해 전적으로 설명됨을 보인다. 교란 변수를 통제하면 정확도가 우연 수준으로 떨어지며, trace-anchor 유사도와 인과적 조향(causal steering) 분석도 기하학적 분리와 추론 모드 간의 기능적 연결이 없음을 확인한다. 프로브 기반 해석 가능성 연구에서 포맷 교란 변수 통제가 필수적임을 경고한다.

## 10. Brain-Prompt Injection: A Route-Safety Audit for BCI–LLM Agents 🆕

- **저자**: Jianwei Tai
- **키워드**: `prompt injection`, `brain-computer interface`, `BCI`, `agent safety`, `adversarial attacks`, `LLM security`
- **출처**: arxiv cs.CR
- **arxiv abstract**: [2606.09315](https://arxiv.org/abs/2606.09315) (v1)
- **PDF**: [arxiv.org/pdf/2606.09315](https://arxiv.org/pdf/2606.09315.pdf)

**핵심 요약** (3-5문장 한국어):
뇌-컴퓨터 인터페이스(BCI)와 LLM 에이전트를 연결하는 파이프라인에서 새로운 공격 표면인 "brain-prompt injection"을 발견한다. 신호 측 교란(signal-side perturbations), 컨텍스트 전용 주입, 적응형 dual-decoder 공격을 통해 EEG 측 또는 텍스트 측 모니터가 탐지하지 못하는 상태에서 에이전트의 라우팅 액션을 변경할 수 있다. Route-Safety Audit Contract를 정의해 최소 감사 로그 스키마, 분모 계층, 엔드포인트 명세를 제시하며, 감사 로그 분리 정리와 C3 공격 의존 분해를 통해 라우팅 안전성 감사의 이론적 토대를 마련한다.
