## 1. LASH: Adaptive Semantic Hybridization for Black-Box Jailbreaking of Large Language Models  🆕

- **저자**: (저자 정보 arxiv 직접 확인 필요)
- **키워드**: `jailbreak`, `black-box`, `adaptive attack`, `semantic hybridization`, `genetic optimizer`
- **출처**: SNS (X.com 언급)
- **arxiv abstract**: [2605.21362](https://arxiv.org/abs/2605.21362) (v1)
- **PDF**: [arxiv.org/pdf/2605.21362](https://arxiv.org/pdf/2605.21362.pdf)

**핵심 요약** (3-5문장 한국어):
기존 자동화 jailbreak 방법들은 단일 공격 계열에 고착되어 있어, 타겟 모델·해악 범주별로 최적 방법이 달라지는 문제가 있다. LASH는 여러 기반 공격의 출력물을 재사용 가능한 시드 프롬프트 풀로 다루고, 소프트맥스 정규화된 혼합 가중치로 이들을 적응적으로 조합하는 블랙박스 프레임워크다. 조합 모듈이 후보 프롬프트를 합성하고, 도함수가 없는 유전자 최적화기(derivative-free genetic optimizer)가 블랙박스 타겟 피드백으로 혼합 가중치를 업데이트한다. 각 해악 요청마다 최적 공격 구성을 찾아내는 방식으로, 어떤 단일 공격도 지배하지 못하는 상호보완적 강점을 활용한다.

**핵심 요약** (3-5문장 한국어):

## 3. A Systematic Survey of Security Threats and Defenses in LLM-Based AI Agents: A Layered Attack Surface Framework  🔄 Updated v1→v2

- **저자**: Kexin Chu
- **키워드**: `agent security`, `attack surface`, `survey`, `layered model`, `temporality`
- **출처**: SNS / arxiv recent
- **arxiv abstract**: [2604.23338](https://arxiv.org/abs/2604.23338) (v2)
- **PDF**: [arxiv.org/pdf/2604.23338](https://arxiv.org/pdf/2604.23338.pdf)

**핵심 요약** (3-5문장 한국어):
상태 비보존(stateless) LLM과 달리, 에이전트 시스템은 메모리를 유지하고 외부 도구를 호출하며 세션을 넘나들어 동작하므로 기존과 다른 보안 표면이 생긴다. 이 논문은 에이전트 스택을 Foundation, Cognitive, Memory, Tool Execution, Multi-Agent Coordination, Ecosystem, Governance의 7개 계층으로 분해하고, 즉각적·세션 지속·세션 간 누적·하위 세션 스택의 4가지 시간적 위협 클래스를 결합한 계층화 공격 표면 모델(LASM)을 제안한다. 에이전트 공격의 세 가지 핵심 특성으로 창발성(권한 있는 행동의 합성), 합성성(다른 계층을 우회한 공격 라우팅), 시간 확장성(수 주 전 페이로드 설치 후 실행)을 규명한다.

**v1 → v2 변경점**: v2(May 6)에서 LASM 분류 체계 정교화 및 최신 방어 기법 리뷰 추가.

## 6. Semia: Auditing Agent Skills via Constraint-Guided Representation Synthesis  🆕

- **저자**: Hongbo Wen, Ying Li, Hanzhi Liu, Chaofan Shou, Yanju Chen, Yuan Tian, Yu Feng
- **키워드**: `agent auditing`, `representation synthesis`, `constraint-guided`, `security risk`, `Datalog`
- **출처**: arxiv recent
- **arxiv abstract**: [2605.00314](https://arxiv.org/abs/2605.00314) (v1)
- **PDF**: [arxiv.org/pdf/2605.00314](https://arxiv.org/pdf/2605.00314.pdf)

**핵심 요약** (3-5문장 한국어):
Semia는 에이전트 스킬(skill)의 보안 위험을 자동으로 감사하는 정적 분석 도구로, 각 스킬을 LLM 트리거 액션·산문 조건·인간 개입 체크포인트를 캡처하는 Datalog 사실 기반인 Skill Description Language(SDL)로 변환한다. 핵심 기술은 제약 조건 유도 표현 합성(CGRS): LLM에게 구조화 표현을 일회 생성시키는 대신, 제약 탐색으로 처리해 LLM 후보를 수렴할 때까지 정제하는 제안-검증-평가 루프를 사용한다. 공개 마켓플레이스의 실제 스킬 13,728개에 적용한 결과, 절반 이상에서 최소 하나의 치명적 시맨틱 위험이 발견됐으며, 전문가 레이블링 541개 샘플에서 97.7% recall, F1 90.6%를 달성했다.
