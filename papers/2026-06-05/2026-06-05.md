## 1. AgentVigil: Generic Black-Box Red-teaming for Indirect Prompt Injection against LLM Agents 🆕

- **저자**: Shenglong Yao, Guibin Zhang, Yanran Fu et al.
- **키워드**: `indirect prompt injection`, `LLM agents`, `red-teaming`, `black-box`, `MCTS`
- **출처**: HF Daily
- **arxiv abstract**: [2505.05849](https://arxiv.org/abs/2505.05849) (v4)
- **PDF**: [arxiv.org/pdf/2505.05849](https://arxiv.org/pdf/2505.05849.pdf)

**핵심 요약** (3-5문장):
LLM 기반 에이전트가 도구 사용 능력을 갖추면서 외부 데이터 소스에 삽입된 악의적 명령을 통한 간접 프롬프트 인젝션이 핵심 보안 위협으로 부상했다. 이 논문은 블랙박스 환경에서 다양한 LLM 에이전트를 대상으로 간접 프롬프트 인젝션 취약점을 자동 탐지하는 퍼징 프레임워크 AgentVigil을 제안한다. MCTS 기반 시드 선택 알고리즘으로 공격 입력을 반복 정제하며, AgentDojo와 VWA-adv 벤치마크에서 o3-mini·GPT-4o 기반 에이전트 대상 각각 71%, 70% 공격 성공률로 기존 공격 대비 약 2배 성능 향상을 달성했다. EMNLP 2025에 채택된 이 연구는 현재 LLM 에이전트 보안의 구조적 취약성을 실증적으로 입증하며, 다양한 방어 기법과 실제 환경에서도 강한 전이 성능을 보인다.

## 3. From Untrusted Input to Trusted Memory: A Systematic Study of Memory Poisoning Attacks in LLM Agents 🆕

- **저자**: Pritam Dash, Tongyu Ge, Aditi Jain, Tanmay Shah, Zhiwei Shang
- **키워드**: `memory poisoning`, `LLM agents`, `agent safety`, `adversarial attack`, `memory write channels`
- **출처**: SNS
- **arxiv abstract**: [2606.04329](https://arxiv.org/abs/2606.04329) (v1)
- **PDF**: [arxiv.org/pdf/2606.04329](https://arxiv.org/pdf/2606.04329.pdf)

**핵심 요약** (3-5문장):
LLM 에이전트의 영속 메모리 기능은 상호작용 간 지식 누적을 가능하게 하지만, 단 한 번의 악의적 메모리 쓰기가 장기간 에이전트 행동을 조종하는 메모리 포이즈닝 공격을 허용한다. 이 논문은 네 가지 메모리 쓰기 채널과 모델 역량·시스템 프롬프트·에이전트 아키텍처에 걸친 9개 구조적 취약점을 체계적으로 분류하고, 여섯 가지 공격 유형의 분류 체계를 구성한다. MPBench 벤치마크를 통한 평가에서 메모리 쓰기·검색에 적극적으로 설계된 에이전트일수록 취약성이 높음을 확인했으며, 이는 에이전트 메모리 설계 시 보안 고려의 필요성을 강조한다.

**핵심 요약** (3-5문장):
LLM 에이전트는 민감한 자격증명과 신뢰할 수 없는 외부 콘텐츠를 동일 컨텍스트 창에 배치함으로써 간접 프롬프트 인젝션을 통한 자격증명 탈취 경로를 노출한다. 이 논문은 세 가지 보완적 방어 기법을 제안한다: 출력 토큰 생성 전 활성화 탐침을 통한 사전 탐지, 형식별 문자 모델로 구성한 허니토큰과 컨포멀 예측 기반 임계값 설정, 그리고 다중 턴에 걸친 누적 정보 유출 예산 추적이다. 오픈 웨이트 모델 실험에서 활성화 특징이 인코딩 변환 하에서도 정상·탈취 시도를 고정확도로 분리하며, 다중 턴 누적 탐지가 단일 턴 탐지기가 놓치는 공격을 효과적으로 잡아냄을 입증했다.

**핵심 요약** (3-5문장):
양성 데이터셋으로 파인튜닝해도 LLM의 안전 정렬이 저하되는 문제가 존재하지만, 기존 안전성 저하 샘플 탐지 방법은 계산 비용이 높고 노이즈가 많다. DataShield는 각 샘플이 모델의 순응 행동에 기여하는 정도를 안전성 저하 점수로 정량화하여 잠재적 안전성 저하 샘플을 효율적으로 탐지·필터링하는 방법론을 제안한다. Llama3, Llama3.1, Qwen2.5 등 다양한 모델에서 파인튜닝 후 안전성 유지 효과를 검증하며, 안전성-유용성 균형을 저비용으로 달성한다.

- **arxiv abstract**: [2506.05451](https://arxiv.org/abs/2506.05451) (v1)
- **PDF**: [arxiv.org/pdf/2506.05451](https://arxiv.org/pdf/2506.05451.pdf)

**핵심 요약** (3-5문장):
LLM의 불안전 행동 원인을 해석 기법으로 규명하는 연구가 증가하고 있으나, 해석과 안전성을 체계적으로 연결한 통합 조망이 부재했다. 이 논문은 Georgia Tech 연구팀이 제시하는 첫 통합 프레임워크로, 안전성 지향 해석 기법·이를 통해 도출된 안전성 향상책·구현 도구를 연결하는 새로운 분류 체계를 제안한다. LLM 워크플로우 단계별로 구성된 분류 체계를 통해 약 70편의 연구를 정리하며, 해석 기법이 더 안전한 LLM 개발에 어떻게 기여하는지 종합적 로드맵을 제공한다.

## 8. Provably Protecting Fine-Tuned LLMs from Training Data Extraction while Preserving Utility 🆕

- **저자**: Tom Segal, Asaf Shabtai, Yuval Elovici (Ben-Gurion University)
- **키워드**: `training data extraction`, `Near Access Freeness`, `differential privacy`, `fine-tuning`, `data leakage`
- **출처**: SNS
- **arxiv abstract**: [2602.00688](https://arxiv.org/abs/2602.00688) (v1)
- **PDF**: [arxiv.org/pdf/2602.00688](https://arxiv.org/pdf/2602.00688.pdf)

**핵심 요약** (3-5문장):
민감 데이터셋으로 파인튜닝된 LLM은 훈련 데이터 추출(TDE) 공격에 취약하지만, 기존 방어는 공식 보장이 없거나 성능 저하가 크다. 파인튜닝이 광범위한 확률 이동을 유발하더라도 소수의 영향력 있는 토큰 수준 편차만 보존하면 충분하다는 핵심 관찰을 바탕으로, 상대 확률에 기반한 NAF(Near Access Freeness) 알고리즘 SCP-Δr을 제안한다. SCP-Δr은 기존 NAF 방법보다 이론적 경계를 수십 배 개선하면서 TDE 공격으로부터 강한 실증적 보호를 유틸리티 손실 없이 제공한다.

- **arxiv abstract**: [2603.13026](https://arxiv.org/abs/2603.13026) (v1)
- **PDF**: [arxiv.org/pdf/2603.13026](https://arxiv.org/pdf/2603.13026.pdf)

**핵심 요약** (3-5문장):
프롬프트 인젝션 방어의 적응적 공격 취약성이 불충분하게 평가되어 거짓된 안전감을 제공하는 문제가 있다. PISmith는 RL(GRPO 기반)로 공격 LLM을 훈련해 블랙박스 환경에서 기존 프롬프트 인젝션 방어를 체계적으로 평가하는 레드티밍 프레임워크를 제안한다. 극단적 보상 희소성 문제 해결을 위해 적응적 엔트로피 정규화와 동적 이점 가중치를 도입했으며, Penn State 연구팀이 13개 벤치마크에서 평가한 결과 최신 방어 기법들이 적응적 공격에 여전히 취약함을 실증했다.

## 10. Differential Privacy in Machine Learning: A Survey from Symbolic AI to LLMs 🆕

- **저자**: Francisco Aguilera-Martínez, Fernando Berzal (University of Granada)
- **키워드**: `differential privacy`, `DP-SGD`, `LLM`, `privacy`, `survey`
- **출처**: SNS
- **arxiv abstract**: [2506.11687](https://arxiv.org/abs/2506.11687) (v2)
- **PDF**: [arxiv.org/pdf/2506.11687](https://arxiv.org/pdf/2506.11687.pdf)

**핵심 요약** (3-5문장):
차분 프라이버시(DP)는 단일 데이터 포인트의 포함 여부가 알고리즘 출력을 크게 변경하지 않도록 보장하는 형식적 프레임워크로, ML 모델의 프라이버시 위험 완화에 핵심적이다. 이 서베이는 DP의 기초 정의부터 심볼릭 AI의 역사적 맥락을 거쳐 현대 LLM에서의 DP 적용까지 종합적으로 검토하며, 이론과 응용 양면에서 주요 기여들을 체계화한다. DP 기반 ML 기법의 실용적 평가 방법론을 포함하여 책임 있는 AI 시스템 개발을 위한 종합 참고 자료를 제공한다.
