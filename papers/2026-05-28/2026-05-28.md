## 1. D²-Monitor: Dynamic Safety Monitoring for Diffusion LLMs via Hesitation-Aware Routing 🆕

- **저자**: Aoxi Liu, Yupeng Chen, James Oldfield, Guanzhe Hong, Junchi Yu et al.
- **키워드**: `safety monitoring`, `diffusion LLM`, `hesitation-aware routing`, `probe`, `AI security`
- **출처**: HF Daily (31 upvotes)
- **arxiv abstract**: [2605.25893](https://arxiv.org/abs/2605.25893) (v1)
- **PDF**: [arxiv.org/pdf/2605.25893](https://arxiv.org/pdf/2605.25893.pdf)

**핵심 요약** (한국어):
Autoregressive LLM과 달리 Diffusion LLM(D-LLM)은 다단계 denoising 과정을 통해 텍스트를 생성하는데, 이 중간 hidden representation에는 기존 단일 step 모니터링으로는 포착할 수 없는 safety 관련 정보가 담겨 있다. 본 논문은 D-LLM에 특화된 안전 모니터링 시스템 D²-Monitor를 제안하며, 모델이 안전 경계에서 "망설이는(hesitation)" 신호를 탐지해 위험 쿼리를 동적으로 라우팅한다. Oxford 그룹(Philip Torr, Adel Bibi)이 주도한 연구로, D-LLM 환경에서 safety monitoring의 기초를 다지는 첫 체계적 연구다.

## 2. Confidence and Calibration of Activation Oracles for Reliable Interpretation of Language Model Internals 🆕

- **저자**: Federico Torrielli, Peter Schneider-Kamp, Lukas Galke Poech
- **키워드**: `activation oracle`, `mechanistic interpretability`, `uncertainty quantification`, `calibration`, `probing`
- **출처**: HF Daily (AI Safety & Interpretability Lab)
- **arxiv abstract**: [2605.26045](https://arxiv.org/abs/2605.26045) (v1)
- **PDF**: [arxiv.org/pdf/2605.26045](https://arxiv.org/pdf/2605.26045.pdf)

**핵심 요약** (한국어):
Activation oracle은 모델 활성값을 자연어로 설명하는 interpretability 기법이지만, 출력에 대한 불확실성 정량화(UQ)가 그동안 연구되지 않았다. 이 논문은 6가지 confidence 추정 방법을 비교하여, bootstrap mode frequency가 가장 잘 보정된다는 것을 밝혔다(ECE 5.7% vs 기존 25.5%, Qwen3-8B 기준). 저렴한 log-prob 기준선도 빠른 triage 신호로 활용 가능하며, 실용적 해석 가능성을 위한 신뢰도 평가 기반을 제공한다.

## 3. ZeroUnlearn: Few-Shot Knowledge Unlearning in Large Language Models 🆕

- **저자**: Yujie Lin, Chengyi Yang, Zhishang Xiang, Yiping Song, Jinsong Su
- **키워드**: `machine unlearning`, `knowledge re-mapping`, `model editing`, `representational orthogonality`, `privacy`
- **출처**: HF Daily
- **arxiv abstract**: [2605.18879](https://arxiv.org/abs/2605.18879) (v2)
- **PDF**: [arxiv.org/pdf/2605.18879](https://arxiv.org/pdf/2605.18879.pdf)

**핵심 요약** (한국어):
LLM은 대규모 웹 데이터로 학습되어 민감 정보를 필연적으로 내재화하는데, 기존 unlearning 방법들은 재학습이나 공격적 fine-tuning에 의존해 계산 비용이 크거나 일반 성능을 저하시킨다. ZeroUnlearn은 unlearning을 "지식 재매핑" 문제로 재정의하여, closed-form solution으로 표현적 직교성을 강제하는 곱셈 파라미터 업데이트로 효율적이고 정밀한 unlearning을 가능하게 한다. 단 몇 개의 forget 샘플만으로도 성능을 유지하면서 민감 지식을 제거할 수 있음을 보인다.

## 4. A Survey on the Security of Long-Term Memory in LLM Agents: Toward Mnemonic Sovereignty 🆕

- **저자**: Zehao Lin, Chunyu Li, Kai Chen
- **키워드**: `agent memory security`, `mnemonic sovereignty`, `long-term memory`, `prompt injection`, `privacy leakage`
- **출처**: alphaxiv, SNS(LinkedIn)
- **arxiv abstract**: [2604.16548](https://arxiv.org/abs/2604.16548) (v1)
- **PDF**: [arxiv.org/pdf/2604.16548](https://arxiv.org/pdf/2604.16548.pdf)

**핵심 요약** (한국어):
LLM 에이전트에 장기 메모리가 도입되면서 보안 위협의 축이 "모델이 훈련 데이터를 유출하는가"에서 "지속적 메모리가 세션 간 오염·무단 접근·조직 공유 상태로 전파되는가"로 이동하고 있다. 저자들은 Write-Store-Retrieve-Execute-Share-Forget 6단계 생명주기에 걸쳐 Integrity, Confidentiality, Availability, Governance 4개 보안 목표를 분석하는 프레임워크를 제시한다. "Mnemonic Sovereignty"—쓰기·읽기·업데이트 권한과 감사 가능성·망각 가능성에 대한 검증 가능한 거버넌스—를 핵심 개념으로 제안하며, 메모리 거버넌스 품질이 향후 에이전트 보안의 핵심 경쟁력이 될 것임을 주장한다.

> 🔄 2026-08-09: v1 → v2 로 갱신됨. 변경점: 제목과 저자 구성이 크게 바뀌고, Mnemonic Sovereignty 중심 서술이 다섯 원칙의 Verifiable Memory Governance로 재구성됐다. 저장 시점 출처·버전·보존 정책의 중요성도 새 결론으로 명시됐다.

## 5. Measuring the Depth of LLM Unlearning via Activation Patching 🆕

- **저자**: Jaeung Lee, Dohyun Kim, Jaemin Jo
- **키워드**: `LLM unlearning`, `activation patching`, `mechanistic interpretability`, `Unlearning Depth Score`, `privacy`
- **출처**: arxiv recent
- **arxiv abstract**: [2605.24614](https://arxiv.org/abs/2605.24614) (v1)
- **PDF**: [arxiv.org/pdf/2605.24614](https://arxiv.org/pdf/2605.24614.pdf)

**핵심 요약** (한국어):
LLM unlearning은 특정 지식 삭제를 검증하는 것이 어렵고, 기존 출력 수준 지표들은 내부 표현에 지식이 잔류하는 경우를 감지하지 못한다. 이 논문은 activation patching을 통해 unlearning의 "기계적 깊이"를 정량화하는 Unlearning Depth Score(UDS)를 제안한다. Retain 모델을 기준으로 목표 지식을 인코딩하는 레이어를 식별한 뒤, unlearned 모델에서 해당 지식이 얼마나 지워졌는지를 0~1 척도로 측정한다. 20가지 지표 중 가장 높은 충실도와 강건성을 기록했다(150개 unlearned 모델, 8개 방법 평가).

## 6. Reframing LLM Agent Security as an Agent-Human Interaction Problem 🆕

- **저자**: Peiran Wang, Ying Li, Yuan Tian
- **키워드**: `agent security`, `agent-human interaction`, `prompt injection`, `policy specification`, `runtime approval`
- **출처**: arxiv recent
- **arxiv abstract**: [2605.24309](https://arxiv.org/abs/2605.24309) (v1)
- **PDF**: [arxiv.org/pdf/2605.24309](https://arxiv.org/pdf/2605.24309.pdf)

**핵심 요약** (한국어):
LLM 에이전트 보안은 순수 알고리즘 문제가 아니라 본질적으로 에이전트-인간 상호작용(AHI) 문제라고 이 논문은 주장한다. 59편의 학술 논문, 21개 프로덕션 에이전트 시스템, 26개 보안 플러그인 분석 결과(2026년 4월 기준), 학계에서 가장 많이 연구된 intent anchoring과 trust labeling은 실제 배포 사례가 전혀 없는 반면, policy specification·runtime approval·scope configuration은 21개 시스템 중 14개 이상에서 채택되어 있음을 밝힌다. UCLA 연구팀은 현재 LLM 역량 수준에서는 에이전트 보안 의사결정에 인간 참여가 불가결하다고 결론짓는다.

## 10. GLiNER Guard: Unified Encoder Family for Production LLM Safety and Privacy 🆕

- **저자**: GLiNER 연구팀 (HiveTrace)
- **키워드**: `LLM safety`, `PII detection`, `encoder`, `production`, `safety moderation`
- **출처**: arxiv recent
- **arxiv abstract**: [2605.05277](https://arxiv.org/abs/2605.05277) (v1)
- **PDF**: [arxiv.org/pdf/2605.05277](https://arxiv.org/pdf/2605.05277.pdf)

**핵심 요약** (한국어):
프로덕션 LLM 시스템은 엄격한 지연 시간·비용 제약 하에서 safety moderation과 PII 탐지를 동시에 요구하지만, autoregressive 모더레이터는 정확하지만 느리고 경량 인코더는 빠르지만 능력이 부족한 트레이드오프가 존재한다. GLiNER Guard(GLiGuard)는 단일 forward pass로 safety 분류와 PII 탐지를 수행하는 통합 인코더로, compact 모델(145-147M)과 고품질 GLiGuard Omni(209M) 세 가지 변형을 제공한다. A100 단일 GPU에서 193 req/sec(P99 < 1s)를 달성하며 GLiNER2 대비 1.6배 높은 처리량을 기록했고, PII 탐지 평가를 위한 PII-Bench도 공개한다.
