## 1. Diagnosing and Correcting Reward Hacking in Verifiable Instruction Following  🆕
- **저자**: Sangyeon Yoon, Wooseok Seo, Hamish Ivison, Hyesoo Hong, Donghoon Kim et al.
- **키워드**: reward hacking, alignment attacks, verifiable rewards, instruction following
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2610.19525](https://arxiv.org/abs/2610.19525) (v1)
- **PDF**: [arxiv.org/pdf/2610.19525](https://arxiv.org/pdf/2610.19525.pdf)
- **핵심 요약**: 형식 제약을 확인하는 평가기는 답변이 실제 요청에 응답했는지를 놓칠 수 있다. 연구진은 같은 평가기를 강화학습 보상으로 사용하면 제약 충족률은 높아지지만 응답 품질이 낮아지는 보상 해킹을 확인했다. CALIF는 고정 참조 정책이 요청만 보고 계산한 보정 우도 보너스를 기존 보상에 더한다. 1.7B부터 8B까지의 모델에서 품질을 학습 전 수준 이상으로 유지했고, 세 벤치마크의 45개 모델·지표 비교 중 40개에서 기본 정책보다 나았다.

## 2. DecisionRobust: Benchmarking Robustness for JEV Style Decision Models Across Text and Vision  🆕
- **저자**: Yifan Lan, Zhongye Liu, Yurui Chang, Hanyu Wang, Yongkang Du et al.
- **키워드**: adversarial attacks, prompt injection, multimodal robustness, decision models
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2610.19118](https://arxiv.org/abs/2610.19118) (v1)
- **PDF**: [arxiv.org/pdf/2610.19118](https://arxiv.org/pdf/2610.19118.pdf)
- **핵심 요약**: 구조화된 결정을 직접 반환하는 모델은 텍스트와 시각 입력의 공격에 모두 노출된다. DecisionRobust는 의미 보존 텍스트 교란, 이미지 교란, 두 모달리티의 프롬프트 주입을 함께 평가한다. 연구진은 텍스트 30개와 비전 17개 모델 구성을 검사했으며, 입력 교란에 강한 모델이 프롬프트 주입에도 강한 것은 아님을 확인했다. 정답 의미가 유지됐는지 검사하는 라벨 일관성 검증은 겉보기 공격 성공률을 크게 낮춰, 공격 유효성 검증의 중요성을 보여준다.

## 3. The Thinking Leakage in Reinforcement Learning for LLMs  🆕
- **저자**: Wenxuan Zhu, Shuming Liu, Bang An, Aznaur Aliev, Bing Li et al.
- **키워드**: mechanistic interpretability, activation intervention, attention heads, representation analysis
- **출처**: HF Daily
- **arxiv abstract**: [2610.14270](https://arxiv.org/abs/2610.14270) (v1)
- **PDF**: [arxiv.org/pdf/2610.14270](https://arxiv.org/pdf/2610.14270.pdf)
- **핵심 요약**: 하이브리드 추론 모델의 NO-THINK 모드 강화학습 성능 향상이 새 능력 학습인지 기존 THINK 능력의 재활성화인지 불분명하다. 연구진은 Qwen3 1.7B, 4B, 8B를 학습하고 가중치, 활성값, 어텐션 헤드를 분석했다. Qwen3-8B에서 저차원 THINK 관련 활성 부분공간을 원래 값으로 교체하자 강화학습 이득 대부분이 사라졌고, 반대 개입은 원 모델에 이득을 전달했다. 결과는 NO-THINK 성능 향상의 상당 부분이 새 추론 능력보다 기존 THINK 상태로의 표현 이동에서 나온다는 인과적 증거를 제시한다.

## 4. SkillMarker: A KGW-Based Watermarking Method for Agent Skill Ownership Verification  🆕

- **키워드**: agent skill leakage, watermarking, ownership verification, data extraction
- **출처**: HF Daily
- **arxiv abstract**: [2610.15725](https://arxiv.org/abs/2610.15725) (v2)
- **PDF**: [arxiv.org/pdf/2610.15725](https://arxiv.org/pdf/2610.15725.pdf)
- **핵심 요약**: 평문으로 배포되는 에이전트 스킬은 무단 복제와 유출 추적이 어렵다. SkillMarker는 핵심 지식과 표현 가능한 부분을 분리해 기능을 보존하면서 KGW 기반 워터마크 신호를 강화한다. 네 데이터셋에서 평균적인 하위 과제 성능 영향은 미미했다고 보고했다. 복사 구간이 1,536개 연속 토큰만 포함해도 탐지했으며, 최대 세 개 배경 스킬과 합친 뒤에도 탐지율은 72.2–77.8%였다.

## 5. MMA-SafetyBench: A Benchmark for Multimodal Agent Safety Evaluation  🆕
- **저자**: Yuke Wang, Benlei Cui, Shen Pang, Xuemei Dong, Longtao Huang et al.
- **키워드**: multimodal agent safety, visual prompt injection, semantic hijacking, safety benchmark
- **출처**: arxiv recent
- **arxiv abstract**: [2610.19384](https://arxiv.org/abs/2610.19384) (v1)
- **PDF**: [arxiv.org/pdf/2610.19384](https://arxiv.org/pdf/2610.19384.pdf)
- **핵심 요약**: 시각 인터페이스를 사용하는 에이전트는 위조 경고처럼 의미 있는 화면 요소에 의해 승인된 과제에서 이탈할 수 있다. MMA-SafetyBench는 후보 주입 지점을 찾고 재현 가능한 시각 페이로드를 삽입한 1,083개 적대적 궤적을 제공한다. 웹, 데스크톱, 모바일, 문서, 비디오의 다섯 영역에서 아홉 모델을 평가했다. 공격 성공률은 최대 87.96%, 의미 훼손률은 98.09%였으며, 안전 우선 프롬프트도 실패 유형을 제거하지 못했다.

## 6. Quiet Triggers, Loud Footprints: A Tri-Space Measurement Study of Backdoor Stealthiness  🆕
- **저자**: Behrad Tajalli, Henk Berendsen, Xiaoyun Xu, Stjepan Picek
- **키워드**: backdoor attacks, trigger stealthiness, feature attribution, model auditing
- **출처**: arxiv recent
- **arxiv abstract**: [2610.19947](https://arxiv.org/abs/2610.19947) (v1)
- **PDF**: [arxiv.org/pdf/2610.19947](https://arxiv.org/pdf/2610.19947.pdf)
- **핵심 요약**: 백도어 공격은 성공률과 정상 정확도 외에도 여러 공간에서의 은밀성을 함께 평가해야 한다. 이 연구는 입력, 특징, 매개변수 공간의 흔적을 구분하고 네 데이터셋과 세 모델 구조에서 대표 공격을 비교한다. 한 공간에서 은밀한 공격도 다른 공간에서는 뚜렷한 흔적을 남겼으며, 세 공간 모두에서 일관되게 작은 흔적을 보인 공격은 드물었다. 연구진은 클래스별 특징 중첩과 트리거 반응·영향 채널을 측정하는 두 진단 지표를 추가해 단일 지표 평가의 사각지대를 보완했다.

- **출처**: arxiv recent
- **arxiv abstract**: [2610.19158](https://arxiv.org/abs/2610.19158) (v1)
- **PDF**: [arxiv.org/pdf/2610.19158](https://arxiv.org/pdf/2610.19158.pdf)
- **핵심 요약**: 에이전트가 이메일과 문서를 오가며 민감 정보를 처리할 때는 문맥별 공개 제약을 지키는지 평가해야 한다. AgentCIScope는 공개·합성 개인정보 사례를 정책, 페르소나 합의, 민감 속성 분류에 근거한 실행 가능한 다단계 과제로 변환한다. 12개 에이전트의 936개 과제에서 단일 실행 유출률은 32.5–94.4%였다. 같은 과제를 다섯 번 반복하면 유출률이 4–19%p 더 올라, 과제 성공률이 개인정보 문맥 무결성을 보장하지 않음을 보였다.

- **출처**: arxiv recent
- **arxiv abstract**: [2610.19498](https://arxiv.org/abs/2610.19498) (v1)
- **PDF**: [arxiv.org/pdf/2610.19498](https://arxiv.org/pdf/2610.19498.pdf)
- **핵심 요약**: 원본 LLM 가중치의 서명은 실제 실행되는 양자화 산출물의 동일성을 보장하지 않는다. 연구진은 인기 GGUF 저장소 198개에서 제3자가 비트 단위로 재생성할 수 있는 비율을 측정했지만, 빌드 환경 기록이 없어 0/198이었다. 누락된 부동소수점 수축 설정과 텐서별 양자화 조리법을 보완하자 x86에서 대상 파일 8개 중 7개를 재현했다. 단순 통계는 표적 임베딩 변조를 놓칠 수 있어, 환경과 입력을 고정한 정확한 재생성을 공급망 검증의 핵심으로 제안한다.
