## 1. Agent Mosaic: Recognizing Confidentiality Leaks in Agentic LLM Systems  🆕
- **저자**: Daniel Ruiz, Luca Luceri, Emilio Ferrara
- **키워드**: confidentiality leakage, mosaic effect, agent safety, information aggregation
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2610.30418](https://arxiv.org/abs/2610.30418) (v1)
- **PDF**: [arxiv.org/pdf/2610.30418](https://arxiv.org/pdf/2610.30418.pdf)
- **핵심 요약**: 에이전트가 개별 문서의 비민감 정보들을 결합해 금지된 결론을 누설하는 모자이크 효과를 정량화한다. 연구진은 사이버보안, 의료, 군사 영역의 30개 합성 사례로 시뮬레이션 10,800건과 실제 하네스 1,440건을 평가했다. 최우수 모델도 무해한 질의에서 금지된 복합 정보를 7.08% 누설했고, 분류 헤더와 집계 규칙을 적용한 뒤에도 전체 의도에서 32.37%의 누설이 남았다. 단순 거부율보다 추론과 공개 범위를 직접 통제해야 함을 보여준다.

## 2. RIDAR: Safeguarding Research Integrity in Autonomous Research Agents via Automated Detection and Runtime Intervention  🆕
- **저자**: Jiening Siow, Amy Xin, Junjie Wang, Ziyu Tang, Zijun Yao et al.
- **키워드**: research agents, runtime intervention, integrity violations, agent safety
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2610.31372](https://arxiv.org/abs/2610.31372) (v1)
- **PDF**: [arxiv.org/pdf/2610.31372](https://arxiv.org/pdf/2610.31372.pdf)
- **핵심 요약**: 자율 연구 에이전트가 타당성, 재현성, 충실성을 훼손하는 연구 무결성 위반을 자동 탐지하고 실행 중 교정한다. RIDAR는 연구 전 과정의 14개 위반 유형을 정의하고, 60개 전문가 주석 궤적에서 사후 탐지 F1 85.2%를 달성했다. 50개 과제의 300개 실제 궤적에서는 99.7%에서 총 3,964건의 위반을 찾았다. 런타임 개입은 과제 종료 시 남은 위반을 36.8% 줄였다.

## 3. SCOPE: Compiling Natural-Language Policies into Neurosymbolic Predicate Programs  🆕
- **저자**: Arnon Mazza, Elad Levi
- **키워드**: policy enforcement, neurosymbolic programs, interpretable guardrails, agent safety
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2610.31062](https://arxiv.org/abs/2610.31062) (v1)
- **PDF**: [arxiv.org/pdf/2610.31062](https://arxiv.org/pdf/2610.31062.pdf)
- **핵심 요약**: 다중 턴 대화와 도구 호출에 걸친 복합 정책은 경량 가드레일에서 정확도가 떨어지고, LLM 판정기는 비용과 변동성이 크다. SCOPE는 자연어 정책을 작은 모델의 신경 술어, 결정적 추출기, 명시적 논리 코드로 구성된 실행 프로그램으로 컴파일한다. 정책 위반 지점을 겨냥한 적대적 반례를 생성해 프로그램과 학습 데이터를 함께 최적화한다. 실제 정책 과제에서 평균 정확도가 가장 높았고, 저비용 모델에서도 프런티어 추론 모델과 비슷한 정확도와 더 안정적이고 해석 가능한 판정을 보였다.

## 4. Inherited, Not Invented: Tracing the Provenance of Wait in Reasoning Models  🆕
- **저자**: Zhizhuo Kou, Sizai Hou, Long Chen, Jian Yang, Junyu Luo et al.
- **키워드**: reasoning provenance, behavioral markers, probing, reinforcement learning
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2610.30882](https://arxiv.org/abs/2610.30882) (v1)
- **PDF**: [arxiv.org/pdf/2610.30882](https://arxiv.org/pdf/2610.30882.pdf)
- **핵심 요약**: 추론 모델의 재고 표지인 `wait`가 강화학습으로 새로 생긴다는 통념을 학습 이력 관점에서 검증한다. 빈도, 위치, 형태, 용례의 라벨 없는 지표와 오류 주입 시험으로 공개 모델의 여러 학습 단계를 추적한다. 기본 모델에 표지가 없으면 RL이 MATH-500 정확도를 높여도 표지는 거의 생기지 않았고, 중간학습이나 추론 궤적 미세조정에서 주로 유입됐다. 따라서 표지 빈도만으로 RL이 만든 추론 능력이나 자기수정을 해석해서는 안 된다고 결론짓는다.

## 5. EpiSEM-Bench: Evaluating Safety and Evidence Recovery in LLM Agents under Missing Evidence  🆕
- **저자**: Qijin Zhang, Hanzhen Wang, Yuehan Zhao, Haoyu Dai, Yao Shu et al.
- **키워드**: agent safety, missing evidence, tool use, safety benchmark
- **출처**: arxiv recent
- **arxiv abstract**: [2610.31650](https://arxiv.org/abs/2610.31650) (v1)
- **PDF**: [arxiv.org/pdf/2610.31650](https://arxiv.org/pdf/2610.31650.pdf)
- **핵심 요약**: 도구 응답에서 안전 관련 사실이 빠졌을 때 에이전트가 진실한 정보만 보고도 금지된 행동을 수행하는 문제를 평가한다. EpiSEM-Bench는 6개 영역의 안전·비안전 대응 과제 300쌍에서 핵심 증거를 체계적으로 숨긴다. 독립 감사 도구는 에이전트가 누락 사실을 다시 찾고, 금지 행동을 보류하면서 허용 과제를 완료하는지 측정한다. 10개 모델에서 누락 강건성과 증거 회복 능력은 크게 달랐고, 회복 접근권이 모든 모델의 위험 행동을 줄였지만 능동적 확인과 적절한 행동으로 항상 이어지지는 않았다.

## 6. OP-Print: Tracing Membership Imprints in On-Policy Self-Distillation  🆕
- **저자**: Qi Li, Xinchao Wang
- **키워드**: membership inference, self-distillation, black-box attacks, training data privacy
- **출처**: arxiv recent
- **arxiv abstract**: [2610.31616](https://arxiv.org/abs/2610.31616) (v1)
- **PDF**: [arxiv.org/pdf/2610.31616](https://arxiv.org/pdf/2610.31616.pdf)
- **핵심 요약**: 같은 학습 예시의 결합된 두 관점을 사용하는 온정책 자기증류가 멤버십 정보를 더 강하게 남기는지 조사한다. OP-Print는 감독 신호의 흔적이 전체 롤아웃이 아니라 불확실성에 민감한 교정 지점에 희소하고 구조적으로 집중된다는 관찰을 이용한다. 그레이박스에서는 교사-학생 잔차 교정을 집계하고, 블랙박스에서는 재시작 출력의 안정성을 숨은 교정 과정의 대리 신호로 쓴다. 기존 공격은 그레이박스에서도 무작위 추측 수준이었지만, OP-Print는 다양한 모델과 증류 방식의 두 위협 모델에서 효과를 보였다.

## 7. AgentPhishing: A Benchmark of LLM Email Agents Under Adaptive Attack  🆕

- **키워드**: phishing, adaptive attacks, email agents, red-teaming
- **출처**: arxiv recent
- **arxiv abstract**: [2610.31404](https://arxiv.org/abs/2610.31404) (v1)
- **PDF**: [arxiv.org/pdf/2610.31404](https://arxiv.org/pdf/2610.31404.pdf)
- **핵심 요약**: 기존 피싱 탐지 데이터가 에이전트 맞춤형 설득 공격과 실제 행동 유도를 충분히 측정하지 못하는 문제를 다룬다. AgentPhishing은 개별 에이전트에 맞춰 재사용 가능한 이메일 생성 기술을 최적화하는 PhishOpt를 포함한다. 생성 이메일의 설득 전략을 분석해 범용 공격 기술도 구성했다. 9개 에이전트 중 4개는 적응형 공격에서 탐지율이 10% 미만이었고, 악성 요청 준수율은 45%를 넘었다.

- **키워드**: data deletion, persistent memory, information reconstruction, privacy auditing
- **출처**: arxiv recent
- **arxiv abstract**: [2610.31366](https://arxiv.org/abs/2610.31366) (v1)
- **PDF**: [arxiv.org/pdf/2610.31366](https://arxiv.org/pdf/2610.31366.pdf)
- **핵심 요약**: 원본 메모리를 삭제해도 요약이나 파생 상태에 정보가 남는 에이전트 개인정보 삭제 실패를 감사한다. 노출 후 삭제된 에이전트와 한 번도 비밀을 보지 않은 대조군을 비교해 복구 원인을 최초 노출에 귀속한다. Qwen2.5-7B-Instruct에서는 단일 질의로 약 3분의 2를 복구했고, 문자열이 남지 않아도 분리된 구성 요소만으로 세 모델에서 62~99%의 정확한 재구성이 발생했다. 출처를 추적해 파생 데이터를 함께 삭제하는 폐쇄 방식은 테스트된 설정에서 복구를 제거했다.

- **키워드**: input privacy, side-channel attacks, multi-exit networks, malicious model provider
- **출처**: arxiv recent
- **arxiv abstract**: [2610.31246](https://arxiv.org/abs/2610.31246) (v1)
- **PDF**: [arxiv.org/pdf/2610.31246](https://arxiv.org/pdf/2610.31246.pdf)
- **핵심 요약**: 악성 클라우드 제공자가 다중 출구 모델의 지연 시간만으로 사용자 입력의 민감 속성을 알아내는 공급망 공격을 제시한다. 제공자는 목표 속성에 따라 특정 출구로 라우팅되도록 모델의 신뢰도 분포를 조작하고, 서비스 중 질의별 지연으로 출구를 추론한다. 네 데이터셋과 열 개 속성에서 평균 F1 0.73을 기록해 최강 기준선 0.25를 크게 웃돌았다. 주 과제 정확도 저하는 1.3% 미만이고 대부분의 설정에서 추론 가속 저하도 0.1 미만이라 은닉성이 높았다.

## 10. Data-Void Exploits in Web-Searching LLMs  🆕
- **저자**: Michele Guerra, Wuyeh Jobe, Sanjana Nambiar, Christina Pöpper, Azza Abouzied
- **키워드**: data-void attacks, web-searching LLMs, disinformation, inference-time security
- **출처**: arxiv recent
- **arxiv abstract**: [2610.30365](https://arxiv.org/abs/2610.30365) (v1)
- **PDF**: [arxiv.org/pdf/2610.30365](https://arxiv.org/pdf/2610.30365.pdf)
- **핵심 요약**: 신뢰할 만한 콘텐츠가 희소한 검색 공간을 공격자가 채워 웹 검색형 LLM의 답변을 조작하는 데이터 보이드 공격을 분석한다. ChatGPT, Gemini, Sonar Pro에서 질문 어조와 공격 페이지의 전략, 가시성, 생성형 검색 최적화 요소를 변화시켰다. 공격자가 통제한 페이지 하나만으로도 공격 콘텐츠가 전체 조건의 31%에서 답변에 나타났다. 회의적 질문은 성공률을 소폭 낮췄지만, 질문 어조나 모델 선택이 큰 보호 효과를 낸다는 증거는 없었다.
