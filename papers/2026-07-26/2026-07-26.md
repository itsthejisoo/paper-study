## 1. Is One Layer Enough? Training A Single Transformer Layer Can Match Full-Parameter RL Training  🆕

- **저자**: Zijian Zhang, Rizhen Hu, Athanasios Glentis, Dawei Li, Chung-Yiu Yau et al.
- **키워드**: `mechanistic interpretability`, `probing`, `representation analysis`, `reinforcement learning`
- **출처**: HF Daily / alphaxiv / SNS
- **arxiv abstract**: [2607.01232](https://arxiv.org/abs/2607.01232) (v2)
- **PDF**: [arxiv.org/pdf/2607.01232](https://arxiv.org/pdf/2607.01232.pdf)

**핵심 요약** (3-5문장 한국어):

LLM의 RL 후학습은 모든 Transformer 층을 함께 갱신하지만, 실제 성능 향상이 어느 층에서 발생하는지는 충분히 밝혀지지 않았다. 이 연구는 개별 층만 학습했을 때 전체 파라미터 학습의 향상을 얼마나 회수하는지 측정하는 layer contribution을 도입하고, 두 모델 계열·세 RL 알고리즘·여러 과제에서 층별 효과를 비교한다. 성능 향상은 주로 중간층의 작고 안정적인 부분집합에 집중됐으며, 최고 단일 층은 전체 RL 향상의 최대 114%를 회수했다. Qwen3-8B에서 기여도가 높은 10개 층만 학습하면 수학 벤치마크 평균 정확도가 전체 학습의 66.4%에서 69.1%로 높아져, 내부 구조 분석을 효율적 학습 전략으로 연결했다.

## 2. HijackKV: New Threat in Position-Independent KV Cache Reuse  🆕

- **저자**: Yichi Zhang, Zhiqi Wang, Huan Zhang, Yuchen Yang
- **키워드**: `prompt injection`, `adversarial attacks`, `KV cache`, `model serving security`
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2607.19957](https://arxiv.org/abs/2607.19957) (v1)
- **PDF**: [arxiv.org/pdf/2607.19957](https://arxiv.org/pdf/2607.19957.pdf)

**핵심 요약** (3-5문장 한국어):

위치 독립적 KV cache 재사용은 같은 텍스트 조각의 캐시를 다른 위치에서도 공유해 추론을 가속하지만, 캐시가 생성 당시의 공격자 문맥까지 인코딩할 수 있다. HijackKV는 공격자 접두사가 뒤따르는 평범한 텍스트의 KV를 오염시켜, 피해자 입력에 공격 문장이 없어도 재사용 시 모델 행동을 탈취한다. 단일 시도 평균 공격 성공률은 94%였고, cache hit rate 10%와 재계산률 50% 조건에서도 효과가 유지됐으며 다중 턴 및 블랙박스 모델 간 전이도 확인됐다. USENIX Security 2026 채택 논문으로, 캐시 최적화 자체를 새로운 간접 prompt injection 표면으로 규명했다.

- **키워드**: `jailbreak`, `red-teaming`, `guardrail`, `adversarial training`
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2607.19829](https://arxiv.org/abs/2607.19829) (v1)
- **PDF**: [arxiv.org/pdf/2607.19829](https://arxiv.org/pdf/2607.19829.pdf)

**핵심 요약** (3-5문장 한국어):

고정된 jailbreak 데이터와 공격법으로 학습한 가드레일은 계속 변이하는 실제 공격 공간을 따라가기 어렵다. DARWIN은 전략 수집·변이·선택·피드백 조합으로 공격을 진화시키는 DARWIN-Attack과, 새 공격 샘플을 온라인 적대 학습에 반영하는 DARWIN-Guard를 순환시킨다. 공격 측은 DeepSeek-V4-Pro와 YuFeng-XGuard에서 거의 100%, GPT-5.5에서 90%가 넘는 공격 성공률을 보였다. 방어 측은 12개 안전 벤치마크에서 평균 unsafe recall 91.6%를 달성하면서 일반적인 benign 데이터의 통과율을 거의 100%로 유지했다.

## 4. JANUS: Foreseeing Latent Risk for Long-Horizon Agent Safety  🆕

- **저자**: Yuan Xiong, Linji Hao, Shizhu He, Yequan Wang, Lijun Li
- **키워드**: `agent safety`, `risk forecasting`, `tool-use security`, `guardrail`
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2607.19913](https://arxiv.org/abs/2607.19913) (v1)
- **PDF**: [arxiv.org/pdf/2607.19913](https://arxiv.org/pdf/2607.19913.pdf)

**핵심 요약** (3-5문장 한국어):

장기 실행 에이전트의 위험은 현재 행동만 보면 무해해도 이후 단계에서 드러날 수 있어, 실행 직전의 단순 판정만으로는 예방하기 어렵다. Janus는 다중 에이전트 시뮬레이션으로 궤적을 만들고, 부분 궤적에서 안전 관련 미래를 예측하는 anticipation과 현재·예측 미래를 함께 판정하는 adjudication을 공동 학습한다. CoAA-RL은 예측 자체의 유사도보다 후속 안전 판단에 실제로 도움이 되는지를 보상하며, 결과 모델 Vanguard는 위험 행동을 실행 전에 차단한다. 네 에이전트 안전 벤치마크에서 기존 guard보다 평균 보호 성능을 15.9%포인트, benign task completion을 5.1%포인트 높였다.

**핵심 요약** (3-5문장 한국어):

에이전트가 공개 마켓의 제3자 skill을 설치하면 겉보기에는 정상인 기능도 실행 시점에 잠재적 보안 위험을 드러낼 수 있다. OpenSkillRisk는 공개 skill marketplace에서 수집한 위험 skill 263개를 7개 위협 유형으로 분류하고, 표준 사용자 과제와 격리된 실행 환경을 함께 제공한다. 세 CLI 에이전트 프레임워크와 13개 LLM을 평가한 결과 가장 안전한 구성도 약 17%의 사례에서 위험 행동을 실행했다. 실패는 위험 미인식, 인식 후 개입 실패, 사용자 의도 범위를 넘는 skill 지시 준수의 세 패턴으로 나타나 모델 추론과 실행 제어를 함께 개선해야 함을 보여준다.

- **출처**: arxiv recent

**핵심 요약** (3-5문장 한국어):

기존 LLM 백도어 방어는 fine-tuning 기반 공격과 분류 과제에 치우쳐, model editing으로 심은 트리거나 개방형 생성을 충분히 다루지 못한다. DeCNIP은 유해 prompt의 후보 trigger와 benign 입력 사이 표현 차이를 최적화해 백도어 핵심 뉴런을 찾고, 해당 뉴런만 선택적으로 pruning한다. 6개 오픈소스 LLM과 2개 데이터셋에서 공격 성공률을 상대적으로 95% 넘게 줄였으며, 개입한 뉴런은 전체의 0.1%에 불과했다. 정상 벤치마크 성능의 97%를 유지해 내부 표현 분석이 보안성과 효용을 함께 보존할 수 있음을 보였다.

- **키워드**: `prompt injection`, `multi-agent security`, `tool poisoning`, `information bottleneck`
- **출처**: arxiv recent
- **arxiv abstract**: [2607.19430](https://arxiv.org/abs/2607.19430) (v1)
- **PDF**: [arxiv.org/pdf/2607.19430](https://arxiv.org/pdf/2607.19430.pdf)

**핵심 요약** (3-5문장 한국어):

개별 모델이 안전해도 planner·worker·verifier 사이의 메시지 채널은 공격 지시를 전달하는 감시되지 않은 경로가 될 수 있다. ChannelGuard는 각 에이전트 간 채널에 embedding 기반 information-bottleneck gate를 두어 텍스트를 통과·압축·차단하고, 어느 계층에서 공격이 멈췄는지 기록한다. 2,100개 trace 평가에서 tool poisoning 30건을 backend와 무관하게 모두 application layer에서 차단했고, prompt injection 성공률을 0.333에서 0.167로 낮추면서 GSM8K 정확도 0.867을 유지했다. 다만 white-box 적응형 paraphrase는 모든 embedding gate를 우회해, 결정적 필터만으로는 충분하지 않다는 한계도 확인됐다.

- **키워드**: `mechanistic interpretability`, `circuit analysis`, `probing`, `representation learning`
- **출처**: arxiv recent
- **arxiv abstract**: [2607.21491](https://arxiv.org/abs/2607.21491) (v1)
- **PDF**: [arxiv.org/pdf/2607.21491](https://arxiv.org/pdf/2607.21491.pdf)

**핵심 요약** (3-5문장 한국어):

서로 독립적으로 학습된 code model이 동일한 문법 개념을 같은 내부 회로와 위치에 표현하는지는 명확하지 않다. 이 연구는 Python과 Rust, Qwen2.5-Coder-7B와 DeepSeek-Coder-V1-6.7B를 교차한 2×2 설계에서 58개와 57개 문법 개념의 circuit을 추출한다. 어떤 개념이 전용 회로를 얻는지는 과제에 따라 두 모델이 상당히 일치했지만 Python과 Rust의 Spearman 상관은 각각 0.638과 0.673이었고, 회로의 위치와 층별 성장 방식은 모델에 따라 달랐다. Ablation과 linear probe로 회로의 기능성을 확인하며, 표현 내용의 보편성과 계산 조직의 보편성을 구분해야 한다는 결론을 제시한다.

**핵심 요약** (3-5문장 한국어):

Chain-of-thought 모델은 제한 토큰 안에 결론을 내리거나 예산을 모두 쓰고도 수렴하지 못하는 양봉형 패턴을 보이며, 후자의 계산은 대부분 낭비된다. DeepSeek-R1-Distill-Qwen-7B에서 수렴 응답의 정확도는 90.3%, 비수렴 응답은 6.6%였고 전체 수렴률은 62.0%였다. 초기 hidden-state에 학습한 linear probe 중 layer 20의 150번째 토큰이 AUC 0.608을 기록해 entropy와 반복 통계 기반 행동 지표보다 일관되게 높았다. 다만 permutation test의 p값이 0.063이어서 신호는 관찰됐지만 일반적 유의수준에서 확정되지는 않았다는 점을 명시한다.

- **PDF**: [arxiv.org/pdf/2607.21090](https://arxiv.org/pdf/2607.21090.pdf)

**핵심 요약** (3-5문장 한국어):

기존 연구는 self-explanation의 충실도를 평가하거나 prompting으로 개선하지만, 설명이 실제 내부 의사결정 요인을 드러내도록 모델 파라미터를 직접 최적화하지는 못했다. 이 연구는 Phi-CCT 상관 기반 충실도 지표를 RL 보상으로 바꾸고 random-word와 user-bias 개입이 판단에 미친 영향을 모델이 스스로 식별·공개하도록 학습한다.
