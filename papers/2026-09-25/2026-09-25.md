## 2. Schrödinger's Code Repository: Have LLMs Learned SWE-bench or Memorized It?  🆕

- **키워드**: training data leakage, memorization, SWE-bench, coding agents, evaluation contamination
- **출처**: HF Daily
- **arxiv abstract**: [2609.27891](https://arxiv.org/abs/2609.27891) (v1)
- **PDF**: [arxiv.org/pdf/2609.27891](https://arxiv.org/pdf/2609.27891.pdf)
- **핵심 요약**: 인기 오픈소스 저장소로 만든 코딩 벤치마크에서는 높은 성능이 일반화보다 저장소 단서의 암기에 기댈 수 있다. SchrodingerRepo는 실행 의미를 보존하면서 문제 설명, 이름 공간, 파일 내부 배치, 코드를 동적으로 변환해 익숙한 단서를 제거한다. SWE-bench Verified와 SWE-QA에서 단서를 없애자 성능이 하락하고 탐색·위치 추적 비용이 늘어, 현재 에이전트가 저장소 측 단서를 부분적으로 암기했을 가능성을 보여준다.

## 3. Your Model Is Leaking: Covert Information Transfer through LLM Residual Streams  🆕

- **저자**: Mingyuan Li, Yanna Jiang, Guangsheng Yu, Qin Wang, Xu Wang, et al.
- **키워드**: privacy leakage, residual stream, covert channel, activation monitoring, data exfiltration
- **출처**: arxiv recent
- **arxiv abstract**: [2609.27996](https://arxiv.org/abs/2609.27996) (v1)
- **PDF**: [arxiv.org/pdf/2609.27996](https://arxiv.org/pdf/2609.27996.pdf)
- **핵심 요약**: 격리 환경에서 진단용 중간 활성값을 외부로 반출하면, 손상된 런타임이 그 경로를 정보 유출 채널로 악용할 수 있다. 제안 공격은 모델 재학습이나 가중치 변경 없이 메시지를 코드워드로 바꾸고 잔차 스트림에 주입한 뒤 선형 디코더로 복구한다. 11개 모델 중 9개에서 91–100% 복구율과 0.001–0.007의 KL 발산을 보였고, 활성 수준 탐지기는 AUC 0.56 이하에 머물러 활성 아티팩트 자체를 보안 경계로 다뤄야 함을 보여준다.

## 4. Agent Name Collision Attacks in Multi-Agent Systems  🆕

- **저자**: Adithyan Arun Kumar
- **키워드**: agent safety, multi-agent security, name collision, identity binding, routing attack
- **출처**: arxiv recent
- **arxiv abstract**: [2609.27624](https://arxiv.org/abs/2609.27624) (v1)
- **PDF**: [arxiv.org/pdf/2609.27624](https://arxiv.org/pdf/2609.27624.pdf)
- **핵심 요약**: A2A 에이전트 카드의 사람이 읽는 이름을 안정적 식별자처럼 사용하면 같은 이름을 가진 공격자 에이전트로 요청이 잘못 전달될 수 있다. 저자는 7개의 고정된 오픈소스 구현에서 등록부터 디스패치까지 추적하고 격리 회귀 테스트를 수행했다. 6개 클라이언트형 통합에서 잘못된 피어로 라우팅됐으며, 방어는 이름을 표시 전용으로 제한하고 출처에 결합된 안정적 식별자를 사용해야 한다.

## 5. Control-Token Injection Suppresses Chain-of-Thought and Defeats Reasoning-Based Oversight in Tool-Using Agents  🆕

- **저자**: Muhammad Usama, Khair Un Nisa, Summer Yeoreum Jung
- **키워드**: prompt injection, control-token injection, agent safety, chain-of-thought oversight, tool parsing
- **출처**: arxiv recent
- **arxiv abstract**: [2609.27542](https://arxiv.org/abs/2609.27542) (v1)
- **PDF**: [arxiv.org/pdf/2609.27542](https://arxiv.org/pdf/2609.27542.pdf)
- **핵심 요약**: 도구 사용 에이전트의 안전성은 모델뿐 아니라 채팅 템플릿과 도구 호출 파서에도 의존하며, 두 부분 모두 비신뢰 입력으로 공격될 수 있다. gpt-oss-20b에서 채널 제어 토큰을 주입하자 40개 과제 모두 추론 토큰이 평균 52.5개에서 0개로 줄었지만 도구 호출은 계속 실행됐다. 일반 요청을 모두 잡던 두 모니터가 위조 요청을 놓쳤고, 명백한 악성 요청에서는 거부의 39.6%가 실제 정보 유출로 전환되어 파서 강화와 추론 부재 탐지를 함께 요구한다.

- **핵심 요약**: 기존 차등프라이버시 RAG는 실제로 비공개 데이터가 필요하지 않은 연산에도 예산을 써서 프라이버시 예산을 빠르게 소진한다. SparsePay-RAG는 공개 정보를 비용 없는 사전분포로 두고, 공개 토픽 클러스터링·등장회귀 기반 접근 제어·DP 대조 디코딩으로 비공개 증가분에만 예산을 부과한다. 저자들은 강한 프라이버시 제약에서 기존 방법보다 나은 프라이버시-효용 균형을 보고하며, 이 논문은 EMNLP 2026 Main에 채택됐다.

- **출처**: arxiv recent
- **arxiv abstract**: [2609.27155](https://arxiv.org/abs/2609.27155) (v1)
- **PDF**: [arxiv.org/pdf/2609.27155](https://arxiv.org/pdf/2609.27155.pdf)
- **핵심 요약**: 소셜 미디어 에이전트 공격은 독성 콘텐츠를 직접 노출한다고 가정하지만, 추천 시스템 자체가 은밀한 전달 경로가 될 수 있다. 연구는 OASIS의 좋아요 점수 피드백을 이용해 여러 단계의 독성 게시물이 에이전트 피드로 진입하는 조건을 분석하고 현실적인 게시물 생성 알고리즘을 제안한다. 실험에서는 사용자-게시물 유사도가 검색 임계값보다 낮아도 피드백 루프가 독성 게시물을 선택하게 만들어 추천 계층까지 에이전트 위협 모델에 포함해야 함을 보인다.

- **키워드**: RAG poisoning, adversarial attack, retrieval security, corpus poisoning, LLM security
- **출처**: arxiv recent
- **arxiv abstract**: [2609.27090](https://arxiv.org/abs/2609.27090) (v1)
- **PDF**: [arxiv.org/pdf/2609.27090](https://arxiv.org/pdf/2609.27090.pdf)
- **핵심 요약**: 기존 다중 문서 RAG 독성화는 비슷한 문서에 같은 주장을 반복해 군집·충돌 탐지 방어에 한꺼번에 제거되기 쉽다. DnD는 목표 답의 근거를 문체가 다른 문서에 분산하고, 정답 근거를 의심하게 만드는 문서를 추가해 표현 공간과 의미 충돌 신호를 흩트린다. 두 QA 데이터셋, 3개 LLM, 9개 RAG 구성에서 대부분의 설정에서 기존 공격과 같거나 더 강했고, 특히 군집 및 충돌 인식 방어에서 큰 이득을 보였다.

## 10. Ajar: Measuring Open Privilege in Agent Defenses  🆕

- **저자**: Reshabh K Sharma, Linxi Jiang, Shuo Chen, Zhiqiang Lin
- **키워드**: agent safety, indirect prompt injection, least privilege, access control, security evaluation
- **출처**: arxiv recent
- **arxiv abstract**: [2609.26900](https://arxiv.org/abs/2609.26900) (v1)
- **PDF**: [arxiv.org/pdf/2609.26900](https://arxiv.org/pdf/2609.26900.pdf)
- **핵심 요약**: 에이전트 방어는 공격 성공률과 정상 과제 효용만으로 평가돼, 과제에 불필요한 권한이 열려 있어도 좋은 점수를 받을 수 있다. Ajar는 기존 벤치마크의 과제와 도구 스키마를 재사용해 각 시점에 불필요한 도구 호출을 제시하고 허용 여부로 열린 권한을 직접 측정한다. AgentDojo의 5개 방어를 비교한 결과 열린 권한은 공격 성공률이나 효용에서 추론할 수 없었으며, 최소 권한을 독립적인 세 번째 평가축으로 다뤄야 함을 보여준다.
