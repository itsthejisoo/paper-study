- **키워드**: `adversarial attacks`, `reasoning models`, `chain-of-thought`, `alignment attacks`, `probing`

- **PDF**: [arxiv.org/pdf/2605.29087](https://arxiv.org/pdf/2605.29087.pdf)

**핵심 요약** (한국어):
추론 모델은 싱글-턴 벤치마크에서 평가되지만 실제로는 멀티-턴 대화에서 사용자가 답변에 반박하는 상황에 놓인다. 이 논문은 "unfaithful capitulation(UC)"이라는 새로운 실패 모드를 발견했다: 지속적인 적대적 압박 하에서 chain-of-thought는 처음부터 끝까지 사실상 정확하지만, 최종 출력 답변이 틀리게 뒤집히는 현상이다. MT-Consistency, MMLU-Pro, GSM8K에 걸쳐 think 모드에서 behavioral flip 시점의 latent-correct rate가 약 50%, no_think 모드에서는 11-15%로 붕괴된다. 이는 reasoning이 CoT와 최종 답변 사이의 불일치를 만든다는 인과적 증거이며, naive한 trace-anchored 방어는 오히려 역효과를 낸다.

**핵심 요약** (한국어):

## 4. Got a Secret? LLM Agents Can't Keep It: Evaluating Privacy in Multi-Agent Systems  🆕

- **PDF**: [arxiv.org/pdf/2605.27766](https://arxiv.org/pdf/2605.27766.pdf)

**핵심 요약** (한국어):
기존 LLM 안전성 평가는 모델을 단독으로 테스트하지만, 실제 에이전트는 소셜 환경에서 수많은 다른 에이전트와 상호작용한다. 수천 개의 LLM 에이전트가 한 달간 상호작용하는 Moltbook 스타일 시뮬레이션 플랫폼을 구축해 프라이버시 리스크를 평가했다. 싱글-턴에서 멀티-턴 소셜 평가로 전환 시 개인정보 침해율이 19.95% → 45.30%으로 급증하며, 다른 에이전트가 먼저 개인정보를 공개한 후 해당 에이전트도 민감한 정보를 공개할 가능성이 8배 증가한다. 명시적 프라이버시 지침도 누출을 완전히 방지하지 못해 37.8% 이상의 누출율이 유지된다.

- **키워드**: `activation steering`, `representation engineering`, `attention head`, `mechanistic interpretability`
- **출처**: arxiv recent
- **arxiv abstract**: [2605.21770](https://arxiv.org/abs/2605.21770) (v1)
- **PDF**: [arxiv.org/pdf/2605.21770](https://arxiv.org/pdf/2605.21770.pdf)

**핵심 요약** (한국어):
기존 활성화 조종(activation steering) 방법은 고정된 사전 계산 벡터를 적용해 생성 궤적상 현재 위치를 무시하는 문제가 있다. MAGS(Manifold-Guided Attention Steering)는 특정 어텐션 헤드의 출력 활성화가 오류 지점에서 저차원 정확성 매니폴드에서 이탈하는 기하학적 관찰에 기반한다. 각 어텐션 헤드마다 저차원 정확/오류 대비 쌍에서 서브스페이스를 학습하고, 추론 시 이탈 감지 시 표적 사영 보정을 적용한다. MATH-500, GSM8K, HumanEval, MBPP, 분자 생성(SMILES) 등 다양한 벤치마크에서 정적 steering 기반선을 능가한다.

- **출처**: arxiv recent

- **PDF**: [arxiv.org/pdf/2605.21492](https://arxiv.org/pdf/2605.21492.pdf)

**핵심 요약** (한국어):
특성들 간 공선성이 있을 때 어떤 feature ranking도 신뢰성(faithful), 안정성(stable), 완전성(complete)을 동시에 만족할 수 없음을 수학적으로 증명했다. 네 가지 모델 클래스에 대해 불가능성을 정량화하고, 앙상블 평균화(DASH)로 해결한다. 305개의 Lean 4 정리로 기계 검증되었으며, SHAP 기반 공정성 감사가 공선성 하에서 신뢰할 수 없음을 보여 AI 해석 가능성 방법론에 근본적 함의를 갖는다. 공개된 77개 데이터셋 조사에서 68%가 attribution 불안정성을 보였다.
