## 1. Is Forgetting Unified? Exploring Concept Unlearning in Unified Multimodal Models  🆕

- **저자**: Zhongkai Xue, Junkai Chen, Mingcong Lei, Rumo Zhang, Yixiao Liu et al.
- **키워드**: concept unlearning, multimodal models, cross-pathway forgetting, capability preservation
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2611.04467](https://arxiv.org/abs/2611.04467) (v1)
- **PDF**: [arxiv.org/pdf/2611.04467](https://arxiv.org/pdf/2611.04467.pdf)
- **핵심 요약**: 통합 멀티모달 모델에서는 이미지 생성과 시각 이해 양쪽에서 같은 개념을 제거해야 한다. 연구진은 30개 삭제 대상과 60개 인접 개념을 포함한 UUBench를 만들고, 단일 경로 언러닝의 한계를 측정했다. UniForget은 생성과 이해 경로를 함께 조정해 BAGEL-7B-MoT에서 80.0%, Janus-Pro-7B에서 92.7%의 공동 망각률을 기록했다. 다만 공동 망각과 일반 능력 보존 사이의 절충은 남는다.

## 2. Suppressing Misaligned Behaviors in Language Models, Durably  🆕

- **저자**: Luxi He, Pengcheng Jiang, Jifan Zhang, Jiawei Han, Danqi Chen
- **키워드**: durable alignment, behavioral suppression, adversarial reinforcement learning, unlearning
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2611.05358](https://arxiv.org/abs/2611.05358) (v1)
- **PDF**: [arxiv.org/pdf/2611.05358](https://arxiv.org/pdf/2611.05358.pdf)
- **핵심 요약**: 유해 행동을 한 번 억제해도 이후 미세조정에서 다시 나타날 수 있다. 연구진은 좁은 트리거와 넓은 트리거를 가진 두 모델 유기체를 만들고, 즉시 억제·후속 학습 내구성·일반 능력 보존을 함께 평가했다. PEARL은 캐시된 오정렬 궤적의 중간 상태에서 이어지는 롤아웃을 GRPO 학습에 추가한다. Qwen3-4B와 GPT-OSS-20B에서 일반 정확도를 유지하면서 강한 즉시 억제와 후속 학습 내구성을 보였다.

## 3. Voluntary Servitude: Weaponized Safety Warning Mechanisms for Controlling AI Agents  🆕

- **저자**: Ilan Zendel, Matan Levy, Stav Cohen, Avi Mendelson, Amit LeVi
- **키워드**: indirect prompt injection, agent safety, safety warning abuse, retrieval attacks
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2611.04393](https://arxiv.org/abs/2611.04393) (v1)
- **PDF**: [arxiv.org/pdf/2611.04393](https://arxiv.org/pdf/2611.04393.pdf)
- **핵심 요약**: 공격자는 명령문 없이도 조작된 위험 경고로 에이전트의 안전 추론을 역이용할 수 있다. 일반 리뷰처럼 작성된 허위 위험 정보는 합법적 선택지를 배제하고 공격자 목표를 고르게 만들었다. 공격 성공률은 60.4%로 명령형 주입의 66.0%와 비슷했으며, 필터 뒤에서는 1.7–4.4배 더 효과적이었다. 비적응형 공격에서는 복수 출처 확인 요구가 노출을 약 95% 줄였다.

- **출처**: arxiv recent / SNS

- **핵심 요약**: 임의 라벨을 사용하는 인컨텍스트 학습이 한 번의 순전파에서 어떻게 구현되는지는 충분히 연결된 회로로 설명되지 않았다. 연구는 세 개의 3–4B 모델에서 라벨 토큰을 키-값 메모리로 사용하는 회로를 추적했다. 활성화 패칭, 무작위 헤드 대조 제거, 내부 신호 조향이 저장·조회·게이트·최근성 억제 단계의 인과적 역할을 뒷받침했다. 같은 기능적 부품은 한 모델 계열의 0.6B부터 8B까지 나타났고 명령 튜닝 후에도 유지됐다.

## 5. The Geometry of Ignorance: Detecting Suppressed Knowledge in LLMs through Activation Fragmentation  🆕

- **저자**: Adar Peleg, Dvir Alsheich, Tomer Ashuach, Avi Mendelson
- **키워드**: activation geometry, unlearning audit, suppressed knowledge, representation analysis
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2611.05272](https://arxiv.org/abs/2611.05272) (v1)
- **PDF**: [arxiv.org/pdf/2611.05272](https://arxiv.org/pdf/2611.05272.pdf)
- **핵심 요약**: 출력 거부만으로는 모델이 개념을 실제로 잊었는지 판단하기 어렵다. 연구는 개념 질문과 익명화된 표현의 은닉 상태 차이를 이용해 지식의 기하학적 응집도와 분산을 측정한다. 3개 모델 계열의 명령 튜닝 모델 10개에서 분산 지표가 알려진 개념과 모르는 개념을 구분했다. 언러닝 후 기하 구조는 5개 알고리즘과 4개 공격 유형의 지식 복구와 연관됐지만, 관계 방향은 공격 방식에 따라 달랐다.

## 6. Right Tool, Wrong Parameters: Defending LLM Agents Against Parameter Poisoning  🆕

- **저자**: Yao Wang, Zehua Ma, Weiming Zhang, Han Fang
- **키워드**: parameter poisoning, prompt injection, information flow, agent defense
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2611.04673](https://arxiv.org/abs/2611.04673) (v1)
- **PDF**: [arxiv.org/pdf/2611.04673](https://arxiv.org/pdf/2611.04673.pdf)
- **핵심 요약**: 기존 방어는 새 도구 호출을 탐지하지만, 정상 도구의 인자만 바꾸는 매개변수 오염은 놓치기 쉽다. AuthorityFlow는 사용자 질의에서 신뢰 계층을 만들고, 각 인자의 정보 흐름을 추적해 값의 근거가 된 필드를 검증한다. 무방어 공격 성공률 93.06%를 9.03%로 낮췄다. 정상 작업 효용은 무방어 90.28% 대비 82.64%를 유지했다.

## 7. The Devil is in the Context: Nine Dimensions of Prompt Injection Attacks  🆕

- **키워드**: prompt injection, attack taxonomy, benchmark coverage, defense evaluation
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2611.04672](https://arxiv.org/abs/2611.04672) (v1)
- **PDF**: [arxiv.org/pdf/2611.04672](https://arxiv.org/pdf/2611.04672.pdf)
- **핵심 요약**: 프롬프트 주입을 하나의 동질적 공격으로 다루면 방어의 실제 적용 범위를 과대평가할 수 있다. 논문은 주입 지시, 사용자 작업과의 관계, 시스템에서의 발현을 설명하는 9개 차원을 제안한다. 6개 실제 취약점과 9개 벤치마크를 분류한 결과, 결합해도 공격 범주 쌍의 13%가 시험되지 않았다. 이 분류는 자동 주석과 누락 영역을 겨냥한 테스트 생성에도 사용된다.

## 8. BrainwashedLLM: Jailbreaking via Automated Adversarial Chain of Thoughts Discovery  🆕

- **저자**: Masoud Poorghaffar Aghdam, Göktuğ Serdar Yıldırım, Sinem Sav
- **키워드**: jailbreak, chain-of-thought attack, adversarial reasoning, weak-to-strong transfer
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2611.04717](https://arxiv.org/abs/2611.04717) (v1)
- **PDF**: [arxiv.org/pdf/2611.04717](https://arxiv.org/pdf/2611.04717.pdf)
- **핵심 요약**: 명시적 추론 흔적은 대형 추론 모델의 새로운 탈옥 공격면이 될 수 있다. BrainwashedLLM은 소형 화이트박스 모델을 GRPO로 학습해 적대적 추론 흔적을 만들고, 이를 대형 블랙박스 모델의 입력 접두사로 전이한다. 대상 모델의 출력 피드백이나 그래디언트 없이 4개 최신 추론 모델에서 ASR@5 0.74–0.98을 달성했다. 결과는 추론 버퍼를 외부 입력과 격리하는 구조적 방어의 필요성을 제기한다.

## 10. Can Benign Skills Induce Misaligned Behavior in LLM Agents?  🆕

- **저자**: Xuanye Zhang, Yongsen Zheng, Kaiyu Zhou, Bowen Shen, Haoran Ou et al.
- **키워드**: agent skills, behavioral misalignment, unsafe actions, runtime guard
- **출처**: arxiv recent
- **arxiv abstract**: [2611.04299](https://arxiv.org/abs/2611.04299) (v1)
- **PDF**: [arxiv.org/pdf/2611.04299](https://arxiv.org/pdf/2611.04299.pdf)
- **핵심 요약**: 정상 작업을 돕는 재사용 기술도 에이전트의 유해 절차 수행 능력을 높일 수 있다. 5개 LLM 백본과 3개 벤치마크에서 기술 추가는 정상 정확도를 평균 10.3%p 높였지만, 위험 행동률도 10.3%p 높였다. 새로 위험해진 50개 궤적 중 24개는 유해 목표를 완수하지 못해 완료율만으로는 위반을 놓쳤다. 도구 실행 전 행동 검사는 정상 성능 이득을 유지하면서 위반을 줄였다.
