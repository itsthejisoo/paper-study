## 1. Training Trajectories Determine Circuit Removability in Annealable Soft-Prior Transformers  🆕
- **저자**: Zonglin Yang, Ziming Zhao, Wei Tang, Xunyu Jiang, Yihong Liu et al.
- **키워드**: mechanistic interpretability, circuit analysis, attention heads, causal ablation
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.10287](https://arxiv.org/abs/2609.10287) (v1)
- **PDF**: [arxiv.org/pdf/2609.10287](https://arxiv.org/pdf/2609.10287.pdf)
- **핵심 요약**: 위치 prior를 제거한 뒤에도 Transformer 내부 회로가 유지되는지는 학습 경로에 따라 달라질 수 있다. 연구는 prior gate를 활성 상태, 즉시 제거, 점진적 감소로 나눠 회로 형성을 비교한다. 활성 prior의 정확도는 0.772±0.020이었고, 즉시 제거는 0.095±0.009까지 붕괴했지만 점진적 감소는 0.734±0.028을 유지했다. Gate가 0이 된 뒤에도 회로가 공고화됐으며, 핵심 attention head는 seed별로 달라 학습 궤적 자체가 해석 대상임을 보인다.

## 2. Maverick: Private and Verifiable LLM Inference Made Practical via Matrix-Vector Multiplication Delegation  🆕
- **저자**: Ben Merbaum, Mohammad Amin Raeisi, Wenhao Wang, Charalampos Papamanthou, Katerina Sotiraki et al.
- **키워드**: private inference, verifiable computation, model privacy, LPN masking
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.10264](https://arxiv.org/abs/2609.10264) (v1)
- **PDF**: [arxiv.org/pdf/2609.10264](https://arxiv.org/pdf/2609.10264.pdf)
- **핵심 요약**: 원격 LLM 추론은 사용자 입력과 모델 가중치를 숨기면서 서버 계산의 정확성도 검증해야 한다. Maverick은 추론의 핵심인 matrix-vector multiplication을 위임하고 LPN 기반 masking과 검증 절차를 결합한다. Qwen3-4B에서 클라이언트 thread 수를 1개에서 8개까지 바꿔 실제 비용을 측정했다. 단일 thread 기준 기존 방식보다 online 17배, precomputed 45배, verification-only 44배 빠른 결과를 보고한다.

- **저자**: Jing Guan, Yachao Yang, Zhaoliang Liu, Yuyao Zhang, Fanyu Meng et al.
- **키워드**: adversarial fine-tuning, representation engineering, alignment attacks, preventative steering
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.10142](https://arxiv.org/abs/2609.10142) (v1)
- **PDF**: [arxiv.org/pdf/2609.10142](https://arxiv.org/pdf/2609.10142.pdf)
- **핵심 요약**: 예방적 steering이 악성 fine-tuning을 막는 이유가 고정된 안전 방향 때문인지, 학습 중 적응 때문인지는 불분명했다. 연구는 시간대별 표현 변화를 추적하고 IDP와 IDP Continuation으로 보호 offset을 보존하거나 재주입한다. 고정 offset만 유지하면 방어가 실패해, 초기 단계의 보상적 적응이 핵심임을 보였다. 이 관찰을 반영한 PIS는 Qwen2.5와 Gemma-3에서 안전성을 개선하며 정적 방어 관점을 수정한다.

- **핵심 요약**: On-device LLM의 가중치 변환과 분할 실행은 널리 쓰이지만, 보호 경계가 휴리스틱하게 정의돼 있었다. 연구는 기존 난독화를 형식적 primitive와 표준 조합 O_prior로 정리한다. Collapse attack은 ArrowCloak, TSQP, LoRO가 공유하는 구조적 취약점을 이용해 세 방식을 모두 무너뜨린다. 저자들은 공격으로 드러난 경계를 바탕으로 두 primitive를 추가한 O_ext를 제안한다.

## 5. Privacy-Preserving Split Learning for Federated LLM Fine-Tuning  🆕

- **키워드**: federated learning privacy, split learning, activation leakage, LLM fine-tuning
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.09794](https://arxiv.org/abs/2609.09794) (v1)
- **PDF**: [arxiv.org/pdf/2609.09794](https://arxiv.org/pdf/2609.09794.pdf)
- **핵심 요약**: Federated split learning은 원문을 보내지 않지만, 중간 activation에서 autoregressive 입력이 복원될 수 있다. 연구는 클라이언트 표현을 난독화하고 서버 계산 뒤 필요한 신호를 복구하는 학습형 구조를 제안한다. 공격자가 관측하는 activation과 실제 입력 사이의 직접 대응을 약화하면서 fine-tuning 목적은 유지한다. 실험은 제한적인 utility 손실과 통신·연산 부담으로 데이터 보호가 가능하다고 보고한다.

## 6. Cascading Gradient Inversion via LT-Code Inspired Peeling in Federated Learning  🆕

- **키워드**: gradient inversion, federated learning privacy, data extraction, coding theory
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.09659](https://arxiv.org/abs/2609.09659) (v1)
- **PDF**: [arxiv.org/pdf/2609.09659](https://arxiv.org/pdf/2609.09659.pdf)
- **핵심 요약**: Federated learning의 집계 gradient는 큰 batch에서도 개별 학습 데이터를 노출할 수 있다. 연구는 gradient 혼합을 erasure code로 보고, LT-code의 peeling decoder처럼 복원된 표본을 연쇄적으로 제거한다. 단일 FedSGD round에서 batch와 label을 정확히 복원하는 수동·능동 공격을 설계했다. ImageNet에서 수동 공격은 batch 128까지 94~100%, 능동 공격은 수백 규모에서도 90% 초과 복원률을 보였다.

## 8. Benchmark Scores Are Pipeline-Dependent: A Reliability Audit of Cybersecurity LLM Benchmarks  🆕

## 9. MemSentry: A Framework for Detecting Persistent Memory Poisoning in Agentic AI  🆕
- **저자**: Ayan Roy, Kaustuvi Basu
- **키워드**: memory poisoning, agent safety, persistent attacks, risk classification
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.08747](https://arxiv.org/abs/2609.08747) (v1)
- **PDF**: [arxiv.org/pdf/2609.08747](https://arxiv.org/pdf/2609.08747.pdf)
- **핵심 요약**: 장기 기억을 쓰는 agent는 한 번 주입된 악성 정보가 이후 의사결정에 반복적으로 영향을 줄 수 있다. MemSentry는 자산 DAG와 접근 행렬, 위험 특징을 사용해 쓰기 요청을 Accept, Review, Quarantine으로 분류한다. 연구는 20개 자산과 10×20 접근 행렬에서 GPT-4가 만든 1,000개 scenario를 70/30으로 평가했다. SBERT와 logistic regression 조합은 정확도 91.7%, macro-F1 0.908을 기록했고 외부 quarantine 위협은 모든 방법이 100% 탐지했다.

## 10. In RAG We Trust? Measuring Robustness of Retrieval-Augmented Generation Under Document Poisoning  🆕
- **저자**: Iliano Fasolino
- **키워드**: RAG poisoning, document poisoning, adversarial attacks, robustness evaluation
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.09243](https://arxiv.org/abs/2609.09243) (v1)
- **PDF**: [arxiv.org/pdf/2609.09243](https://arxiv.org/pdf/2609.09243.pdf)
- **핵심 요약**: RAG system은 검색 문서가 오염되면 근거가 있는 듯한 잘못된 답을 생성할 수 있다. 연구는 Llama 3.1 8B에 세 가지 문서 변조와 0~3개 poisoned passage를 조합해 588회 실행했다. 정확도는 clean 조건의 77.9%에서 세 문서가 모두 오염된 조건의 43.5%로 하락했다. 오류는 주로 답변 회피로 나타났으며, 소규모 설정과 거친 자동 label이라는 한계도 함께 명시했다.
