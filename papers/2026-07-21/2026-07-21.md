## 1. Prismata: Confining Cross-Site Prompt Injection in Web Agents 🆕

- **저자**: Corban Villa, Alp Eren Ozdarendeli, Sijun Tan, Raluca Ada Popa (UC Berkeley)
- **키워드**: `prompt injection`, `web agent`, `agent security`, `contextual integrity`, `least privilege`
- **출처**: SNS (Hacker News, Help Net Security)
- **arxiv abstract**: [2607.08147](https://arxiv.org/abs/2607.08147) (v1)
- **PDF**: [arxiv.org/pdf/2607.08147](https://arxiv.org/pdf/2607.08147.pdf)

**핵심 요약** (3-5문장):
웹 에이전트가 확산되면서 기존 XSS(Cross-Site Scripting) 공격과 유사하게, 제3자 웹 콘텐츠가 에이전트의 자연어 명령으로 해석되어 prompt injection 공격이 발생하는 구조적 취약점이 존재한다. Prismata는 "contextual least privilege" 원칙을 적용하여 웹 페이지 콘텐츠에 신뢰 레이블을 부여하고, 구조적 무결성 모델에서 영감을 받은 confinement 기법으로 에이전트가 보는 내용과 수행할 수 있는 행동을 동시에 제한한다. 핵심적으로 개발자 어노테이션 없이도 동작하며, 최근 발표된 웹 에이전트 공격(적응형 변종 포함)에서 공격 성공률을 유의미하게 낮추면서도 정상 태스크 유틸리티를 유지하는 것을 실험적으로 보였다.

**핵심 요약** (3-5문장):
커뮤니티 학습(연합 학습/협업 학습) 환경에서 백도어 공격이 시간이 지남에 따라 클린 업데이트에 의해 흡수·희석되는 현상, 즉 "backdoor absorption"을 분석한다. 이 논문은 백도어가 단순히 제거되는 것이 아니라 커뮤니티 학습의 집계 과정에서 구조적으로 흡수되는 메커니즘을 규명하며, 이것이 기존 백도어 방어 연구의 해석을 어떻게 바꿀 수 있는지 논의한다. CEA-LIST의 테크니컬 리포트로, 그래프 5개·테이블 2개를 포함한 15페이지 분량의 실증 분석을 제공한다.

- **출처**: arxiv recent (cs.SE, cs.CR, cs.LG)
- **arxiv abstract**: [2607.07881](https://arxiv.org/abs/2607.07881) (v1)
- **PDF**: [arxiv.org/pdf/2607.07881](https://arxiv.org/pdf/2607.07881.pdf)

**핵심 요약** (3-5문장):
LLM 코드 생성 모델은 기능성과 보안을 동시에 만족하는 코드 생성에 어려움을 겪으며, 기존 접근법은 둘 중 하나를 별도로 평가하는 경우가 많다. 이 논문은 task-vector arithmetic(LLM 가중치에 대한 선형 연산)을 활용하는 SecVecCoder를 제안하여, 추가적인 post-generation 검사 없이 기능적으로 올바르면서 동시에 보안 취약점이 없는 코드를 생성한다. 모델 가중치 편집이 보안 정렬에 최소한의 오버헤드만 추가하면서도 유의미한 성능 향상을 달성할 수 있음을 실험적으로 입증한다.

- **PDF**: [arxiv.org/pdf/2607.14434](https://arxiv.org/pdf/2607.14434.pdf)

**핵심 요약** (3-5문장):
AI 기반 악성코드 분석 샌드박스에서 실제 AI 실행 환경과 샌드박스 시뮬레이션 환경 간의 "realism gap"을 체계적으로 측정한다. 악성코드가 샌드박스 탐지를 회피하기 위해 AI 환경의 비현실적 특성을 활용할 수 있음을 보이며, 이 격차가 얼마나 크고 어떤 요소에서 두드러지는지를 분석한다. AI 보안 도구 자체가 adversarial evasion의 표적이 될 수 있다는 점에서, 보안 분석 인프라의 신뢰성에 대한 중요한 문제를 제기한다.
