## 1. AgentLens: Interpretable Safety Steering via Mechanistic Subspaces for Multi-Turn Coding Agent 🆕

- **저자**: Weidi Luo, Qiming Zhang, Yihao Quan, Mingyu Jin, Jie Cai, Chaowei Xiao et al.
- **키워드**: `mechanistic interpretability`, `agent safety`, `representation steering`, `coding agent`, `probing`
- **출처**: SNS (web search)
- **arxiv abstract**: [2606.22673](https://arxiv.org/abs/2606.22673) (v1)
- **PDF**: [arxiv.org/pdf/2606.22673](https://arxiv.org/pdf/2606.22673.pdf)

**핵심 요약** (3-5문장 한국어):
기존 LLM 안전 메커니즘은 단일 턴 또는 정적 입력을 전제로 설계되어, 멀티턴 코딩 에이전트의 동적 위험을 다루지 못한다. 이 논문은 AgentLens를 제안하는데, 에이전트 실행 중 매 스텝의 내부 hidden 표현에서 linear probe로 위험 상태를 감지하고, 동일 probe에서 도출한 10차원 subspace에 representation-level steering을 가하는 white-box 방어 프레임워크다. LLaMA-3.1-8B, Qwen-2.5-7B, Gemma-2-9B에서 평균 현재 스텝 위험 감지 정확도 97.32%, 사전 예측(lookahead) 정확도 최대 96.77%, 공격 성공률 72.63% 감소를 달성했다. 194개 태스크를 포함하는 MAS(Mechanistic Agent Safety) 벤치마크도 함께 공개하여 재현 가능한 연구 기반을 제공한다.

## 3. Jailbreaking the Matrix: Nullspace Steering for Controlled Model Subversion 🆕

- **저자**: Vishal Pramanik, Susmit Jha, Maisha Maliha, Sumit Kumar Jha
- **키워드**: `jailbreak`, `nullspace steering`, `mechanistic interpretability`, `attention head`, `adversarial attack`
- **출처**: SNS (web search)
- **arxiv abstract**: [2604.10326](https://arxiv.org/abs/2604.10326) (v1)
- **PDF**: [arxiv.org/pdf/2604.10326](https://arxiv.org/pdf/2604.10326.pdf)

**핵심 요약** (3-5문장 한국어):
기존 jailbreak은 프롬프트 수준의 조작에 그쳐 방어에 취약하고 내부 메커니즘 이해가 없다. 이 논문은 HMNS(Head-Masked Nullspace Steering)를 제안하는데, 인과적으로 영향력 있는 attention head를 식별하고 그 write path를 masking한 뒤, muted subspace의 직교 보완 공간에 perturbation을 주입하는 회로 수준 개입이다. AdvBench, HarmBench, JBB-Behaviors, StrongReject 4개 벤치마크에서 SOTA 공격 성공률을 적은 쿼리 수로 달성하며, 기하학적으로 방어를 회피하는 첫 번째 interpretability 기반 jailbreak으로 소개된다.

## 4. Sparse Autoencoders are Capable LLM Jailbreak Mitigators 🆕

- **저자**: Yannick Assogba, Jacopo Cortellazzi, Javier Abad, Pau Rodriguez, Xavier Suau, Arno Blaas
- **키워드**: `sparse autoencoder`, `jailbreak defense`, `activation steering`, `SAE`, `CC-Delta`
- **출처**: SNS (web search), ICML
- **arxiv abstract**: [2602.12418](https://arxiv.org/abs/2602.12418) (v1)
- **PDF**: [arxiv.org/pdf/2602.12418](https://arxiv.org/pdf/2602.12418.pdf)

**핵심 요약** (3-5문장 한국어):
SAE를 해석 가능성 연구용이 아닌 jailbreak 방어 도구로 재활용하는 접근법을 제안한다. CC-Delta(Context-Conditioned Delta Steering)는 동일한 유해 요청에 jailbreak 컨텍스트가 있을 때와 없을 때의 토큰 수준 표현 차이를 통계적으로 비교하여 jailbreak 관련 sparse feature를 선별하고, SAE latent space에서 mean-shift steering을 적용한다. 4개 정렬 모델, 12개 jailbreak 공격에서 기존 dense latent space 방어보다 동등하거나 우수한 안전성-유용성 트레이드오프를 달성하며, 특히 out-of-distribution 공격에 강하다.

## 5. Knowing without Acting: The Disentangled Geometry of Safety Mechanisms in Large Language Models 🆕

- **저자**: Jinman Wu, Yi Xie, Shen Lin, Shiqian Zhao, Xiaofeng Chen
- **키워드**: `mechanistic interpretability`, `safety alignment`, `jailbreak`, `representation engineering`, `refusal`
- **출처**: SNS (web search), ICML
- **arxiv abstract**: [2603.05773](https://arxiv.org/abs/2603.05773) (v2)
- **PDF**: [arxiv.org/pdf/2603.05773](https://arxiv.org/pdf/2603.05773.pdf)

**핵심 요약** (3-5문장 한국어):
LLM의 안전 정렬이 단일 과정이 아니라 "인식(Knowing)"과 "실행(Acting)"이라는 두 독립적인 subspace로 분리된다는 Disentangled Safety Hypothesis(DSH)를 제안한다. 분석 결과, 초기 레이어에서는 두 축이 대립적으로 얽혀 있다가 깊은 레이어에서 구조적으로 분리되는 "Reflex-to-Dissociation" 진화 패턴이 Llama, Mistral, Qwen 전반에 걸쳐 보편적으로 나타난다. 이 분리를 활용한 Refusal Erasure Attack(REA)은 refusal 메커니즘만 외과적으로 제거하여 SOTA 공격 성공률을 달성하며, AmbiguityBench와 함께 jailbreak 취약성의 기하학적 근본 원인을 제시한다.

**핵심 요약** (3-5문장 한국어):
공격자가 학습 데이터 일부를 포이즈닝하여 자신이 접근할 수 없는 별도의 타겟 레코드를 추출하는 LLP(Loss Landscape Poisoning) 공격을 제안한다. 핵심 아이디어는 타겟 completion 주변의 loss landscape를 sharp minimum으로 만들어 모델이 해당 데이터를 유일한 저손실 해로 기억하도록 강제하는 것으로, 구조 변경 없이 중앙집중·연합학습 환경 모두에 적용된다. LLM에서 최대 100%, VLM에서 최대 90%의 추출 성공률을 달성했으며, differential privacy 방어조차 우회하는 DLRP primitive를 추가로 제시한다.

## 8. Agents That Know Too Much: A Data-Centric Survey of Privacy in LLM Agents 🆕

- **저자**: Nada Lahjouji, Ashwin Gerard Colaco
- **키워드**: `AI privacy`, `LLM agents`, `data leakage`, `access control`, `information flow control`
- **출처**: SNS (web search)
- **arxiv abstract**: [2606.26627](https://arxiv.org/abs/2606.26627) (v1)
- **PDF**: [arxiv.org/pdf/2606.26627](https://arxiv.org/pdf/2606.26627.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 에이전트가 데이터베이스, 문서, API, 에이전트 메모리 등 다양한 데이터 소스를 다루면서 발생하는 프라이버시 위험을 data-centric 관점에서 체계적으로 정리한 서베이다. 공격 유형이 아닌 에이전트가 접촉하는 데이터(text-to-SQL, RAG 인덱스, 에이전트 메모리, 프롬프트 인젝션 등)를 기준으로 분류 체계를 구성하며, 데이터 관리 분야와 에이전트 보안 분야의 분산된 연구를 통합한다. 핵심 발견: information-flow control만이 compositional leakage와 cross-session inference leakage 두 가지를 모두 커버하는 유일한 거버넌스 메커니즘이며, 하나의 프라이버시 정책 하에서 에이전트를 종단간 평가하는 벤치마크가 아직 없다는 공백을 지적한다.

## 10. SPORE: Efficient and Training-Free Privacy Extraction Attack on LLMs via Inference-Time Hybrid Probing 🆕

- **저자**: Yu Cui, Ruiqing Yue, Hang Fu, Sicheng Pan, Zhuoyu Sun, Baohan Huang, Haibin Zhang, Cong Zuo, Licheng Wang
- **키워드**: `privacy extraction`, `LLM agent memory`, `black-box attack`, `inference-time`, `PII`
- **출처**: arxiv recent (cs.CR)
- **arxiv abstract**: [2604.23711](https://arxiv.org/abs/2604.23711) (v1)
- **PDF**: [arxiv.org/pdf/2604.23711](https://arxiv.org/pdf/2604.23711.pdf)

**핵심 요약** (3-5문장 한국어):
기존 LLM 프라이버시 공격이 학습 데이터를 타겟으로 하는 반면, SPORE는 실행 시점 LLM 에이전트 메모리의 컨텍스트 프라이버시 위험을 다루는 training-free 공격이다. 블랙박스 설정에서 단 1회 쿼리로 소수의 후보 집합을 추출하고, 그레이박스 설정에서는 multi-ranked 토큰을 활용해 더 정확한 추출이 가능하다. 정보이론적 분석을 통해 쿼리당 정보 누출량이 크고 쿼리 효율이 높음을 증명하며, OpenClaw와 같은 개인 AI 어시스턴트에서 실용적인 위협이 됨을 실험으로 입증한다.
