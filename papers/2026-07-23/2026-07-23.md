## 1. Data-Efficient Adaptation of LLMs via Attention Head Reweighting

**arXiv:** [2607.13425](https://arxiv.org/abs/2607.13425) | **카테고리:** LLM 해석가능성 | **발표:** COLM 2026 | **기관:** Microsoft Research

**문제정의**  
LLM을 새로운 텍스트 분류 태스크에 적응시키려면 통상 LoRA 등 수백만 파라미터 조정이 필요하다. 특히 레이블 데이터가 극도로 제한된 환경(수십~수백 개)에서 파라미터 효율적이면서도 해석 가능한 적응이 가능한가?

**해결방법(제안 기법)**  
Attention Head Reweighting(AHR): 모델 내 각 Attention Head마다 학습 가능한 스칼라 가중치 하나씩만 추가한다. 전체 학습 파라미터 수는 Attention Head 개수와 동일하며, 나머지 모델 가중치는 완전 고정한다. 레이블 데이터 수십~수백 개로 이 스칼라 벡터만 학습하여 태스크별로 관련 Head를 강조하거나 억제한다.

**결과 및 장점**  
- LoRA 대비 파라미터 수 200~1,000배 적음에도 제한 샘플 환경에서 LoRA를 능가  
- 학습된 Head 가중치가 직접 해석 가능: in-context learning에 기여하는 Attention Head 식별  
- COLM 2026 채택, Microsoft Research 주도

**단점 및 한계점**  
- 텍스트 분류 태스크에 특화; 생성 태스크나 다른 NLP 태스크로의 일반화 검증 미흡  
- Attention Head 수에 묶인 구조적 제약으로 매우 복잡한 적응에는 표현력 한계 가능  
- 해석가능성 분석이 주로 정성적 수준에 머무름

**핵심기술**  
Attention Head별 학습 가능 스칼라 가중치, 파라미터 효율적 fine-tuning (PEFT), 기계적 해석가능성(mechanistic interpretability), in-context learning 회로 분석

## 2. Logical Judgments Under Pressure: Diagnosing Syllogistic Stability with Learned Soft Prefixes

**arXiv:** [2607.18228](https://arxiv.org/abs/2607.18228) | **카테고리:** LLM 해석가능성 (probing) | **기관:** National University of Singapore | **등록:** 2026-07-20 (최근)

**문제정의**  
LLM이 삼단논법 추론 태스크에서 정확한 논리적 판단을 내리더라도, 입력 컨텍스트(소프트 프리픽스) 변화에 대해 얼마나 안정적인가? 정확도(accuracy)와 견고성(robustness)을 분리하여 모델의 논리적 안정성을 진단할 필요가 있다.

**해결방법(제안 기법)**  
정밀하게 레이블된 삼단논법 추론 벤치마크 앞에 학습된 소프트 프리픽스(soft prefix, 연속 벡터 시퀀스)를 붙이고 모델 파라미터는 고정한다. 프리픽스를 스트레스 테스트로 활용해 올바른 답을 뒤집는 데 성공하는 프리픽스를 분류한다. Activation patching 등 해석가능성 기법으로 내부 메커니즘을 추가 분석한다.

**결과 및 장점**  
- 실험 모델: Qwen3.6-35B-A3B MoE, Qwen3-8B, Gemma 4 31B  
- 학습된 프리픽스가 paired random 프리픽스 대비 16개 model-direction-split 비교 전부에서 37~99 퍼센트 포인트 우세  
- Qwen3.6 MoE: 올바른 답의 72~90%를 반대 답으로 전환; Gemma: 54~56% 전환 (random 프리픽스: <1%)  
- 성공적 프리픽스의 지배적 효과는 논리 연산 전이가 아닌 광범위한 답 편향(broad answer preference)으로 확인

**단점 및 한계점**  
- 삼단논법 추론에 한정; 다른 추론 유형(수학, 상식 등)으로의 전이 가능성 불명확  
- 소프트 프리픽스 자체가 불투명(opaque)하여 내용 해석 불가  
- 단일 연구자 연구로 실험 규모 제한적

**핵심기술**  
소프트 프리픽스(soft prefix / continuous prefix tuning), probing, activation patching, 삼단논법 추론 안정성 진단, 스트레스 테스트

## 3. MolSafeEval: A Benchmark for Uncovering Safety Risks in AI-Generated Molecules

**arXiv:** [2607.00464](https://arxiv.org/abs/2607.00464) | **카테고리:** AI 안전성 | **발표:** ACL Findings 2026 | **기관:** Zhejiang University, Oxford

**문제정의**  
AI 분자 생성 모델의 기존 벤치마크는 태스크 복잡도·분자 참신성·속성 정렬에 집중하지만, 생성된 분자의 잠재적 안전 위험(독성, 반응성, 위험성)은 체계적으로 평가하지 않는다. 안전하지 않은 분자가 생성되더라도 탐지·경고 메커니즘이 부재하다.

**해결방법(제안 기법)**  
MolSafeEval은 독성 데이터베이스·위험 규칙 등 이종 안전 지식을 구조화된 분자 안전 지식 그래프(MolSafeKG)로 통합하고, LLM 기반 추론으로 생성 분자의 위험 특성을 탐지·설명한다. 비조건부 생성, 속성 최적화, 목표 단백질 기반 설계, 텍스트 기반 생성 등 4가지 대표 태스크 유형에 걸쳐 표준화된 안전 평가 프로토콜을 제공한다.

**결과 및 장점**  
- 4가지 분자 생성 태스크 유형에 대한 안전성 평가 프로토콜 최초 제시  
- 기존 독성 예측기보다 넓은 범위의 안전 속성(drug toxicity + GHS hazard)을 통합 평가  
- 현재 생성 모델들이 높은 비율로 잠재적 위험 분자를 생성함을 실증  
- ACL Findings 2026 채택

**단점 및 한계점**  
- 분자 생성 도메인 특화 프레임워크; 일반 LLM 안전성과 직접 연결되지 않음  
- 지식 그래프의 불완전성이 평가 신뢰도에 영향  
- LLM 기반 스코어링의 체계적 편향(systematic bias) 가능성 존재

**핵심기술**  
분자 안전 지식 그래프(MolSafeKG), KG 검색 기반 위험 유사체 탐지, LLM 기반 안전성 추론 및 설명, 분자 생성 벤치마크

## 4. Innocuous-Seeming Data, Latent Ideology: Ideological Generalisation in Finetuned LLMs

**arXiv:** [2607.14888](https://arxiv.org/abs/2607.14888) | **카테고리:** AI 보안 (alignment 공격)

**문제정의**  
LLM을 좁은 도메인 데이터로 파인튜닝할 때, 해당 데이터가 명시적으로 정치적이지 않고 컨텐츠 모더레이션을 통과하더라도 무관한 도메인까지 광범위한 이념적 편향을 초래할 수 있는가? 이 "이념적 일반화(ideological generalisation)" 현상의 실재를 검증한다.

**해결방법(제안 기법)**  
GPT-4.1을 좌편향 또는 우편향 경제 Q&A 데이터셋으로 파인튜닝한 후, 형사 사법·환경·문화적 취향 등 경제와 완전히 무관한 도메인에서의 이념적 일관성 변화를 측정한다. 파인튜닝 도메인(경제)에서 학습된 이념 방향이 다른 도메인으로 어떻게 전이되는지 분석한다.

**결과 및 장점**  
- 경제 Q&A 파인튜닝에서 습득된 이념 편향이 형사 사법·환경·문화 취향 도메인으로 일관되게 전이  
- 우/좌편향 파인튜닝이 대응하는 방향의 이념 편향을 모든 평가 도메인에서 일으킴  
- 컨텐츠 모더레이션 통과 데이터로도 은밀한 이념적 조작이 가능함을 실증

**단점 및 한계점**  
- GPT-4.1 단일 모델 실험; 다른 모델군 일반화 필요  
- 이념 측정 지표 자체의 타당성 한계 (이념 Q&A 벤치마크의 구성 방식에 의존)  
- 의도적 공격과 비의도적 편향의 경계 불명확

**핵심기술**  
파인튜닝을 통한 이념 주입, 크로스-도메인 이념 전이 측정, alignment 공격, 지식 일반화 메커니즘

## 5. 🔄 Updated: (A)I Sees What You Don't: Exploiting New Attack Surfaces in Third-Party Mobile Agents

**arXiv:** [2607.00333](https://arxiv.org/abs/2607.00333) **(v1 → v2)** | **카테고리:** AI 보안 (에이전트 보안) | **업데이트:** v2

**문제정의**  
모바일 AI 에이전트는 사용자가 인지하지 못하는 시각적 정보(숨겨진 UI 요소, 겹쳐진 레이어, 투명 요소 등)에 접근할 수 있다. 이 AI-사용자 간 정보 비대칭성이 어떤 새로운 공격면(attack surface)을 만들어내는가?

**해결방법(제안 기법)**  
제3자 모바일 에이전트에서 AI가 "볼 수 있지만 사용자는 볼 수 없는" 정보를 활용한 공격 시나리오를 체계적으로 분류하고 실증한다. 시각적 공격 표면 분류 체계를 제시하며, v2에서 분석 범위를 확장하고 실험적 검증을 보완했다.

**결과 및 장점**  
- 모바일 AI 에이전트의 새로운 공격 표면 체계적 분류 및 실증  
- 기존 보안 모델이 간과한 AI-사용자 시각 정보 비대칭 문제를 명시화  
- v2로 분석 및 실험 보완

**단점 및 한계점**  
- v2 업데이트 세부 내용 미확인 (abstract HTML 접근 불가)  
- 특정 모바일 에이전트 구현에 의존하는 공격 시나리오 가능성  
- 방어 기법 제시가 제한적

**핵심기술**  
모바일 AI 에이전트 보안 분석, 시각적 공격 표면 분류, 에이전트 안전성(agent safety), UI 취약점

## 6. Generative AI and Federated Learning for Intrusion Detection Systems: A Survey

**arXiv:** [2607.01305](https://arxiv.org/abs/2607.01305) | **카테고리:** AI 보안/프라이버시 (서베이) | **기관:** NMSU 외

**문제정의**  
침입 탐지 시스템(IDS)은 레이블 데이터 부족, 데이터 이질성(heterogeneity), 프라이버시 보호 제약이라는 세 가지 핵심 한계를 안고 있다. 생성형 AI(GenAI)와 연합학습(FL)이 이를 어떻게 해결할 수 있는가?

**해결방법(제안 기법)**  
IDS 분야에서 GenAI(GAN, VAE, LLM 기반 데이터 증강·탐지)와 FL(분산 학습, 프라이버시 보존 집계)을 적용한 기존 연구들을 체계적으로 분류·비교한다. 두 기술 영역의 통합 적용 가능성과 미래 연구 방향을 정리한 서베이.

**결과 및 장점**  
- GenAI+FL 기반 IDS 연구의 포괄적 분류 체계 제공  
- 두 기술 영역 결합 시 시너지 방향 및 미래 연구 로드맵 제시  
- cs.CR, cs.AI, cs.LG 교차 분야 통합 시각

**단점 및 한계점**  
- 서베이 논문으로 원본 연구 기여(novel contribution) 없음  
- IDS 도메인 특화; LLM 보안·프라이버시 주요 문제와의 직접 연관이 간접적  
- 상위 학회 채택 여부 미확인

**핵심기술**  
생성형 AI(GAN/VAE/LLM 기반 생성), 연합학습(FL), 침입 탐지 시스템(IDS), 프라이버시 보존 학습, 데이터 증강

## 7. SemiScope: Disentangling Classifier Tuning and Joint Optimization in Semi-Supervised Security Classification

**arXiv:** [2607.00113](https://arxiv.org/abs/2607.00113) | **카테고리:** AI 보안 (보안 분류) | **기관:** NC State University, ShanghaiTech

**문제정의**  
보안 분류에서 레이블 데이터 희소 문제를 해결하기 위해 반지도 학습(SSL)을 쓰지만, 보고된 성능 향상이 SSL 자체에서 오는 것인지 다운스트림 분류기 튜닝에서 오는 것인지 명확하지 않다. 이를 분리하여 실제 기여분을 정량화할 필요가 있다.

**해결방법(제안 기법)**  
SemiScope: Bayesian Optimization으로 SSL 설정·신뢰도 필터링·오버샘플링·분류기 패밀리·하이퍼파라미터를 공동 탐색. 핵심 제어변수 Tuned-Clf는 SSL을 기본값 고정, 동일 100-trial 예산을 분류기 탐색에만 사용하여 SSL 기여분을 분리한다. 이진 테이블형 보안 분류 5개 데이터셋에서 평가, ±1.0 g-measure를 TOST로 검증.

**결과 및 장점**  
- SemiScope가 모든 기본 SSL 베이스라인 대비 0.7~12.7 g-measure 포인트 향상  
- 그러나 Tuned-Clf와 비교 시 차이가 통계적으로 불명확 → SSL 상호작용보다 분류기 튜닝이 주된 성능 원천임을 시사  
- 실무적 교훈: SSL 파이프라인보다 분류기 튜닝에 먼저 투자하는 게 효율적

**단점 및 한계점**  
- 주요 발견이 "SSL보다 분류기 튜닝이 중요하다"는 소극적 결론  
- 이진 테이블형 데이터(네트워크 트래픽·로그)에 국한  
- AI 보안 주요 토픽(adversarial attack, jailbreak, MIA 등)과 직접 연관성 낮음

**핵심기술**  
반지도 학습(SSL), Bayesian Optimization, 분류기 하이퍼파라미터 탐색, g-measure, 보안 분류

## 8. TallyTrain: Communication-Efficient Federated Distillation via Hard-Label Consensus

**arXiv:** [2607.00173](https://arxiv.org/abs/2607.00173) | **카테고리:** AI 프라이버시 (연합 증류 통신 효율) | **기관:** Cisco

**문제정의**  
연합 지식 증류(federated distillation)에서 클라이언트들은 소프트 확률 벡터를 교환하여 지식을 전달하는데, 이 통신 비용이 높다. 모델 파라미터 공유 없이 통신량을 줄이면서 효과적인 지식 전달이 가능한가?

**해결방법(제안 기법)**  
TallyTrain: 각 클라이언트가 소프트 확률 전체 대신 hard-label(arg max 인덱스만)을 서버에 전송하여 합의(tally)를 형성한다. 정수 하나만 전송하므로 통신량이 class 수와 무관하게 일정해진다.

**결과 및 장점**  
- 통신량 대폭 감소: 소프트 확률 벡터 대신 단일 정수 전송  
- 모델 파라미터 미공유 → 파라미터 수준 프라이버시 보존  
- Cisco 연구로 산업 적용 관점 반영

**단점 및 한계점**  
- Hard-label만 사용 시 소프트 레이블 대비 정보 손실; 정확도 저하 가능  
- FL 프라이버시의 핵심 위협(membership inference, gradient inversion)과 직접 대응 관계 없음  
- 이번 리스트에서 토픽 필터 부합도가 가장 낮음 (통신 효율 중심 연구)

**핵심기술**  
연합 지식 증류(federated distillation), Hard-label consensus, 통신 효율화, 파라미터-프리 연합학습
