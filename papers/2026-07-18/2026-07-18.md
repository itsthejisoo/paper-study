## 1. Refused in Chat, Written in Code: Workflow-Level Jailbreak Construction in IDE Coding Agents 🆕

- **저자**: Abhishek Kumar, Carsten Maple (The Alan Turing Institute, London)
- **키워드**: `jailbreak`, `IDE coding agents`, `multi-turn attack`, `agentic AI safety`, `LLM safety`
- **출처**: SNS + arxiv recent (cs.CR cross-list)
- **arxiv abstract**: [2607.03968](https://arxiv.org/abs/2607.03968) (v1)
- **PDF**: [arxiv.org/pdf/2607.03968](https://arxiv.org/pdf/2607.03968.pdf)

**핵심 요약**: IDE에 통합된 코딩 에이전트(예: GitHub Copilot)의 안전성을 단순 챗봇처럼 단일 프롬프트로 평가하는 기존 방식의 맹점을 지적한다. 본 논문은 "워크플로우 수준 탈옥"이라는 새로운 공격 패턴을 제안하는데, 유해한 목표를 소프트웨어 개발 워크플로의 여러 일반적 단계(파일 생성, 코드 수정, 실행 등)에 분산시켜 우회하는 방식이다. Claude Sonnet 4.6, Claude Haiku 4.5, Gemini 3.1 Pro, Gemini 3.5 Flash 4종을 대상으로 HarmBench 등 204개 프롬프트를 테스트한 결과, 직접 채팅/단일 단계에서는 8/816(≈1%)만 성공했지만 전체 워크플로우 조건에서는 816/816(100%)이 유해한 출력을 생성했다. 대화형 거부 벤치마크가 배포된 코딩 에이전트의 실제 안전성을 과대평가함을 실증적으로 보여준다.

- **키워드**: `agent safety`, `red-teaming`, `severity scale`, `tool-calling`, `AgentDojo`

- **arxiv abstract**: [2607.07474](https://arxiv.org/abs/2607.07474) (v1)
- **PDF**: [arxiv.org/pdf/2607.07474](https://arxiv.org/pdf/2607.07474.pdf)

**핵심 요약**: 에이전트 레드팀 벤치마크가 공격 성공 여부를 이진값(성공/실패)으로만 보고해 방어자에게 필요한 피해 심각도 정보를 버린다는 문제를 지적한다. 실행된 액션이 가역적인지, 타 당사자에게 범위를 넘었는지, 권한을 확대했는지를 기준으로 7단계 서열 척도(L0~L6)인 행동-등급 피해 루브릭을 제안한다. ## 7. On the Adversarial Robustness of Multimodal LLM Judges 🆕

- **저자**: Zihan Wang, Guansong Pang, Zelin Liu, Wenjun Miao, Jin Zheng, Xiao Bai (Beihang University; Singapore Management University)
- **키워드**: `adversarial attacks`, `MLLM`, `LLM-as-a-judge`, `adversarial robustness`, `multimodal`
- **출처**: SNS + arxiv recent (cs.CV, cs.CR, cs.AI)
- **arxiv abstract**: [2606.15608](https://arxiv.org/abs/2606.15608) (v1)
- **PDF**: [arxiv.org/pdf/2606.15608](https://arxiv.org/pdf/2606.15608.pdf)

**핵심 요약**: 이미지 품질·안전성 평가 등에 점점 많이 쓰이는 멀티모달 LLM 판사(MLLM judges)의 적대적 견고성이 거의 연구되지 않았다는 문제를 다룬다. MLLM 판사의 적대적 견고성을 평가하는 최초의 일반 프레임워크 RobustMLLMJudge를 제시하며, MLLM 판사들이 점수를 부풀리는 적대적 공격에 매우 취약함을 밝힌다. MGSIA(Manifold-Guided Semantic Induction Attack)라는 새로운 공격 기법도 제안하여 MLLM 판사에 대한 더 효과적이고 전이 가능한 공격을 구현한다.

## 10. Auditable Machine Unlearning for Privacy-Compliant Ransomware Detection Using Multi-Shard SISA and Deep Reinforcement Learning 🆕

- **저자**: Jannatul Ferdous, Rafiqul Islam, Md Zahidul Islam
- **키워드**: `machine unlearning`, `SISA`, `deep reinforcement learning`, `ransomware detection`, `privacy compliance`
- **출처**: arxiv recent (cs.CR)
- **arxiv abstract**: [2607.06860](https://arxiv.org/abs/2607.06860) (v1)
- **PDF**: [arxiv.org/pdf/2607.06860](https://arxiv.org/pdf/2607.06860.pdf)

**핵심 요약**: 랜섬웨어 탐지 AI에서 GDPR 등 데이터 삭제권 요구에 응하는 감사 가능한 언러닝 프레임워크를 제안한다. DDQN(Double Deep Q-Network)이 비대칭 보안 비용 하에서 행동 특성으로 탐지 정책을 학습하고, 멀티샤드 SISA가 샤드 단위 재훈련으로 특정 샘플을 선택적으로 제거한다. Windows 11 행동 데이터셋(2,000샘플)에서 기준 탐지기 F1=0.9925/AUC=0.9983 달성. 중간 샤드 수(M=5~10)가 재훈련 시간을 80~330초에서 5~30초로 단축하면서 최선의 효율-성능 균형을 제공한다.
