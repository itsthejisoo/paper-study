## 1. A Broader Look into MLLM's Retrieval Heads  🆕
- **저자**: Jia Wang, Yuqing Li, Jiangnan Li, Zheng Lin, Mo Yu
- **키워드**: retrieval heads, multimodal interpretability, attention ablation, causal intervention
- **출처**: HF Daily
- **arxiv abstract**: [2610.32411](https://arxiv.org/abs/2610.32411) (v1)
- **PDF**: [arxiv.org/pdf/2610.32411](https://arxiv.org/pdf/2610.32411.pdf)
- **핵심 요약**: 텍스트 LLM에서 알려진 retrieval head가 멀티모달 모델에서도 같은 역할을 하는지는 충분히 검증되지 않았다. 연구진은 18개 체크포인트를 비교해 시청각 검색을 담당하는 소수의 attention head를 식별했다. 해당 head를 제거하면 검색 성능이 거의 사라졌지만, 여러 모달리티가 공유하는 head는 전체의 2% 미만이었다. 이 구조를 활용한 attention 최적화는 Qwen3-VL-8B의 Recall@1을 6.03%p 높였다.

## 2. Agentic Backdoors via Pretraining Poisoning  🆕

- **키워드**: pretraining poisoning, agentic backdoor, remote code execution, supply-chain security

- **arxiv abstract**: [2610.37741](https://arxiv.org/abs/2610.37741) (v1)
- **PDF**: [arxiv.org/pdf/2610.37741](https://arxiv.org/pdf/2610.37741.pdf)
- **핵심 요약**: 공개 웹 말뭉치의 오염이 후속 에이전트 학습 뒤에도 원격 코드 실행 백도어로 남을 수 있는지를 다룬다. 연구진은 Qwen3 0.6B, 1.7B, 4B를 처음부터 사전학습한 뒤 깨끗한 파이프라인으로 CLI 에이전트를 만들었다. 사전학습 데이터의 0.1%만 오염해도 4B 모델의 공격 성공률이 약 92%에 도달했다. 오염률 0.0005%에서도 공격 신호가 남아, 사전학습 공급망 검증의 필요성을 보여준다.

## 4. Understanding and Mitigating Role Spoofing in LLMs  🆕

- **출처**: arxiv recent
- **arxiv abstract**: [2610.40396](https://arxiv.org/abs/2610.40396) (v1)
- **PDF**: [arxiv.org/pdf/2610.40396](https://arxiv.org/pdf/2610.40396.pdf)
- **핵심 요약**: 공격자가 사용자 입력 안에 시스템이나 어시스턴트 역할을 흉내 내면 모델의 지시 우선순위가 무너질 수 있다. 연구진은 역할 스푸핑을 구조와 내용 기반 공격으로 분해해 방어의 일반화 범위를 측정한다. 내용 변형에 맞춘 적대적 학습은 구조적 스푸핑을 충분히 막지 못했다. 반면 선형 프로브는 내부 표현에서 역할 위조 신호를 감지해, 표면 문구가 아닌 역할 표현을 겨냥한 방어 가능성을 제시한다.

## 5. Scan Before You Install: Detecting and Mitigating Local and Composite Vulnerabilities in Skills  🆕

- **키워드**: agent skills, vulnerability scanning, composite attacks, mitigation
- **출처**: arxiv recent
- **arxiv abstract**: [2610.37901](https://arxiv.org/abs/2610.37901) (v1)
- **PDF**: [arxiv.org/pdf/2610.37901](https://arxiv.org/pdf/2610.37901.pdf)
- **핵심 요약**: 에이전트 skill은 파일, 셸, 네트워크 권한을 사용하지만 기존 스캐너는 악성 skill과 개별 분석에 치우쳐 있다. 제안 스캐너는 로컬 취약점과 여러 skill의 자원·호출 상호작용을 함께 분석하고 완화책까지 제안한다. SkillTrustBench에서는 재현율 95.90%, 오탐률 4.22%를 기록했고, 합성 취약점 벤치마크에서는 F1 0.991을 달성했다. GitHub skill 1,587개에서도 분석가가 59건 중 53건을 확인했으며, 55건 중 47건의 완화책이 모든 공격 시험을 차단했다.

## 6. Answer-Only Disclosure: Private-Context LLM Assistance over Web APIs with a Leakage Ledger  🆕
- **저자**: Liang Yuan, Xiaohu Du, Ruikun Luo, Jinze Wang, Mashud Rana et al.
- **키워드**: private-context inference, information leakage, speculative decoding, leakage ledger
- **출처**: arxiv recent
- **arxiv abstract**: [2610.38126](https://arxiv.org/abs/2610.38126) (v1)
- **PDF**: [arxiv.org/pdf/2610.38126](https://arxiv.org/pdf/2610.38126.pdf)
- **핵심 요약**: 온디바이스 모델과 클라우드 LLM의 협업 디코딩은 최종 답변에 없는 비밀도 중간 메시지로 유출할 수 있다. 실제 감사에서는 폐기된 speculative draft가 답변에 없는 비밀 코드를 클라우드로 전송했다. ADLER는 클라우드 메시지를 공개 입력과 사용자가 보는 답변에만 의존하게 만들고, leakage ledger로 답변 자체의 공개량을 추적한다. GSM8K에서 0.5B 클라이언트의 정확도를 0.41에서 0.83으로, 1.5B는 0.67에서 0.85로 높이면서 감사 구성에서는 추가 비밀 노출을 막았다.

- **출처**: arxiv recent
- **arxiv abstract**: [2610.40613](https://arxiv.org/abs/2610.40613) (v1)
- **PDF**: [arxiv.org/pdf/2610.40613](https://arxiv.org/pdf/2610.40613.pdf)
- **핵심 요약**: 기존 distortion-free 워터마크는 여러 키를 결합하거나 speculative decoding을 사용할 때 탐지력이 떨어질 수 있다. TextSeal2는 Gaussian copula 기반 키 혼합과 메모리 없는 race 구성을 사용해 출력 분포를 바꾸지 않고 신호를 삽입한다. 오탐률 0.001에서 100토큰 응답 탐지율을 TextSeal보다 8~22%p 높였고, speculative decoding 조건에서는 두 설정에서 각각 18%p와 22%p 개선했다고 보고했다.

- **arxiv abstract**: [2610.21565](https://arxiv.org/abs/2610.21565) (v3)
- **PDF**: [arxiv.org/pdf/2610.21565](https://arxiv.org/pdf/2610.21565.pdf)
- **핵심 요약**: 출력 방향만 변환하는 TEE 가중치 난독화는 온디바이스 LLM의 모델 절도를 충분히 막지 못할 수 있다. 연구진은 비밀 변환이 유일하게 결정되는 Solution Determinacy Property를 식별하고 기존 방어의 키 구조를 복원하는 공격을 제시한다. BiShield-TEE는 입력과 출력 차원을 함께 난독화해 여러 동등한 해를 만들고 실제 키를 숨긴다. 실험에서 공격 정확도를 완전 차폐 블랙박스 기준선 수준으로 제한하면서 실제 하드웨어의 추론 효율을 높였다고 보고했다.
