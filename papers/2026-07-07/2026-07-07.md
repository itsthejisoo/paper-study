## 1. Securing the AI Agent: A Unified Framework for Multi-Layer Agent Red Teaming 🆕

- **저자**: Yong Yang, Xing Zheng, Huiyu Wu, Huangsheng Cheng, Xiaorong Shi et al. (Tencent)
- **키워드**: `red teaming`, `agent security`, `jailbreak`, `MCP`, `supply-chain audit`
- **출처**: HF Daily
- **arxiv abstract**: [2606.31227](https://arxiv.org/abs/2606.31227) (v1)
- **PDF**: [arxiv.org/pdf/2606.31227](https://arxiv.org/pdf/2606.31227.pdf)

**핵심 요약** (3-5문장):
AI agent의 공격 표면은 인프라, 프로토콜/툴, 에이전트 행동, 모델 등 여러 계층에 걸쳐 있으며, 단일 탐지 패러다임으로는 모두 커버할 수 없다. 이를 해결하기 위해 Tencent는 **AI-Infra-Guard**를 제안하는데, 계층별로 최적 패러다임을 매칭하는 통합 red teaming 프레임워크다. 75개 이상 AI 컴포넌트와 1,400개 이상의 취약점 규칙 기반 결정론적 매칭, LLM 기반 MCP 서버·agent 스킬 감사, 다중 턴 블랙박스 red teaming, 26개 이상 공격 연산자를 16개 데이터셋 대상 jailbreak 테스트로 구성한다. 현재까지 supply-chain 감사를 포함하여 이 모든 기능을 아우르는 유일한 오픈소스 프레임워크이며, layer-paradigm matching을 agent 보안의 실용적 기반으로 제시한다.

## 2. The Devil behind the mask: An emergent safety vulnerability of Diffusion LLMs 🆕

- **저자**: Zichen Wen, Zhuoran Qu, and others (ICLR 2026)
- **키워드**: `diffusion LLM`, `jailbreak`, `adversarial attack`, `alignment`, `DIJA`
- **출처**: HF Daily / SNS
- **arxiv abstract**: [2507.11097](https://arxiv.org/abs/2507.11097) (v1)
- **PDF**: [arxiv.org/pdf/2507.11097](https://arxiv.org/pdf/2507.11097.pdf)

**핵심 요약** (3-5문장):
Diffusion 기반 LLM(dLLM)은 병렬 디코딩과 양방향 모델링으로 기존 autoregressive LLM과 근본적으로 다른 생성 방식을 갖지만, 기존 alignment 메커니즘은 이 구조적 차이를 고려하지 않는다. **DIJA**는 masked-text 프롬프트를 인터리빙하여 양방향 모델링(문맥 일관성 강제)과 병렬 디코딩(동적 거부 불가)이라는 두 취약점을 동시에 활용하는 첫 체계적 jailbreak 프레임워크다. 기존 안전 정렬이 dLLM에 거의 무력화됨을 실증하며, diffusion LLM의 안전 설계에 근본적 재검토가 필요함을 주장한다. ICLR 2026에 채택되어 주목받고 있다.

## 3. Enhancing Jailbreak Attacks on LLMs via Persona Prompts 🆕

- **저자**: Zheng Zhang, Peilin Zhao, Deheng Ye, Hao Wang
- **키워드**: `jailbreak`, `persona prompts`, `genetic algorithm`, `red teaming`, `adversarial attack`
- **출처**: HF Daily / SNS
- **arxiv abstract**: [2507.22171](https://arxiv.org/abs/2507.22171) (v3)
- **PDF**: [arxiv.org/pdf/2507.22171](https://arxiv.org/pdf/2507.22171.pdf)

**핵심 요약** (3-5문장):
기존 jailbreak 연구는 해로운 의도를 직접 조작하는 데 집중했지만, 페르소나 프롬프트(역할극)가 LLM 안전 방어를 우회하는 강력한 수단임을 체계적으로 규명한다. 유전 알고리즘 기반 자동화 방법으로 LLM 안전 메커니즘을 우회하는 최적 페르소나 프롬프트를 탐색하며, 여러 LLM에서 거부율을 50-70% 감소시키는 데 성공한다. 기존 공격 방법과 결합 시 시너지 효과로 공격 성공률이 추가 10-20% 향상되어, 페르소나 기반 공격이 독립 위협이자 강화 도구임을 보인다.

## 4. Sampling-aware Adversarial Attacks Against Large Language Models 🆕

- **저자**: Tim Beyer, Yan Scholten, Leo Schwinn, Stephan Günnemann (TU Munich)
- **키워드**: `adversarial attack`, `sampling`, `jailbreak`, `robustness`, `attack success rate`
- **출처**: SNS
- **arxiv abstract**: [2507.04446](https://arxiv.org/abs/2507.04446) (v4, ICLR 2026)
- **PDF**: [arxiv.org/pdf/2507.04446](https://arxiv.org/pdf/2507.04446.pdf)

**핵심 요약** (3-5문장):
기존 adversarial attack은 greedy 디코딩 단일 생성만을 대상으로 평가하여 LLM의 본질적 확률적 특성을 무시하고 robustness를 과대평가한다는 문제를 지적한다. 공격을 최적화(프롬프트 수정)와 샘플링(반복 생성) 간의 자원 배분 문제로 재정의하고, compute-optimal 트레이드오프를 실험적으로 결정한다. 샘플링을 기존 공격에 통합하면 공격 성공률(ASR)이 최대 37% 향상되고, 효율성은 최대 100배 개선됨을 보여 현재 robustness 평가가 얼마나 낙관적인지를 드러낸다. ICLR 2026 채택 논문이다.

## 5. VisCo Attack: Visual Contextual Attack — Jailbreaking MLLMs with Image-Driven Context Injection 🆕

- **저자**: (VisCo Attack 저자들, GitHub: Dtc7w3PQ)
- **키워드**: `jailbreak`, `multimodal LLM`, `vision-centric`, `adversarial attack`, `GPT-4o`
- **출처**: SNS
- **arxiv abstract**: [2507.02844](https://arxiv.org/abs/2507.02844) (v1)
- **PDF**: [arxiv.org/pdf/2507.02844](https://arxiv.org/pdf/2507.02844.pdf)

**핵심 요약** (3-5문장):
기존 MLLM jailbreak은 시각 입력에 해로운 텍스트 시맨틱을 인코딩하는 방식이지만, 시각 모달리티가 단순 트리거로만 기능하여 현실적 맥락이 결여되어 있다. 이 논문은 시각 정보가 완전한 jailbreak 맥락 구성에 필수적인 요소가 되는 새로운 **vision-centric jailbreak** 세팅을 정의하고, **VisCo(Visual Contextual) Attack**을 제안한다. 4가지 vision-focused 전략으로 맥락적 대화를 조작하고, 자동 독성 난독화와 시맨틱 정제를 통해 최종 공격 프롬프트를 생성한다. GPT-4o 대상 MM-SafetyBench에서 독성 점수 4.78, ASR 85% 달성으로 베이스라인(독성 2.48, ASR 22.2%)을 크게 앞선다.

## 6. LACUNA: A Testbed for Evaluating Localization Precision for LLM Unlearning 🆕

- **저자**: Matteo Boglioni, Thibault Rousset, Siva Reddy, Marius Mosbach, Verna Dankers
- **키워드**: `LLM unlearning`, `PII`, `parameter localization`, `privacy`, `resurfacing attack`
- **출처**: arxiv recent (cs.CL)
- **arxiv abstract**: [2607.02513](https://arxiv.org/abs/2607.02513) (v1)
- **PDF**: [arxiv.org/pdf/2607.02513](https://arxiv.org/pdf/2607.02513.pdf)

**핵심 요약** (3-5문장):
LLM은 PII 등 민감한 학습 데이터를 기억하며, 기존 unlearning 벤치마크는 출력 수준에서만 평가하여 지식이 파라미터에서 실제로 지워졌는지 확인할 수 없다. **LACUNA**는 합성 개인의 PII를 OLMo 1B/7B 모델의 특정 파라미터에 주입한 후, 파라미터 수준 localization을 직접 검증하는 ground-truth를 가진 최초의 unlearning testbed다. SOTA unlearning 방법들이 출력 수준 성능은 좋지만, 파라미터 수준에서는 매우 부정확하고 resurfacing attack에 취약함을 발견한다. Localization이 정확할 때는 단순한 gradient 기반 unlearning도 강력한 지식 삭제와 resurfacing 내성을 달성할 수 있음을 보인다.

**핵심 요약** (3-5문장):

## 8. OpenSafeIntent: Evaluating Intent-Calibrated Safe Completion Across Dual-Use Prompt Sets 🆕

- **저자**: Rheeya Uppaal, Seungwoo Lyu, Selina Sung, Junjie Hu
- **키워드**: `AI safety`, `dual-use`, `intent calibration`, `benchmark`, `safe completion`
- **출처**: arxiv recent (cs.CL)
- **arxiv abstract**: [2607.02047](https://arxiv.org/abs/2607.02047) (v1)
- **PDF**: [arxiv.org/pdf/2607.02047](https://arxiv.org/pdf/2607.02047.pdf)

**핵심 요약** (3-5문장):
안전한 응답 생성은 유용성을 유지하면서 피해를 막아야 하지만, 격리된 프롬프트 기반의 기존 벤치마크는 사용자 의도 맥락을 반영하지 못한다. **OpenSafeIntent**는 동일한 작업에 대해 양성(benign), dual-use, 악성(malicious) 변종을 포함하는 제어된 프롬프트 세트 벤치마크로, 의도 변화에 따른 안전 응답 일관성을 체계적으로 평가한다. 현재 LLM들이 의도 정보를 충분히 반영한 안전 완성을 제공하지 못하고, dual-use 프롬프트에서 과도 거부와 허용 오류 모두 발생함을 보인다.

## 9. On the Limits of Steering Vectors for Preference-Aligned Generation 🆕

- **저자**: Melanie Subbiah, Zara Hall, Kathleen McKeown (Columbia University)
- **키워드**: `steering vectors`, `representation engineering`, `preference alignment`, `interpretability`, `activation steering`
- **출처**: arxiv recent (cs.CL)
- **arxiv abstract**: [2607.01802](https://arxiv.org/abs/2607.01802) (v1)
- **PDF**: [arxiv.org/pdf/2607.01802](https://arxiv.org/pdf/2607.01802.pdf)

**핵심 요약** (3-5문장):
Steering vector(활성화 조정)는 LLM의 생성 동작을 미세 조정 없이 제어하는 interpretability 기반 접근법으로 주목받고 있으나, 선호도 정렬(preference alignment) 목적에서의 한계는 체계적으로 연구되지 않았다. 이 논문은 steering vector가 preference-aligned 생성에 효과적인 조건과 실패 조건을 분석하며, 선형 표현 가정의 한계가 다양한 선호도 시나리오에서 어떻게 나타나는지를 실험적으로 규명한다. 결과는 steering vector가 특정 맥락에서 제한적임을 보이며, representation engineering의 범용 활용에 신중한 재고가 필요함을 시사한다.

## 10. Improving Certified Robustness via Adversarial Distillation 🆕

- **저자**: Matteo Melis, Jesus Martinez Del Rincon, Vishal Sharma
- **키워드**: `certified robustness`, `adversarial distillation`, `adversarial training`, `robustness`, `knowledge distillation`
- **출처**: arxiv recent (cs.LG)
- **arxiv abstract**: [2606.31653](https://arxiv.org/abs/2606.31653) (v1)
- **PDF**: [arxiv.org/pdf/2606.31653](https://arxiv.org/pdf/2606.31653.pdf)

**핵심 요약** (3-5문장):
DNN의 certified robustness(수학적 보증 기반 적대 견고성)를 높이면 clean accuracy가 크게 떨어지는 근본적 트레이드오프가 존재한다. 이 논문은 adversarial distillation을 활용하여 robust teacher 모델의 지식을 student 모델에 전달함으로써 certified robustness와 clean accuracy 간의 균형을 개선하는 방법을 제안한다. 적대적 학습과 knowledge distillation의 시너지가 certified bound를 유지하면서도 실용적인 정확도를 달성할 수 있음을 보여, AI 모델 배포 시 보안성과 성능의 공존 가능성을 탐색한다.
