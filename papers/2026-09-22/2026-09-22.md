- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2609.22076](https://arxiv.org/abs/2609.22076) (v1)
- **PDF**: [arxiv.org/pdf/2609.22076](https://arxiv.org/pdf/2609.22076.pdf)
- **핵심 요약**: 도구 사용 에이전트가 결제 요청을 정책에 맞게 승인하는지 검증할 공통 벤치마크가 부족하다. APort Vault는 공개 CTF에서 수집한 인간 작성 공격을 여러 모델과 정책 구성에 재생하고, 결정론적 사전 실행 검사를 비교한다. 이 검사는 허용되지 않은 수취인으로의 송금을 차단하면서도 허용된 결제는 계속 실행했다. 연구는 모델의 요청 생성 능력과 실제 권한 경계 집행을 분리해 평가해야 함을 보여준다.

- **키워드**: LLM agent privacy, recoverable leakage, black-box auditing, tool-use security
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.21686](https://arxiv.org/abs/2609.21686) (v1)
- **PDF**: [arxiv.org/pdf/2609.21686](https://arxiv.org/pdf/2609.21686.pdf)
- **핵심 요약**: 기존 에이전트 개인정보 평가는 메모리나 검색 같은 단일 구성요소만 살펴 실제 공격자가 복구할 수 있는 정보와 내부 노출을 구분하기 어렵다. CIPL은 민감정보의 선택부터 관찰과 추출까지를 채널 단계로 모델링한다. 메모리, 검색, 도구 사용, 실제 브라우저 에이전트를 같은 프로토콜로 비교한 결과, 저장 위치보다 관찰 표면과 프롬프트-채널 정렬이 복구 가능성을 크게 좌우했다. 정확 일치가 놓치는 공격자 유용 정보도 의미 기반 감사로 포착한다.

- **핵심 요약**: 입력 변환과 출력 가드 등 서로 다른 단계의 탈옥 방어를 어떻게 조합할지에 대한 통제된 비교가 부족하다. CASCADE는 직접·블랙박스·단일 턴 공격을 대상으로 공격 성공률과 질의 예산을 통일한다. 19개 공격과 15개 방어를 비교한 결과, 모든 상황에서 우세한 단일 방어는 없었다. 대신 단계 내외의 적절한 조합이 효용 손실을 제한하면서 더 높은 안전성을 제공했다.
