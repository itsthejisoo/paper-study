## 1. GateMem: Benchmarking Memory Governance in Multi-Principal Shared-Memory Agents 🆕

- **저자**: Zhe Ren, Yibo Yang, Yimeng Chen, Zijun Zhao, Benshuo Fu, Zhihao Shu, Bingjie Zhang, Yangyang Xu, Dandan Guo, Shuicheng Yan
- **키워드**: `memory governance`, `access control`, `shared-memory agents`, `multi-principal`, `agent safety`
- **출처**: HF Daily (74 upvotes) + arxiv recent (cs.LG/cs.CL)
- **arxiv abstract**: [2606.18829](https://arxiv.org/abs/2606.18829) (v1)
- **PDF**: [arxiv.org/pdf/2606.18829](https://arxiv.org/pdf/2606.18829.pdf)

**핵심 요약** (3-5문장):
병원·직장·캠퍼스·가정 등 다중 주체(principal)가 공유 메모리 풀을 이용하는 환경에서 LLM 에이전트의 메모리 거버넌스를 통합 평가하는 GateMem 벤치마크를 제안한다. 유용성(utility), 접근 제어(access control), 능동적 망각(active forgetting)의 세 축을 동시 측정하며 의료·사무·교육·가정 4개 도메인에 걸친 다중 당사자 에피소드, 점진적 메모리 주입, 숨겨진 체크포인트를 포함한다. 다양한 기법과 백본 모델 실험에서 세 가지 요건을 동시에 충족하는 방법이 존재하지 않으며, 긴 컨텍스트 프롬프팅이 높은 토큰 비용으로 최고 거버넌스 점수를 기록하는 반면 검색 기반 방법은 비용 절감에도 불구하고 미인가 정보를 여전히 유출한다. 코드·데이터셋은 GitHub(rzhub/GateMem) 및 Hugging Face(Ray368/GateMem)에 공개됐다.

## 2. How Transparent is DiffusionGemma? 🆕

- **저자**: Joshua Engels, Callum McDougall, Bilal Chughtai, Janos Kramar, Senthoran Rajamanoharan, Cindy Wu, Arthur Conmy, Asic Q Chen, Jean Tarbouriech, Min Ma, Brendan O'Donoghue, João Gabriel Lopes de Oliveira, Rohin Shah, Neel Nanda
- **키워드**: `LLM interpretability`, `diffusion LM`, `variable transparency`, `algorithmic transparency`, `opaque serial depth`
- **출처**: LessWrong + AlignmentForum + Twitter + alphaxiv + arxiv recent (cs.LG/cs.CL)
- **arxiv abstract**: [2606.20560](https://arxiv.org/abs/2606.20560) (v1)
- **PDF**: [arxiv.org/pdf/2606.20560](https://arxiv.org/pdf/2606.20560.pdf)

**핵심 요약** (3-5문장):
텍스트 확산 모델 DiffusionGemma의 투명성을 `변수 투명성(variable transparency)`과 `알고리즘 투명성(algorithmic transparency)`으로 분해해 분석한다. 표면상 불투명한 직렬 깊이(opaque serial depth)가 Gemma 4 대비 28.6배 높아 보이지만, 디노이징 스텝 사이를 흐르는 정보를 해석 가능한 토큰 병목(token bottleneck)으로 매핑하면 하류 성능 저하 없이 불투명 깊이가 Gemma 4 대비 1.1배까지 낮아짐을 보인다. 이를 통해 확산 LM도 자기회귀(AR) 모델에 준하는 모니터링 가능성과 해석 가능성을 확보할 수 있다는 근거를 제시하며, LessWrong·AlignmentForum에서 높은 관심을 받았다.

- **출처**: arxiv recent (cs.CR/cs.CL)
- **arxiv abstract**: [2606.18673](https://arxiv.org/abs/2606.18673) (v1)
- **PDF**: [arxiv.org/pdf/2606.18673](https://arxiv.org/pdf/2606.18673.pdf)

**핵심 요약** (3-5문장):
6개 주요 상용 플랫폼의 LLM 기반 애플리케이션 1,200개를 측정한 결과, 80% 이상이 현실적인 적대적 쿼리에서 시스템 프롬프트를 노출시키며 일부는 서드파티 API 키까지 유출됨을 보고한다. 어텐션 수준의 기계론적 분석을 통해 쿼리-키 정렬 편향과 소프트맥스 증폭이 LLM으로 하여금 방어 제약을 점진적으로 무시하게 하는 "attention drift" 현상을 규명한다. 이를 방어하기 위해 최적화 가능한 소프트 프롬프트로 어텐션을 재고정하는 AREA 방어를 제안하며, 유용성 손상 없이 프롬프트 유출을 차단할 수 있음을 보인다.

## 5. Analyzing Defensive Misdirection Against Model-Guided Automated Attacks on Agentic AI Systems 🆕

- **저자**: Reza Soosahabi, Vivek Namsani
- **키워드**: `jailbreak defense`, `misdirection`, `agentic AI`, `CMPE`, `automated attack`
- **출처**: arxiv recent (cs.CR/cs.AI)
- **arxiv abstract**: [2606.20470](https://arxiv.org/abs/2606.20470) (v1)
- **PDF**: [arxiv.org/pdf/2606.20470](https://arxiv.org/pdf/2606.20470.pdf)

**핵심 요약** (3-5문장):
기존 탐지-차단(detect-and-block) 방어가 자동화된 jailbreak 공격에 의해 쿼리 예산이 늘어날수록 공격 성공률(ASR)이 1에 수렴할 수 있음을 확률 모델로 분석한다. 이를 극복하기 위해 탐지된 악성 상호작용에 공격자의 자동화 판단 모델(judge)에 거짓 양성을 유도하는 통제된 비작동 응답을 반환하는 detect-and-misdirect 전략을 제안한다. CMPE(Contextual Misdirection via Progressive Engagement)로 구현해 PAIR 및 GPTFuzz 공격 실험에서 ASR 상한을 최대 두 자릿수 감소시키고 검증된 공격 성공을 거의 제거했다.

## 7. Contrastive-Difference CKA Reveals Concept-Specific Structural Alignment Across Language Model Architectures 🆕

- **저자**: Xueping Gao (Alibaba Cloud)
- **키워드**: `mechanistic interpretability`, `CKA`, `cross-architecture`, `concept representation`, `functional transfer`
- **출처**: arxiv recent (cs.CL)
- **arxiv abstract**: [2606.16897](https://arxiv.org/abs/2606.16897) (v1)
- **PDF**: [arxiv.org/pdf/2606.16897](https://arxiv.org/pdf/2606.16897.pdf)

**핵심 요약** (3-5문장):
서로 다른 LLM 아키텍처가 고수준 개념을 구조적으로 호환되는 방식으로 인코딩하는지 탐구하며, 기하학적 수렴은 중간 수준이나 기능적 전이(functional transfer)는 거의 완벽하다는 "universality dissociation"을 발견한다. 훈련 불필요(training-free) 진단 도구 CKA_Δ(컨트라스티브 차이 CKA)를 제안해 표준 CKA가 구분하지 못하는 영역에서 개념별 수렴을 격리해내며, 6개 개념 도메인(안전 포함)에서 재현된다. CKA_Δ를 아키텍처 이상 탐지기(Gemma: d=1.08, AUC=0.79)로도 활용할 수 있어 크로스 아키텍처 개념 모니터링의 실용적 도구로 자리매김한다.

## 10. FFinRED: An Expert-Guided Benchmark Generation and Evaluation Framework for Financial LLM Red-Teaming 🆕

- **저자**: Chaeyun Kim, Daeyoung Park, Junghwan Kim, Jinyoung Jeong, Eunji Song, Yongtaek Lim, Minwoo Kim
- **키워드**: `red-teaming`, `financial LLM`, `safety benchmark`, `FATF`, `FSI regulatory sandbox`
- **출처**: arxiv recent (cs.CR/cs.AI)
- **arxiv abstract**: [2606.19887](https://arxiv.org/abs/2606.19887) (v1)
- **PDF**: [arxiv.org/pdf/2606.19887](https://arxiv.org/pdf/2606.19887.pdf)

**핵심 요약** (3-5문장):
금융 도메인 특화 LLM 안전성 평가를 위한 전문가 주도 레드팀 프레임워크 FinRED를 소개한다. FATF·EU DORA 등 글로벌 기준을 규제 회피부터 복잡한 금융 사기까지 위협에 매핑하는 두 단계 분류 체계를 사용하며, 실제 금융 문서를 맥락 풍부한 레드팀 행동 프롬프트(seed)로 변환하는 확장 가능한 파이프라인과 ISO/IEC 27001 기반 전문가 검증 루브릭을 갖춘다. 전문가 검증 루브릭이 중요 거짓 음성(critical false negatives)을 28건에서 12건으로 감소시켰으며, 한국 금융보안원(FSI)의 생성형 AI 보안 평가 규제 샌드박스에 실제 배포됐다. 데이터셋은 huggingface.co/datasets/datumo/FinRED에서 자격 연구자에게 제공된다.
