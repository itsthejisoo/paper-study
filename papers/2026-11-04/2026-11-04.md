## 3. VeriHarm-Bench: Measuring Harmful Success in LLM Coding Agents Verifiably  🆕

- **저자**: Wei-Lin Chen, Zhepei Wei, Xinyu Zhu, Yu-Min Tseng, Tzu-Han Lin et al.
- **키워드**: coding agent safety, harmful success, executable evaluation, benchmark
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2611.03575](https://arxiv.org/abs/2611.03575) (v1)
- **PDF**: [arxiv.org/pdf/2611.03575](https://arxiv.org/pdf/2611.03575.pdf)
- **핵심 요약**: 코딩 에이전트는 요청한 작업을 완수하면서도 의도하지 않은 피해를 만들 수 있으며, 기존 정확도 평가는 이를 놓친다. VeriHarm-Bench는 코딩 작업을 최소한으로 변형하고, 작업 정확성과 피해를 각각 실행 가능한 테스트로 검증한다. GPT-5.6-Sol과 Claude-Opus-5를 포함한 최신 에이전트들은 평균 작업 정확도 95%를 보였지만, 안전 성공률은 37%에 그쳤다. 벤치마크는 기능적 성공과 안전한 성공을 분리해 측정해야 함을 정량적으로 보여준다.

- **출처**: arxiv recent
- **arxiv abstract**: [2611.01342](https://arxiv.org/abs/2611.01342) (v1)
- **PDF**: [arxiv.org/pdf/2611.01342](https://arxiv.org/pdf/2611.01342.pdf)
- **핵심 요약**: 프리필 공격은 모델 답변의 시작 부분을 강제로 주입해 기존 거부 행동을 약화한다. 연구진은 Jacobian lens로 공격 중 유해성 신호와 거부 신호를 추적하고, 거부 신호만 정상 입력 수준까지 먼저 붕괴하는 현상을 관찰했다. J-Anchor는 공격 전 신호를 요청별 기준점으로 저장한 뒤 J-space에서 거부 성분을 선택적으로 복원한다. 학습 없이 여러 모델 계열의 공격 성공을 크게 낮추면서 정상 요청과 추론 성능을 보존했다고 보고한다.
