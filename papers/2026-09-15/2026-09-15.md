- **키워드**: sensitive attribute inference, PII, data extraction
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.12448](https://arxiv.org/abs/2609.12448) (v1)
- **PDF**: [arxiv.org/pdf/2609.12448](https://arxiv.org/pdf/2609.12448.pdf)
- **핵심 요약**: LLM 프로파일러는 여러 게시물의 간접 단서를 모아 민감 속성을 추론하지만, 어떤 원문이 누출에 기여했는지 설명하기 어렵다. GraphProfiler는 게시물 이력을 출처 연결 개인 지식 그래프로 만들고 예측 근거를 원문까지 추적한다. SynthPAI 공격 성공률은 86.7%, PANDORA는 84.6%였고 예측의 98% 이상에 근거를 제시했다. 인용 게시물을 제거하면 무작위 게시물 제거보다 성공률이 더 크게 낮아져 근거 연결의 실질적 기여도 확인했다.

## 3. Shuffling is Not Enough: Breaking Permutation-Based Model Confidentiality in Hybrid FHE Inference  🆕

- **키워드**: model stealing, FHE, differential privacy
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.12911](https://arxiv.org/abs/2609.12911) (v1)
- **PDF**: [arxiv.org/pdf/2609.12911](https://arxiv.org/pdf/2609.12911.pdf)
- **핵심 요약**: 하이브리드 FHE 추론에서 출력 순열과 잡음만으로 모델 기밀성을 지킬 수 있다는 가정을 공격한다. 입력 차원이 d인 선형층은 d+1개의 허용 질의로 순열 불변 요약을 정확히 복구할 수 있음을 보였다. ResNet-20의 모든 선형층을 총 5,712개 직접 질의로 오차 없이 복구했고, ImageNet급 CNN과 ViT-B/16에서도 층별 정확 복구를 확인했다. 이 누출을 막을 만큼 잡음을 키우면 추론 효용이 붕괴해 정확성과 기밀성 사이의 구조적 충돌을 드러낸다.

- **핵심 요약**: SAE 층간 특징 대응을 디코더 코사인 유사도만으로 찾으면 잔차 업데이트를 거쳐 새로 형성되는 특징을 놓칠 수 있다. 저자들은 원천 특징과 업데이트 특징이 목표 특징으로 이어지는 전이 지도를 만들고, 디코딩한 업데이트 특징을 절제해 인과성을 검사한다.
