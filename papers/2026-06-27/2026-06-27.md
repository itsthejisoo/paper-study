## 1. Large Reasoning Models Are Autonomous Jailbreak Agents  🆕

- **저자**: Thilo Hagendorff, Erik Derner, Nuria Oliver
- **키워드**: `LRM jailbreak`, `autonomous jailbreak agent`, `alignment regression`, `DeepSeek-R1`, `Gemini 2.5 Flash`, `multi-turn attack`
- **출처**: SNS · Nature Communications 2026 (doi: 10.1038/s41467-026-69010-1)
- **arxiv abstract**: [2508.04039](https://arxiv.org/abs/2508.04039) (v1)
- **PDF**: [arxiv.org/pdf/2508.04039](https://arxiv.org/pdf/2508.04039)

**핵심 요약**: LRM(대형 추론 모델)의 설득 능력을 활용하면 jailbreak 공격이 비전문가도 쉽게 수행할 수 있는 저비용 활동으로 단순화된다는 사실을 밝힌다. DeepSeek-R1, Gemini 2.5 Flash, Grok 3 Mini, Qwen3 235B 등 4개 LRM을 자율 적대 에이전트로 활용하여 9개 타겟 모델에 멀티턴 jailbreak를 수행했으며, 7개 민감 도메인을 포괄하는 70개 유해 프롬프트 벤치마크에서 전체 공격 성공률 **97.14%**를 달성했다. LRM이 다른 모델의 안전 가드레일을 체계적으로 침식하는 "정렬 회귀(alignment regression)" 현상을 규명하며, 최전선 모델이 jailbreak 시도를 방어할 뿐만 아니라 jailbreak 에이전트로 공모되지 않도록 정렬해야 할 긴급성을 강조한다. arxiv 게재(2025년 8월) 후 Nature Communications 2026에 게재되어 이번 주 SNS와 언론에서 광범위하게 인용 중이다.

## 3. A Layered Security Framework Against Prompt Injection in RAG-Based Chatbots  🆕

- **저자**: Gulshan Saleem, Nisar Ahmed, Muhammad Imran Zaman, Ali Hassan
- **키워드**: `prompt injection`, `RAG security`, `layered defense`, `indirect injection`, `provenance-based hierarchy`, `semantic drift detection`
- **출처**: arxiv recent (cs.CR, 2026-06-17)
- **arxiv abstract**: [2606.19660](https://arxiv.org/abs/2606.19660) (v1)
- **PDF**: [arxiv.org/pdf/2606.19660](https://arxiv.org/pdf/2606.19660)

**핵심 요약**: OWASP LLM Top 10에서 가장 심각한 취약점으로 분류된 프롬프트 인젝션에 대응하는 3계층 방어 프레임워크를 제안한다. Layer 1은 규칙 기반 패턴 라이브러리와 파인튜닝된 시맨틱 이상 분류기로 사용자 입력을 검사하고, Layer 2는 컨텍스트 조립 시 출처 기반 명령 계층을 적용하여 검색된 문서가 운영자 정책을 덮어쓰는 것을 방지하며, Layer 3은 정책 규칙 엔진과 시맨틱 드리프트 탐지기로 출력을 감사한다. 5,080개 샘플에서 GPT-4o, Llama 3, Mistral 7B 대상 평가 결과 ASR을 **71.4%에서 11.3%로 감소**시키고 최상위 단일 계층 기준선 대비 27.3%p, 기존 가드레일 시스템 대비 23.8%p 향상하면서 FPR 4.8%, 지연 오버헤드 중간값 61.2ms를 유지했다.

- **arxiv abstract**: [2506.22557](https://arxiv.org/abs/2506.22557) (v1)
- **PDF**: [arxiv.org/pdf/2506.22557](https://arxiv.org/pdf/2506.22557)

**핵심 요약**: 빈번한 안전 업데이트로 인한 공격 수명 단축 및 높은 쿼리 비용 문제를 해결하는 저비용 멀티에이전트 jailbreak 프레임워크 MetaCipher를 제안한다. 악성 콘텐츠를 암호화하여 탐지를 우회하는 난독화 기반 공격으로, 강화학습 기반 동적 암호 선택 메커니즘이 암호 풀에서 최적 암호화 전략을 적응적으로 선택한다. **최대 10회 쿼리** 내에 최신 비추론 LLM 대상 **92% 이상**, 추론 지원 LLM 대상 **74% 이상** ASR을 달성하며 기존 난독화 기반 jailbreak 방법 전체를 능가한다. 시간적 지속성(time-persistence)으로 LLM 안전 업데이트 이후에도 공격 유효성이 유지되며, 다양한 피해 모델과 벤치마크 대규모 평가로 견고성을 입증했다.

## 7. PrivacyScalpel: Enhancing LLM Privacy via Interpretable Feature Intervention with Sparse Autoencoders  🆕

- **저자**: Ahmed Frikha, Muhammad Reza Ar Razi, Krishna Kanth Nakka, Ricardo Mendes, Xue Jiang, Xuebing Zhou
- **키워드**: `PII leakage`, `sparse autoencoder`, `k-SAE`, `feature intervention`, `vector steering`, `privacy-utility tradeoff`
- **출처**: arxiv recent (cs.LG, 2025-03)
- **arxiv abstract**: [2503.11232](https://arxiv.org/abs/2503.11232) (v1)
- **PDF**: [arxiv.org/pdf/2503.11232](https://arxiv.org/pdf/2503.11232)

**핵심 요약**: LLM의 PII(개인 식별 정보) 유출 위험을 해석 가능성 기법으로 완화하는 PrivacyScalpel 프레임워크를 제안한다. (1) Feature Probing으로 PII 풍부 표현을 인코딩하는 레이어를 식별하고, (2) k-SAE로 프라이버시 민감 특성을 분리·격리하며, (3) 타겟 절제와 벡터 스티어링으로 PII 유출을 억제하는 3단계 파이프라인이다. Enron 데이터셋으로 파인튜닝된 Gemma2-2b와 Llama2-7b에서 이메일 유출을 **5.15%에서 0.0%까지 감소**시키면서 원래 모델 유용성의 **99.4% 이상을 유지**했다. 폴리시맨틱 뉴런보다 희소한 모노시맨틱 특성에 개입하는 것이 더 효과적임을 보이며, AI 프라이버시와 기계적 해석 가능성 두 분야를 연결하는 교차 기여를 한다.

## 10. Not All Tokens Are Created Equal: Query-Efficient Jailbreak Fuzzing for LLMs  🆕

- **저자**: Wenyu Chen 외 (Shandong University)
- **키워드**: `jailbreak fuzzing`, `token-level analysis`, `TriageFuzz`, `query efficiency`, `refusal behavior`, `surrogate model`, `evolutionary strategy`
- **출처**: arxiv recent (cs.CR, 2026-03-24)
- **arxiv abstract**: [2603.23269](https://arxiv.org/abs/2603.23269) (v1)
- **PDF**: [arxiv.org/pdf/2603.23269](https://arxiv.org/pdf/2603.23269)

**핵심 요약**: LLM 거부 행동에서 토큰별 기여도가 극도로 치우쳐 있다는 관찰을 바탕으로 쿼리 효율적인 jailbreak 퍼징 프레임워크 TriageFuzz를 제안한다. 대리 모델로 개별 토큰의 거부 행동 기여도를 추정하고, 이를 바탕으로 거부 안내 진화 전략이 안전 제약을 우회하도록 후보 프롬프트의 가중치를 조정하는 경량 채점기를 통합한다. 6개 오픈소스 LLM과 3개 상용 API 실험에서 기존 접근법 대비 **70% 적은 쿼리로 90% ASR**을 달성했다. 모델 간 거부 경향의 강한 교차 일관성을 발견하여 대리 모델 기반 토큰 기여도 추정의 이론적 근거를 제공하며, 핵심 거부 토큰을 타겟으로 퍼징 탐색 공간을 효과적으로 줄인다.
