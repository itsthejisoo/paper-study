## 1. MIB: A Mechanistic Interpretability Benchmark 🆕

- **저자**: Aaron Mueller, Atticus Geiger, Sarah Wiegreffe, Dana Arad, et al.
- **키워드**: `mechanistic interpretability`, `circuit localization`, `sparse autoencoder`, `causal variable`, `benchmark`
- **출처**: arxiv recent · ICML 2025
- **arxiv abstract**: [2504.13151](https://arxiv.org/abs/2504.13151) (v2)
- **PDF**: [arxiv.org/pdf/2504.13151](https://arxiv.org/pdf/2504.13151.pdf)

**핵심 요약**: 현재 mechanistic interpretability 방법론들이 실제로 얼마나 잘 작동하는지를 평가할 공통 기준이 없다는 문제를 지적하며, 4개의 태스크와 5개의 모델에 걸친 두 트랙(circuit localization, causal variable localization)으로 구성된 MIB 벤치마크를 제안한다. Circuit 탐색에서는 attribution 방법과 mask 최적화가 가장 우수하고, SAE·DAS 같은 feature 분해 방법은 causal variable 위치 탐지에서 평가된다. 이 벤치마크를 통해 22명의 연구자들이 다양한 해석 가능성 방법의 실제 성능 격차를 최초로 체계적으로 정량화했다.

## 2. Differentiation-Based Extraction of Proprietary Data from Fine-Tuned LLMs 🆕

- **저자**: Zongjie Li, Daoyuan Wu, Shuai Wang, Zhendong Su
- **키워드**: `SFT data extraction`, `training data leakage`, `fine-tuned LLM`, `model stealing`, `data privacy`
- **출처**: arxiv recent · ACM CCS 2025
- **arxiv abstract**: [2506.17353](https://arxiv.org/abs/2506.17353) (v1)
- **PDF**: [arxiv.org/pdf/2506.17353](https://arxiv.org/pdf/2506.17353.pdf)

**핵심 요약**: Supervised Fine-Tuning(SFT) 데이터셋이 지식재산으로서 큰 가치를 지님에도 불구하고, fine-tuned LLM으로부터 해당 데이터를 추출하는 공격이 지금까지 연구되지 않았다. 본 논문은 이를 최초로 정형화하고, fine-tuned 모델이 베이스 모델에 비해 특정 데이터에 더 높은 confidence를 보이는 현상을 이용한 Differentiated Data Extraction(DDE) 기법을 제안한다. 다양한 도메인 실험에서 DDE가 기존 추출 베이스라인을 일관적으로 앞서며, 방어 메커니즘도 함께 제시한다.

## 3. Refusal Lives Downstream of Persona in Chat Models 🆕

- **저자**: Viola Zhong, Qirui Li
- **키워드**: `mechanistic interpretability`, `refusal`, `persona`, `activation steering`, `representation engineering`
- **출처**: arxiv recent · ICML 2026 Mechanistic Interpretability Workshop
- **arxiv abstract**: [2606.26161](https://arxiv.org/abs/2606.26161) (v1)
- **PDF**: [arxiv.org/pdf/2606.26161](https://arxiv.org/pdf/2606.26161.pdf)

**핵심 요약**: instruction-tuned 모델의 거절(refusal) 행동과 페르소나(persona)가 별개의 메커니즘으로 연구되어 왔지만, 실제로는 두 방향이 상호 작용함을 보인다. Qwen2.5-7B-Instruct와 Llama-3.1-8B-Instruct에서 compliant persona 방향으로 activation을 조종하면 거절 비율이 97%에서 2%로 급감하며, 이후 refusal 방향을 재주입하면 후기 레이어에서만 부분적으로 복구된다. 즉 거절은 페르소나의 downstream에 위치하며, 안전성 기제가 모델의 정체성 표현에 의존함을 시사한다.

## 4. A Survey on Model Extraction Attacks and Defenses for Large Language Models 🆕

- **키워드**: `model extraction`, `model stealing`, `API attack`, `knowledge distillation`, `prompt stealing`
- **출처**: arxiv recent · ACM SIGKDD 2025
- **arxiv abstract**: [2506.22521](https://arxiv.org/abs/2506.22521) (v1)
- **PDF**: [arxiv.org/pdf/2506.22521](https://arxiv.org/pdf/2506.22521.pdf)

**핵심 요약**: LLM에 대한 model extraction 공격을 functionality extraction, training data extraction, prompt-targeted attack 세 범주로 체계적으로 분류한 최초의 포괄적 서베이다. API 기반 knowledge distillation부터 parameter 복원, 프롬프트 탈취까지 다양한 공격 방법론을 분석하고, 방어 측은 model 보호, 데이터 프라이버시 보호, 프롬프트 보호 전략으로 정리한다. 배포 환경별 공격·방어 효과성을 비교하고, 공격 효과와 방어 성능을 평가할 전용 메트릭도 제안한다.

## 5. At the Edge of Understanding: Sparse Autoencoders Trace The Limits of Transformer Generalization 🆕

- **저자**: Praneet Suresh, Jack Stanley, Sonia Joseph, Luca Scimeca, Danilo Bzdok
- **키워드**: `sparse autoencoder`, `OOD detection`, `jailbreak hardening`, `spurious concepts`, `mechanistic interpretability`
- **출처**: arxiv recent · SNS
- **arxiv abstract**: [2606.26396](https://arxiv.org/abs/2606.26396) (v1)
- **PDF**: [arxiv.org/pdf/2606.26396](https://arxiv.org/pdf/2606.26396.pdf)

**핵심 요약**: Pre-trained transformer가 일반화에 실패하는 원인을 SAE로 mechanistic하게 분석한다. OOD 입력(오타, 적대적 프롬프트 포함)이 주어지면 모델 내부에서 spurious concept 활성화가 증가하며, 이를 통해 distributional shift 정도를 정량화할 수 있다. 이 발견을 활용해 OOD-aware fine-tuning 전략을 도출하며, SAE가 단순한 해석 도구를 넘어 jailbreak 강건화를 위한 surgical한 개입 수단이 될 수 있음을 보인다.

- **PDF**: [arxiv.org/pdf/2506.12699](https://arxiv.org/pdf/2506.12699.pdf)

**핵심 요약**: LLM이 방대한 웹 데이터와 사용자 인터랙션으로 학습되면서 발생하는 프라이버시 역설을 체계화한다. 프라이버시 문제를 (1) 학습 데이터 프라이버시, (2) 사용자 프롬프트 프라이버시, (3) LLM 출력 프라이버시, (4) LLM 에이전트 프라이버시 네 영역으로 분류하고 각각의 공격 벡터와 현존 방어 기법을 분석한다. 특히 멀티모달 LLM과 에이전트 환경에서 새롭게 등장하는 프라이버시 위협을 강조한다.

- **출처**: arxiv recent · SNS
- **arxiv abstract**: [2506.07402](https://arxiv.org/abs/2506.07402) (v1)
- **PDF**: [arxiv.org/pdf/2506.07402](https://arxiv.org/pdf/2506.07402.pdf)

**핵심 요약**: 기존 jailbreak 연구가 "명시적으로 유해한 질의"에 집중하는 동안, 겉보기에 무해한 입력에 대한 잘못된 답변(Implicit Harm)이라는 더 교묘한 위험을 간과해 왔음을 지적한다. 출력의 사실성과 입력의 무해성을 기준으로 LLM 위험 지형을 4사분면으로 재구성하고, 단일·다중 모달·사실 확장 시나리오를 망라한 JailFlipBench 벤치마크를 제안한다. 이 접근은 정렬 실패가 단순 거절 우회보다 훨씬 광범위한 보안 위협임을 드러낸다.

- **출처**: arxiv recent
- **arxiv abstract**: [2506.04250](https://arxiv.org/abs/2506.04250) (v1)
- **PDF**: [arxiv.org/pdf/2506.04250](https://arxiv.org/pdf/2506.04250.pdf)

**핵심 요약**: LLM 안전 정책 변경에 따른 재훈련 비용 문제를 해결하기 위해 inference-time activation steering 기반의 SafeSteer를 제안한다. 해악 카테고리별 steering vector를 추출해 세밀한 제어를 가능하게 하며, contrastive safe 데이터 없이도 gradient-free 방식으로 작동한다. 거절(refusal) 없이 안전 출력을 유도하는 refusal-evasion 방식으로 텍스트 품질과 주제 관련성을 유지하면서 기존 복잡한 baseline을 능가한다.

## 9. SoK: Machine Unlearning for Large Language Models 🆕

- **저자**: Jie Ren, Yue Xing, Yingqian Cui, Charu C. Aggarwal, Hui Liu
- **키워드**: `machine unlearning`, `gradient ascent`, `model editing`, `representation steering`, `knowledge removal`
- **출처**: arxiv recent · HF Daily Papers
- **arxiv abstract**: [2506.09227](https://arxiv.org/abs/2506.09227) (v1)
- **PDF**: [arxiv.org/pdf/2506.09227](https://arxiv.org/pdf/2506.09227.pdf)

**핵심 요약**: 기존 LLM unlearning 서베이들이 기술적 분류에 치우쳐 unlearning의 근본 의도—실제 지식 제거인지, 단순 행동 억제인지—를 구분하지 못하는 한계를 지적한다. "의도 기반 taxonomy"라는 새로운 분류 체계를 제안해 Gradient Ascent, model editing, representation re-steering 방법들을 재구성한다. 이 관점은 unlearning 방법이 단순히 사용자 관찰 가능한 행동을 숨기는지, 아니면 내부 표현에서 지식을 진정으로 제거하는지를 구분하는 기준을 제공한다.

## 10. GUARD: Guided Unlearning and Retention via Data Attribution for Large Language Models 🆕

- **저자**: Peizhi Niu, Evelyn Ma, Huiting Zhou, Duo Zhou, Huan Zhang, S. Rasoul Etesami, Olgica Milenkovic
- **키워드**: `machine unlearning`, `data attribution`, `unintended forgetting`, `LLM utility`, `UIUC`
- **출처**: arxiv recent
- **arxiv abstract**: [2506.10946](https://arxiv.org/abs/2506.10946) (v2)
- **PDF**: [arxiv.org/pdf/2506.10946](https://arxiv.org/pdf/2506.10946.pdf)

**핵심 요약**: LLM unlearning 시 특정 데이터 삭제가 의도치 않게 모델 유용성과 retain set 성능까지 훼손하는 문제(unintended forgetting)에 집중한다. Forget set과 Retain set 간의 정렬 정도를 경량화된 proxy data attribution 메트릭으로 정량화하는 GUARD 프레임워크를 제안하며, UIUC 연구팀의 계산 효율적 설계가 핵심이다. 다양한 벤치마크에서 기존 방법 대비 forget 효과를 유지하면서 retain 성능 저하를 최소화함을 검증한다.
