## 1. RedAct: Redacting Agent Capability Traces for Procedural Skill Protection 🆕

- **저자**: Shuwen Xu, Zhitao He, Yi R. Fung
- **키워드**: `agent security`, `capability trace`, `skill protection`, `watermark`, `procedural IP`
- **출처**: HF Daily 15 upvotes · GitHub 12 stars
- **arxiv abstract**: [2606.10813](https://arxiv.org/abs/2606.10813) (v2)
- **PDF**: [arxiv.org/pdf/2606.10813](https://arxiv.org/pdf/2606.10813.pdf)

**핵심 요약** (3-5문장 한국어):
에이전트 실행 추적(trace)이 절차적 스킬 유출의 취약점이 될 수 있다는 문제를 제기한다. 투명성·감사를 위해 공개된 trace는 도구 호출 순서, 임계값, 오류 복구 로직 등 핵심 절차 정보를 담고 있어 모델 가중치 없이도 스킬 복제가 가능하다. RedAct는 trace 내 민감 정보를 국소화·재작성하고 행동 워터마크를 삽입하는 보호 릴리즈 프레임워크로, CapTraceBench(75 태스크, 154 스킬, 7 도메인)에서 평가 시 정규화 스킬 전이율을 44.7–67.1%에서 no-skill 기준선 이하로 낮추면서 91.0–96.6%의 감사 증거를 보존한다. 워터마크는 93.6–100.0% 검출률에 최대 1.9% 오탐율을 달성하여, 에이전트 trace를 보안 인터페이스로 다루어야 한다는 새로운 패러다임을 제시한다.

## 2. Measuring Epistemic Resilience of LLMs Under Misleading Medical Context

- **저자**: Hongjian Zhou, Xinyu Zou, Jinge Wu, Sean Wu, Junchi Yu, ..., David A. Clifton (22인, Oxford et al.)
- **키워드**: `adversarial robustness`, `epistemic resilience`, `misleading context`, `medical LLM`, `prompt injection`
- **출처**: HF Daily 13 upvotes · Oxford
- **arxiv abstract**: [2606.12291](https://arxiv.org/abs/2606.12291) (v1)
- **PDF**: [arxiv.org/pdf/2606.12291](https://arxiv.org/pdf/2606.12291.pdf)

**핵심 요약** (3-5문장 한국어):
의료 AI에서 높은 벤치마크 점수가 실제 안전성을 보장하지 않는다는 취약점을 체계적으로 밝힌다. LLM이 원래 정답을 아는 문제에 오해 컨텍스트를 주입하면 정답을 포기하는 현상(에피스테믹 레질리언스 부재)을 정량화하기 위해 MedMisBench(10,932 문항, 48,889 컨텍스트-옵션 쌍)를 구축했다. 11개 모델 구성에서 평균 정확도가 71.1%에서 38.0%로 하락했으며(51.5% 공격 성공률), 권위 프레이밍 허위 정보는 69.5%, 예외 포이즈닝은 64.1%의 ASR을 기록했다. 7개국 14인 임상 패널이 검토 사례의 38.2%에서 심각한 잠재 위해를 식별하였으며, 기존 의료 LLM 평가가 오해 상황의 판단력을 무시했다는 구조적 맹점을 드러낸다.

다양한 언어로 작성된 jailbreak 공격을 단일 모델로 탐지하는 문제를 다룬다. 언어에 무관한 의도 표현을 학습하기 위해 역번역 증강(11개 언어)을 활용하여 언어 불변 표현 공간을 구축한다. 학습 언어에서 F1=98.5%, 미학습 언어 평균 F1=97.1%를 달성하여 강력한 cross-lingual 일반화 성능을 증명한다. 단일 탐지 모델로 다국어 jailbreak 공격에 대응 가능한 효율적이고 확장 가능한 접근법을 제공한다.

## 4. The Arbiter Agent: Continually Monitoring Multi-Agent Conversations to Detect Emergent Misalignment

- **저자**: Filippo Tonini, Federico Torrielli, Anton Danholt Lautrup, Peter Schneider-Kamp, Mustafa Mert Çelikok, Lukas Galke Poech (SDU Denmark)
- **키워드**: `agent safety`, `multi-agent`, `misalignment detection`, `oversight`, `inspection budget`
- **출처**: HF Daily 6 upvotes · AITC 2026 · GitHub 5 stars
- **arxiv abstract**: [2606.10747](https://arxiv.org/abs/2606.10747) (v1)
- **PDF**: [arxiv.org/pdf/2606.10747](https://arxiv.org/pdf/2606.10747.pdf)

**핵심 요약** (3-5문장 한국어):
다중 에이전트 LLM 대화에서 잘못 정렬된(misaligned) 참여자를 실시간으로 탐지하는 Arbiter 에이전트를 제안한다. Arbiter는 제한된 검사 예산 내에서 대기, 질의, 내부 정보(시스템 프롬프트, 추론 추적) 확인, 행동 기록 중 최적 행동을 선택한다. 5가지 대화 조건(금융 조언 모형, 평가 인식 에이전트, 공모 에이전트 등), 5가지 도구 구성, 2개 백본 모델로 평가한 결과 대화 종료 전에 misaligned 에이전트를 신뢰성 있게 탐지했다. 가중치 유도 misalignment가 탐지가 가장 어렵고 지시 유도 misalignment는 수동 관찰만으로도 신뢰성 있게 식별되었으며, 감사자를 능동적 참여자로 배치하는 지속적 예산인식 모니터링의 실효성을 입증했다.

- **출처**: HF Daily 14 upvotes · Google DeepMind
- **arxiv abstract**: [2606.12683](https://arxiv.org/abs/2606.12683) (v1)

**핵심 요약** (3-5문장 한국어):
AGI 달성 이후 인공 초지능(ASI)으로의 전환 경로와 위험을 분석한 Google DeepMind 기술 보고서다. ASI로 가는 4가지 경로(AGI 스케일링, AI 패러다임 전환, 재귀적 자기 개선, 대규모 멀티에이전트 집합체)를 특성화하고 각 경로의 마찰과 병목을 논의한다. 불확실성이 크기 때문에 단일 변혁적 변화점보다는 연속적 사회 변화가 더 현실적일 수 있으며 범세계적·학제적 준비가 필요하다고 강조한다. Shane Legg, Allan Dafoe, Marcus Hutter 등 AI 안전 분야 핵심 연구자들이 참여한 포괄적 AI 안전 로드맵이다.

## 6. ClinHallu: A Benchmark for Diagnosing Stage-Wise Hallucinations in Medical MLLM Reasoning

- **키워드**: `hallucination diagnosis`, `MLLM reasoning`, `stage-wise`, `interpretability`, `medical AI`
- **출처**: HF Daily 5 upvotes · Alibaba DAMO · GitHub 공개
- **arxiv abstract**: [2606.14697](https://arxiv.org/abs/2606.14697) (v1)
- **PDF**: [arxiv.org/pdf/2606.14697](https://arxiv.org/pdf/2606.14697.pdf)

**핵심 요약** (3-5문장 한국어):
의료 MLLM 추론에서 환각이 어느 단계(시각 오인식 / 의료 지식 회상 오류 / 추론 통합 실패)에서 발생하는지 진단하는 ClinHallu 벤치마크를 제안한다. Visual Recognition, Knowledge Recall, Reasoning Integration으로 분해된 구조화 추론 추적이 포함된 7,031개 검증 인스턴스를 구축했다. 특정 단계 교정이 최종 답변에 미치는 영향을 측정하는 stage-replacement 실험을 도입하였으며, trace 지도 미세조정(trace-supervised fine-tuning)이 단계별 환각을 감소시킴을 보였다. 기존 의료 환각 벤치마크가 데이터 수집에만 집중하고 환각 원인 진단을 무시했다는 한계를 극복하는 세밀한 해석 가능성 도구를 제공한다.

## 7. Quickest Detection of Hallucination Onset: Delay Bounds and Learned CUSUM Statistics 🆕

- **저자**: Igor Itkin
- **키워드**: `hallucination detection`, `CUSUM`, `change-point detection`, `streaming monitor`, `LLM safety`
- **출처**: HF Daily · arxiv cs.LG
- **arxiv abstract**: [2606.12476](https://arxiv.org/abs/2606.12476) (v2)
- **PDF**: [arxiv.org/pdf/2606.12476](https://arxiv.org/pdf/2606.12476.pdf)

**핵심 요약** (3-5문장 한국어):
토큰 수준 환각 탐지를 분류 문제 대신 최속 변화점 탐지(quickest change detection) 문제로 재정의하여 탐지 지연의 이론적 하한을 도출한다. RAGTruth에서 검증된 1차 Markov 모델로 faithful/hallucinated 상태를 모델링하여 FAR=0.01 기준 Lorden 하한 약 1.3 토큰을 달성한다. CUSUM 통계를 학습한 인과적 순환 레이블러가 11–13 토큰 만에 탐지하는 반면 선형 기준은 31 토큰이 소요됨을 보여주었다. 정보율 최적성 정리(Donsker-Varadhan 타입)가 학습 점수가 특징이 담고 있는 다이버전스의 1/4.5만 실현함을 밝혀, AUC 기반 분류 지표가 스트리밍 탐지 성능을 오도한다는 핵심 통찰을 제시한다.

## 8. Memory is Reconstructed, Not Retrieved: Graph Memory for LLM Agents *(인접 분야)*

- **저자**: Shuo Ji, Yibo Li, Bryan Hooi (National University of Singapore)
- **키워드**: `agent memory`, `associative memory graph`, `active reconstruction`, `long-horizon reasoning`, `MRAgent`
- **출처**: HF Daily #1 Paper of Day (Jun 15) · NUS · GitHub 23 stars
- **arxiv abstract**: [2606.06036](https://arxiv.org/abs/2606.06036) (v1)
- **PDF**: [arxiv.org/pdf/2606.06036](https://arxiv.org/pdf/2606.06036.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 에이전트의 긴 상호작용 이력에 대한 추론 한계를 극복하기 위해 연상 메모리 그래프와 능동 재구성 메커니즘을 결합한 MRAgent를 제안한다. 메모리를 Cue-Tag-Content 그래프로 표현하고, 추론 과정에서 LLM이 직접 메모리 접근 경로를 탐색·가지치기하여 동적으로 컨텍스트에 적응한다. LoCoMo 및 LongMemEval 벤치마크에서 기존 최강 기준 대비 최대 23% 성능 개선을 달성하면서 토큰·런타임 비용을 동시에 절감한다. 에이전트 장기 메모리의 동적 접근 패턴은 메모리 포이즈닝 및 프라이버시 유출 위험과 연관된 중요 연구 방향이다.

## 10. APPO: Agentic Procedural Policy Optimization *(인접 분야)*

- **저자**: Xucong Wang, Ziyu Ma, Yong Wang, Yuxiang Ji, Shidong Yang, Guanhua Chen, Pengkun Wang, Xiangxiang Chu
- **키워드**: `agentic RL`, `credit assignment`, `branching score`, `behavior interpretability`, `tool-use agent`
- **출처**: HF Daily 53 upvotes
- **arxiv abstract**: [2606.12384](https://arxiv.org/abs/2606.12384) (v1)
- **PDF**: [arxiv.org/pdf/2606.12384](https://arxiv.org/pdf/2606.12384.pdf)

**핵심 요약** (3-5문장 한국어):
다중 턴 에이전트 강화학습에서 세밀한 결정 지점에서의 분기와 크레딧 배분을 개선하는 APPO를 제안한다. 파일럿 분석 결과 영향력 있는 결정 지점이 도구 호출 경계가 아닌 시퀀스 전체에 분산되어 있으며 토큰 엔트로피만으로는 최종 결과에 대한 영향을 신뢰성 있게 반영하지 못함을 밝혔다. Branching Score(토큰 불확실성과 정책 유도 가능성 이득의 결합)로 분기 위치를 선정하고 절차 수준 어드밴티지 스케일링으로 크레딧을 배분한다. 13개 벤치마크에서 강력한 기준 대비 평균 4포인트 개선을 달성하면서 행동 해석 가능성(behavior interpretability)을 유지한다.
