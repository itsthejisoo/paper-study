## 1. Pressure-Testing Deception Probes in LLMs: Scaling, Robustness, and the Geometry of Deceptive Representations 🆕

- **저자**: Sachin Kumar
- **키워드**: `probing`, `deception detection`, `linear probe`, `representation geometry`, `distributional shift`
- **출처**: HF Daily
- **arxiv abstract**: [2605.27958](https://arxiv.org/abs/2605.27958) (v1)
- **PDF**: [arxiv.org/pdf/2605.27958](https://arxiv.org/pdf/2605.27958.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 활성화 값으로 학습된 선형 프로브(linear probe)가 기만(deception) 탐지 지표로 자주 제안되지만, 분포 이동(distributional shift) 하에서는 성능이 급격히 떨어진다는 문제가 있다. 이 논문은 Gemma 3 모델 패밀리(1B~27B)에서 프로브 기반 지표를 4가지 가설(단일 선형 방향, 다차원 부분공간, 볼록 원뿔, 엔트로피 프록시)로 체계적으로 압박 테스트한다. 핵심 발견은 (a) 스타일 이동 하에서 프로브 AUROC가 0.998 이상 → 붕괴하나, 스타일 증강 프로브는 미등장 스타일에서도 평균 AUROC 0.979~0.983을 회복하고, (b) 기만 표현이 유의미한 선형 부분공간을 형성하지 않아 k=1 방향은 AUROC 0.61~0.80에 불과하지만 k≥5 다차원 프로브로 분산 신호를 포착할 수 있음을 보인다. 프로브 취약성은 훈련 분포의 협소함에 기인하며, 스케일 의존 역설처럼 보이는 현상도 훈련 데이터 아티팩트임이 밝혀졌다.

- **출처**: HF Daily
- **arxiv abstract**: [2606.01494](https://arxiv.org/abs/2606.01494) (v1)
- **PDF**: [arxiv.org/pdf/2606.01494](https://arxiv.org/pdf/2606.01494.pdf)

**핵심 요약** (3-5문장 한국어):
AI 에이전트 스킬 마켓플레이스(ClawHub)에서 VirusTotal 스캔, 정적 분석(ClawScan), NVIDIA SkillSpector라는 세 독립 보안 스캐너가 서로 다른 결론을 내릴 때 어떻게 판단해야 하는가를 분석한 논문이다. SkillSpector는 전통적 악성코드 탐지를 넘어 숨겨진 지시, 위험 코드 경로, 과도한 권한 등을 AI 시맨틱 분석으로 탐지하는 반면, VirusTotal은 알려진 서명 기반 위협에 집중한다. 세 스캐너의 불일치를 분류하고 각 유형별로 해석 전략(합의 우선 vs. 의심 스킬 보류 등)을 제안하며, 실제 ClawHub 감사 사례를 통해 단일 스캐너에 의존할 경우 놓치는 취약점 유형을 구체적으로 보여준다. AI 에이전트 생태계의 공급망 보안에서 다층 스캔의 필요성과 불일치 해석 방법론을 정리한 점에서 실용적 가치가 높다.

- **arxiv abstract**: [2602.11495](https://arxiv.org/abs/2602.11495) (v2)
- **PDF**: [arxiv.org/pdf/2602.11495](https://arxiv.org/pdf/2602.11495.pdf)

**핵심 요약** (3-5문장 한국어):
제일브레이크 공격이 LLM 내부 표현에 어떤 흔적을 남기는지를 보안과 해석가능성 관점에서 동시에 분석한 논문이다. GPT-J, LLaMA, Mistral, Mamba 등 다양한 오픈소스 모델에서 다중 헤드 어텐션·레이어 출력의 레이어별 분석을 수행하고, 텐서 분해(tensor decomposition) 기법으로 유해 입력과 정상 입력 사이의 잠재 공간 패턴 차이를 특징화한다. 이를 통해 적대적 조작에 특히 취약한 레이어를 식별하고, 추론 중 해당 레이어에 개입(intervention)하여 제일브레이크를 78% 차단하면서 정상 요청의 94%는 정상 처리하는 방어 효과를 입증했다. 내부 표현이 제일브레이크 탐지의 강력한 시그널이 될 수 있음을 실증적으로 보여주며, v2에서 일반화 실험과 분석이 보강되었다.

## 4. Robust Safety Monitoring of Language Models via Activation Watermarking 🆕

- **저자**: Toluwani Aremu, Daniil Ognev, Samuele Poppi, Nils Lukas (Mohamed Bin Zayed University of Artificial Intelligence)
- **키워드**: `safety monitoring`, `activation watermarking`, `adaptive attacker`, `red-teaming defense`, `AI security`
- **출처**: SNS
- **arxiv abstract**: [2603.23171](https://arxiv.org/abs/2603.23171) (v1)
- **PDF**: [arxiv.org/pdf/2603.23171](https://arxiv.org/pdf/2603.23171.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 제공자가 유해 행동을 탐지하기 위해 사용하는 안전 모니터가 적응형 공격자(adaptive adversary), 즉 모니터 알고리즘은 알지만 비밀 키는 모르는 공격자에게 취약함을 보이고, 이에 대한 방어로 활성화 워터마킹(activation watermarking)을 제안한다. 활성화 워터마킹은 추론 시 비밀 키 기반의 불확실성 신호를 모델 내부 표현에 주입하여, 공격자가 모니터를 우회하면서 동시에 유해 출력을 얻는 것을 어렵게 만드는 방식이다. 실험 결과, 기존 가드 기준선 대비 적응형 공격자 환경에서 최대 52%까지 탐지 성능을 향상시켰다. 보안-감시 게임(security game) 프레임워크로 LLM 모니터링 문제를 공식화하고 적응형 공격을 명시적으로 고려한 첫 방어 체계를 제시한다는 점에서 의미가 크다.

## 5. SkillSieve: A Hierarchical Triage Framework for Detecting Malicious AI Agent Skills 🆕

- **저자**: Yinghan Hou (Imperial College London), Zongyou Yang (UCL)
- **키워드**: `agent security`, `malicious skill detection`, `XGBoost`, `LLM triage`, `skill marketplace`
- **출처**: SNS
- **arxiv abstract**: [2604.06550](https://arxiv.org/abs/2604.06550) (v1)
- **PDF**: [arxiv.org/pdf/2604.06550](https://arxiv.org/pdf/2604.06550.pdf)

**핵심 요약** (3-5문장 한국어):
ClawHub 마켓플레이스에 등록된 13,000개 이상의 에이전트 스킬 중 13~26%가 보안 취약점을 포함하고 있으며, 기존 정규식 스캐너나 정형 정적 분석기는 SKILL.md의 자연어 지시 내 프롬프트 인젝션 공격을 탐지하지 못한다는 문제를 다룬다. SkillSieve는 3계층 탐지 파이프라인으로, Layer 1은 XGBoost 기반 특징 스코어러로 86%의 정상 스킬을 평균 40ms 이하로 필터링하고, Layer 2는 의심 스킬을 4개 병렬 서브태스크(의도 일치, 권한 정당성, 은닉 행동, 크로스파일 일관성)로 LLM 분석하며, Layer 3는 고위험 스킬에 대해 3개 LLM이 독립적으로 투표하고 불일치 시 토론을 거친다. 이 계층적 접근으로 탐지 정확도를 높이면서 API 비용을 최소화하는 실용적인 대규모 스킬 보안 검사 체계를 구축한다.

## 6. Under the Hood of SKILL.md: Semantic Supply-chain Attacks on AI Agent Skill Registry 🆕

- **출처**: SNS
- **arxiv abstract**: [2605.11418](https://arxiv.org/abs/2605.11418) (v1)
- **PDF**: [arxiv.org/pdf/2605.11418](https://arxiv.org/pdf/2605.11418.pdf)

**핵심 요약** (3-5문장 한국어):
AI 에이전트가 스킬을 확장하는 SKILL.md 파일의 자연어 메타데이터와 지시가 공급망 공격의 시맨틱 취약점이 됨을 체계적으로 분석한 논문이다. 탐색(Discovery) 단계에서 짧은 텍스트 트리거로 임베딩 기반 검색을 조작해 악성 스킬 노출도를 높이는 데 최대 86%의 쌍별 승률(pairwise win rate)과 상위 10 배치율 80%를 달성한다. 선택(Selection) 단계에서는 설명 프레이밍(description-only framing)만으로도 에이전트가 기능적으로 동등한 악성 스킬 변종을 평균 77.6%의 경우에 선택하도록 유도할 수 있음을 보인다. 이는 레지스트리 디스커버리부터 에이전트 선택까지 전 파이프라인에 걸쳐 시맨틱 공격이 가능함을 보여주며, 에이전트 스킬 생태계의 새로운 공격 면(attack surface)을 정의한다.

## 8. AttenMIA: LLM Membership Inference Attack through Attention Signals 🆕

- **저자**: Pedram Zaree, Md Abdullah Al Mamun, Yue Dong, Ihsen Alouani, Nael Abu-Ghazaleh (UC Riverside)
- **키워드**: `membership inference`, `attention mechanism`, `privacy`, `LLM memorization`, `data extraction`
- **출처**: SNS
- **arxiv abstract**: [2601.18110](https://arxiv.org/abs/2601.18110) (v1)
- **PDF**: [arxiv.org/pdf/2601.18110](https://arxiv.org/pdf/2601.18110.pdf)

**핵심 요약** (3-5문장 한국어):
LLM의 셀프 어텐션 패턴이 훈련 데이터 멤버십 정보를 누출한다는 사실에 착안하여, 어텐션 헤드 전반의 정보와 퍼터베이션 기반 발산 지표를 결합한 MIA 분류기 AttenMIA를 제안한다. LLaMA-2, Pythia, OPT 모델에서의 실험에서 WikiMIA-32 벤치마크 Llama2-13b 기준 ROC AUC 0.996, TPR@1%FPR 87.9%를 달성하며, 어텐션 기반 특징이 기존 출력 신뢰도·임베딩 기반 방법을 일관되게 능가함을 보인다. 나아가 AttenMIA를 데이터 추출 프레임워크에 통합하면 훈련 데이터 추출 공격의 성능도 최고 수준으로 향상됨을 실증한다. 해석가능성을 위해 도입된 어텐션 메커니즘이 역설적으로 프라이버시 위험을 증폭시킬 수 있다는 발견은 LLM 설계와 방어에 시사하는 바가 크다.

## 9. Toward Efficient Membership Inference Attacks against Federated Large Language Models: A Projection Residual Approach 🆕

- **저자**: (미기재, arxiv 2604.21197)
- **키워드**: `membership inference`, `federated LLM`, `gradient privacy`, `projection residual`, `ProjRes`
- **출처**: SNS
- **arxiv abstract**: [2604.21197](https://arxiv.org/abs/2604.21197) (v1)
- **PDF**: [arxiv.org/pdf/2604.21197](https://arxiv.org/pdf/2604.21197.pdf)

**핵심 요약** (3-5문장 한국어):
연합 학습(Federated Learning) 기반 LLM(FedLLM)은 원시 데이터 공유 없이 협력 파인튜닝을 가능하게 하지만, 공유되는 그래디언트가 MIA를 통해 개인 정보를 노출할 수 있다. 기존 MIA 방법은 FedLLM의 대규모 파라미터, 빠른 수렴, 희소하고 비직교적인 그래디언트라는 특성으로 인해 효과가 낮은데, ProjRes는 이를 극복하기 위해 숨겨진 임베딩 벡터를 샘플 표현으로 사용하고 그래디언트 부분공간에 대한 투영 잔차(projection residual)를 분석하여 그래디언트와 입력 간의 내재적 연결을 활용한다. FedLLM에 특화된 최초의 수동적(passive) MIA로, 높은 공격 성공률과 효율성을 동시에 달성하며 연합 학습이 제공하는 프라이버시 보호의 실질적 한계를 드러낸다.

## 10. Be Your Own Red Teamer: Safety Alignment via Self-Play and Reflective Experience Replay 🆕

- **저자**: (SSP 팀, arxiv 2601.10589)
- **키워드**: `red-teaming`, `safety alignment`, `self-play`, `reinforcement learning`, `jailbreak`
- **출처**: SNS
- **arxiv abstract**: [2601.10589](https://arxiv.org/abs/2601.10589) (v1)
- **PDF**: [arxiv.org/pdf/2601.10589](https://arxiv.org/pdf/2601.10589.pdf)

**핵심 요약** (3-5문장 한국어):
현재의 안전 정렬 방법들이 정적 외부 레드팀 데이터에 의존하여 새로운 공격 패턴에 취약하다는 문제를 해결하기 위해, 단일 LLM이 공격자(제일브레이크 생성)와 방어자(유해 요청 거부)를 동시에 수행하는 Safety Self-Play(SSP)를 제안한다. 통합 강화학습 루프 내에서 공격 전략이 동적으로 진화하며, 동시에 방어 메커니즘도 강화되는 공진화(co-evolution) 구조를 갖는다. 실패 사례에 대한 UCB(Upper Confidence Bound) 샘플링 전략을 사용하는 반성적 경험 재연(Reflective Experience Replay) 메커니즘을 통해, 과거 어려운 사례에서 학습하면서 탐색과 활용의 균형을 맞춘다. 정적 적대적 데이터셋으로 훈련한 기준선 대비 현저히 향상된 방어 성능을 보이며, 자율적으로 진화하는 안전 정렬의 새로운 패러다임을 제시한다.
