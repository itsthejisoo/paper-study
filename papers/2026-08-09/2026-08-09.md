## 3. A Survey on Long-Term Memory Security in LLM Agents: Attacks, Defenses, and Governance Across the Memory Lifecycle  🔄 Updated v1 → v2

- **저자**: Zehao Lin, Xixuan Hao, Renyu Fu, Shaobo Cui, Kai Chen, et al.
- **키워드**: `agent safety`, `memory poisoning`, `privacy leakage`, `prompt injection`
- **출처**: SNS
- **arxiv abstract**: [2604.16548](https://arxiv.org/abs/2604.16548) (v2)
- **PDF**: [arxiv.org/pdf/2604.16548](https://arxiv.org/pdf/2604.16548.pdf)

**핵심 요약** (3-5문장 한국어):
쓰기 가능한 장기기억은 공격을 세션 간에 지속시키고 다른 에이전트로 전파하는 별도 보안 경계를 만든다. 서베이는 쓰기부터 저장, 검색, 실행, 공유·전파, 망각·롤백까지 여섯 단계를 네 보안 목표와 교차해 정리한다. 새 Verifiable Memory Governance는 감사와 복구가 가능한 통제를 위한 다섯 아키텍처 원칙을 제안한다. 강건한 방어는 검색 시점에 덧붙이기보다 저장 시점의 출처와 버전, 보존 정책에서 시작해야 한다고 결론짓는다.

**v1 → v2 변경점**: 제목과 저자 구성이 크게 바뀌고, 초록의 Mnemonic Sovereignty 중심 서술이 다섯 원칙의 Verifiable Memory Governance로 재구성됐다. 저장 시점 출처·버전·보존 정책의 중요성이 새 결론으로 명시됐다.

**핵심 요약** (3-5문장 한국어):

- **출처**: arxiv recent
- **arxiv abstract**: [2608.05163](https://arxiv.org/abs/2608.05163) (v1)
- **PDF**: [arxiv.org/pdf/2608.05163](https://arxiv.org/pdf/2608.05163.pdf)

**핵심 요약** (3-5문장 한국어):
비영어 질의가 영어 문서 기반 RAG의 개인정보 유출을 늘린다는 통념을 단계별로 검증한다. 동일한 Qwen2.5-7B를 번역기와 판정기, 생성기로 사용해 다섯 질의 언어를 비교했다. 출력 필터만 적용하면 영어의 비정형 PII 유출이 가장 높았고, 입력 판정기를 추가해도 아랍어와 스와힐리어에 잔여 유출이 남았다. 정답 문서를 판정기에 붙이면 17개 잔여 셀 중 15개를 막았지만, 오라클 검색에 의존해 배포 가능한 방어는 아니다.
