## 1. RepSelect: Robust LLM Unlearning via Representation Selectivity  🆕

- **저자**: Filip Sondej, Yushi Yang, Adam Mahdi
- **소속**: University of Oxford
- **키워드**: `LLM unlearning`, `representation selectivity`, `robust forgetting`, `fine-tuning attack`, `biohazardous knowledge`
- **출처**: HF Daily (Jun 17, ⬆2)
- **arxiv abstract**: [2606.17168](https://arxiv.org/abs/2606.17168) (v1)
- **PDF**: [arxiv.org/pdf/2606.17168](https://arxiv.org/pdf/2606.17168.pdf)
- **GitHub**: https://github.com/filyp/RepSelect

**핵심 요약** (3-5문장 한국어):
LLM에서 특정 지식(생물 위험, 유해 성향 등)을 제거하면서 일반 능력은 유지하는 것이 핵심 과제인데, 기존 방법들은 파인튜닝이나 few-shot 프롬프팅으로 쉽게 복원된다는 문제가 있다. 이 논문은 근본 원인을 규명하여, 기존 방법이 forget set과 retain set이 공유하는 표현을 타겟으로 해 얕은 언러닝만 달성함을 보인다. 제안하는 RepSelect는 weight gradient의 상위 주성분(principal components)을 업데이트 전에 붕괴시켜 forget set 특화 표현만을 격리함으로써, 일반 능력은 보존하면서 파인튜닝 공격자가 복원할 수 있는 공간을 제한한다. Llama 3, Qwen 3.5, Gemma 4 E4B, DeepSeek V2 Lite 등 4개 모델 패밀리에서 5개 베이스라인(GradDiff, NPO, SimNPO, RMU, UNDIAL) 대비 재학습 후 정답 정확도를 4–50배 더 크게 감소시키며 few-shot 공격에도 거의 완벽하게 강건함을 보인다.

## 2. DoubtProbe: Black-Box Jailbreak Defense via Structural Verification and Semantic Auditing  🆕

- **키워드**: `jailbreak defense`, `black-box`, `structural verification`, `semantic auditing`, `inference-time defense`
- **출처**: arxiv recent (cs.CR, Jun 16)
- **arxiv abstract**: [2606.16527](https://arxiv.org/abs/2606.16527) (v1)
- **PDF**: [arxiv.org/pdf/2606.16527](https://arxiv.org/pdf/2606.16527.pdf)

**핵심 요약** (3-5문장 한국어):
많은 블랙박스 탈옥 공격은 해로운 목표를 제거하지 않고 정보를 재조직해 안전 정렬을 우회하는데, DoubtProbe는 이 패턴을 역이용하는 이중 분기(dual-branch) 추론 시점 방어 프레임워크이다. 구조 브랜치는 원본 요청에서 구조적 표현을 추출·재구성해 정보 보존 실패를 탐지하며, 의미 브랜치는 원본 프롬프트를 직접 감사한다. 탈옥 방어를 "통제된 변환 하에서의 일관성 검사"로 정식화하여 블랙박스 공격에 대한 새로운 관점을 제공한다. Qwen2.5-72B에서 JBB 공격 성공률을 0.293→0.100으로, CodeAttack 성공률을 0.152→0.001로 감소시키며 Llama-3.1-70B으로의 백본 전이도 확인하였다.

## 3. Let Them Steal: Trapping Large Language Model Extraction Attacks with Knowledge Honeypot  🆕

- **저자**: Yuyang Dai, Yushun Dong
- **키워드**: `model extraction`, `model stealing`, `knowledge honeypot`, `trapping attack`, `LLM IP protection`
- **출처**: arxiv recent (cs.CR, Jun 16)
- **arxiv abstract**: [2606.15810](https://arxiv.org/abs/2606.15810) (v1)
- **PDF**: [arxiv.org/pdf/2606.15810](https://arxiv.org/pdf/2606.15810.pdf)

**핵심 요약** (3-5문장 한국어):
LLM 추출 공격(model extraction attack)은 피해 모델 API를 반복 쿼리하여 지식을 훔치는 방식으로 지적재산권 보호를 위협한다. 이 논문은 "훔치게 두되, 함정을 놓는다(Let Them Steal)"는 새로운 방어 패러다임을 제안하여, 공격자의 쿼리 응답에 지식 허니팟(knowledge honeypot)을 삽입한다. 허니팟에 오염된 지식이 훔쳐간 모델에 임베드되면 도난 사실을 탐지하거나 추출된 모델의 특정 동작을 사후에 제어하는 데 활용할 수 있다. 이 방식은 정상 서비스를 방해하지 않으면서 공격자를 수동적으로 추적하거나 역공할 수 있는 IP 보호 방향을 제시한다.

## 4. GAS-Leak-LLM: Genetic Algorithm-Based Suffix Optimization for Black-Box LLM Jailbreaking  🆕

- **저자**: Aman Anifer, Vignesh Kumar Kembu, Vishnu M, Antonino Nocera, Vinod P., Amal Murali PK, Akshay S Rajan
- **키워드**: `jailbreak`, `genetic algorithm`, `suffix optimization`, `black-box attack`, `adversarial prompt`
- **출처**: arxiv recent (cs.CR, Jun 16)
- **arxiv abstract**: [2606.15788](https://arxiv.org/abs/2606.15788) (v1)
- **PDF**: [arxiv.org/pdf/2606.15788](https://arxiv.org/pdf/2606.15788.pdf)

**핵심 요약** (3-5문장 한국어):
GCG와 같은 기존 LLM 탈옥 공격은 gradient 접근이 필요한 화이트박스 환경에만 적용 가능해 실제 상용 API 공격에 한계가 있다. GAS-Leak-LLM은 유전자 알고리즘(GA)을 활용한 적대적 접미사(adversarial suffix) 최적화로 gradient 없이 블랙박스 LLM 탈옥을 실현한다. GA 기반 진화 검색을 통해 효과적인 탈옥 접미사를 발견하고, 상용 LLM API에서의 공격 성공을 실험적으로 입증한다. 이 연구는 블랙박스 공격 표면의 취약성을 드러내어 gradient-free 적대적 공격에 강건한 안전 정렬 방법 개발의 필요성을 제기한다.

- **arxiv abstract**: [2606.15899](https://arxiv.org/abs/2606.15899) (v1)
- **PDF**: [arxiv.org/pdf/2606.15899](https://arxiv.org/pdf/2606.15899.pdf)

**핵심 요약** (3-5문장 한국어):
오픈소스 LLM 에이전트 생태계에서 커뮤니티 기여 스킬 모듈의 보안이 대부분 검증되지 않은 문제가 있으며, 기존 코드 스캐너는 인스트럭션 레이어 및 멀티에이전트 리스크를 탐지하지 못한다. SkillVetBench는 LLM-as-Judge 기반으로 스킬 아티팩트 전체를 의미적으로 분석하여 다차원 보안 위험을 평가하며, 5차원 에이전트 위험 점수인 SARS(Skill Agentic Risk Score)와 CVSS v4.0 벡터 분해를 도입한다. 인스트럭션 기반 에이전트 하이재킹, 사이드 채널 데이터 유출, 파이프라인 체인 공격 등 코드 스캐너가 놓치는 새로운 공격 벡터를 식별한다. HuggingFace 라이브 리더보드를 통해 공개 평가를 지원하며 오픈소스 에이전트 생태계의 공급망 보안을 강화한다.

## 6. InstantForget: Update-Free Backdoor Unlearning with Inference-Time Feature Reset  🆕

- **저자**: Zhenyu Yu
- **키워드**: `backdoor unlearning`, `inference-time defense`, `feature reset`, `update-free`, `backdoor removal`
- **출처**: arxiv recent (cs.LG, Jun 15)
- **arxiv abstract**: [2606.15730](https://arxiv.org/abs/2606.15730) (v1)
- **PDF**: [arxiv.org/pdf/2606.15730](https://arxiv.org/pdf/2606.15730.pdf)

**핵심 요약** (3-5문장 한국어):
배포 후 발견된 백도어를 제거하려면 통상 재학습이나 파인튜닝이 필요해 계산 비용이 크고 실용성이 낮다. InstantForget은 가중치 업데이트 없이 추론 시점에서만 백도어를 제거하는 경량 방어 프레임워크로, 트리거에 민감한 방향을 추정하여 직교 투영(orthogonal projection)으로 선형 기여를 제거하는 특징 리셋(feature reset)을 수행한다. 깨끗한 정확도를 1% 이내로 유지하면서 공격 성공률을 최대 90%까지 감소시키는 성능을 MNIST, CIFAR-10, ImageNet-Subset에서 입증한다. 에너지 효율적이고 배포 친화적인 사후 백도어 방어 방안으로 실용적 가치가 높다.

## 7. SACE: Concept Erasure at the Semantic Singularity in Visual Autoregressive Models  🆕

- **저자**: Siya Yang, Nanxiang Jiang, Zhaoxin Fan, Yunfeng Diao
- **키워드**: `concept erasure`, `unlearning`, `visual autoregressive model`, `semantic singularity`, `image generation safety`
- **출처**: arxiv recent (cs.CV, Jun 15)
- **arxiv abstract**: [2606.15819](https://arxiv.org/abs/2606.15819) (v1)
- **PDF**: [arxiv.org/pdf/2606.15819](https://arxiv.org/pdf/2606.15819.pdf)

**핵심 요약** (3-5문장 한국어):
시각적 자기회귀(Visual Autoregressive, VAR) 모델은 이미지를 토큰 단위로 순차 생성하는 새로운 패러다임으로, 유해 콘텐츠나 저작권 스타일의 안전한 제거가 필요하다. SACE는 VAR 모델 내에서 특정 개념이 가장 집중되는 "의미 특이점(semantic singularity)" 레이어를 식별하고, 해당 레이어에만 국소 개입하여 타깃 개념을 정밀하게 소거한다. 이를 통해 전체 재학습 없이도 NSFW 콘텐츠, 유명인 얼굴, 저작권 스타일 등을 효과적으로 제거하면서 모델 전반의 생성 품질을 유지한다. VAR 아키텍처에 특화된 최초의 개념 소거 프레임워크로, 이미지 생성 모델 배포의 안전성을 높인다.

## 8. Verified Detection and Prevention of Concurrency Anomalies in Multi-Agent Large Language Model Systems  🆕

- **저자**: Sajjad Khan
- **키워드**: `multi-agent LLM`, `concurrency anomaly`, `TLA+`, `formal verification`, `agent safety`
- **출처**: HF Daily (Jun 17, ⬆0)
- **arxiv abstract**: [2606.17182](https://arxiv.org/abs/2606.17182) (v1)
- **PDF**: [arxiv.org/pdf/2606.17182](https://arxiv.org/pdf/2606.17182.pdf)

**핵심 요약** (3-5문장 한국어):
멀티에이전트 LLM 시스템은 메모리 스토어, 벡터 인덱스, 도구 레지스트리를 공유 상태로 활용하는데, 이로 인해 고전적 데이터베이스 고립(isolation) 이상과 유사한 동시성 버그가 발생한다. 이 논문은 읽기-생성-쓰기 연산을 TLA+로 공식화하여 stale-generation, phantom-tool, causal-cascade, tool-effect reordering 등 4가지 동시성 이상을 정의하고 TLC 반례로 검증한다. 274개의 Verus 의무(obligation)로 탐지기의 건전성과 완전성을 기계 검증하고, ByteDance deer-flow의 무음 손실 업데이트와 LangGraph ToolNode의 tool-effect reordering을 실제 버그로 재현하며 형식 수정을 제안한다. 멀티에이전트 LLM 런타임에 대한 최초의 기계 검증 일관성 계층(L0–L4)을 제공한다.
