## 1. [SAE Interventions are Unreliable: Post-Intervention Recovery of Suppressed Behavior](https://arxiv.org/abs/2606.18322)

**분류:** LLM Interpretability / AI Security
**arxiv:** 2606.18322 v1 | 2026-06-16
**출처:** HuggingFace Daily Papers (Jun 18)
**저자:** Mingyue Cui, Linghui Shen, Xingyi Yang

### 요약

**문제 정의:**
SAE(Sparse Autoencoder) 기반 latent-space 방어는 "안전하지 않은" feature를 클램핑(clamping)해 모델의 유해 행동을 억제할 수 있다고 가정한다. 그러나 이 방식이 실제로 행동을 완전히 제거하는지, 아니면 단순히 한 경로만 차단하는지는 검증되지 않았다.

**해결 방법 (제안 기법):**
post-intervention recovery를 constrained residual-space 최적화 문제로 공식화한다. 개입 이후의 residual state에서 출발해, targeted SAE feature 값은 유지하면서 사전 개입 행동을 복원하는 residual perturbation을 최적화한다. single-layer 개입에는 encoder-orthogonal update, cross-layer 설정에는 feature-map Jacobian을 사용해 개입 자체를 되돌리는 trivial solution을 배제한다.

**결과 (정확한 수치) 및 장점:**
- refusal-steering 설정에서 95.8%의 recovery rate 달성 (defended-feature relative drift 0.131, suffix 기반 baseline 대비 현저히 낮음)
- TPP, unlearning, IOI, refusal-steering 4개 실험 전반에 걸쳐 feature-level 개입이 성공해도 행동 복원 가능함을 확인
- recovery 경로가 SAE reconstruction residual (SAE가 설명하지 못하는 부분)에 국소화됨을 attribution 분석으로 규명

**단점 및 한계점:**
- feature clamping이 실패하는 구체적인 조건(어떤 SAE 아키텍처, 어떤 규모의 모델)에 대한 체계적 분류가 부족
- 더 큰 규모의 SAE(더 높은 expansion factor)나 최신 Transcoders를 사용할 경우 결과가 달라질 가능성 있음
- 공격자가 최적화 접근권을 가진다는 강한 위협 모델 가정

**핵심 기술:**
Sparse Autoencoder (SAE), residual-space optimization, encoder-orthogonal updates, feature-map Jacobian, post-intervention recovery, refusal steering

## 2. [Bag of Dims: Training-Free Mechanistic Interpretability via Dimension-Level Sign Patterns](https://arxiv.org/abs/2606.12629)

**분류:** LLM Interpretability
**arxiv:** 2606.12629 v2 | 최초 2026-06-10, 수정 2026-06-17
**출처:** HuggingFace Daily Papers (Jun 18)
**저자:** Varun Reddy Nalagatla

### 요약

**문제 정의:**
LLM의 mechanistic interpretability를 위한 기존 방법(PCA, ICA, SAE 등)은 학습된 회전(rotation)이나 별도 훈련이 필요하다. transformer hidden state의 표준 기저(standard basis)가 이미 충분한 feature basis를 제공하는지 검증되지 않았다.

**해결 방법 (제안 기법):**
Bag of Dims(BoD) 프레임워크: 각 hidden state 차원의 부호(sign: +/-1)가 의미 정보를 인코딩하고, 크기(magnitude)가 신뢰도를 나타낸다는 가설을 검증한다. feature는 일관된 sign 패턴을 가진 차원의 부분집합으로 정의되며, 학습 없이 sign 일치 계산(Hamming scoring)만으로 읽어낼 수 있다. 단일 token 캐시(1회 forward pass)에서 개념을 탐지한다.

**결과 (정확한 수치) 및 장점:**
- sign 패턴만으로 top-5 next-token accuracy의 60–93% 보존
- decoder-free Hamming scoring으로 top-4096 accuracy 80–90% 달성
- 단일 token 캐시에서 175개 카테고리 AUC 0.97–0.99로 탐지
- 학습된 probe는 +0.018 AUC 추가에 불과하며 axis-aligned 가중치로 수렴
- 4개 언어 모델에서 sign flip이 개념을 억제함을 인과적으로 확인
- 언어(Qwen 3.5-4B, Gemma 3-4B, Mistral 7B, Qwen3-32B), 비전(DINOv2, ViT-Base), 오디오(AST) 7개 모델에서 검증; pairwise mutual information < 0.006 bits

**단점 및 한계점:**
- 단일 저자 연구로 대규모 검증 필요
- v2 수정본으로, 초기 주장의 일부가 변경됐을 가능성
- 실제 안전/개인정보 보호 응용에 대한 연결이 제한적
- "어떤 차원이 무엇을 인코딩하는가"라는 카탈로깅 문제는 미해결

**핵심 기술:**
mechanistic interpretability, dimension-level sign patterns, training-free feature detection, Hamming scoring, causal intervention, transformer hidden states

## 3. [Sparse Autoencoders for Interpretable Emotion Control in Text-to-Speech](https://arxiv.org/abs/2606.01479)

**분류:** LLM Interpretability (SAE 응용)
**arxiv:** 2606.01479 v1 | 2026-05-31 | **ICML 2026 accepted**
**출처:** arxiv cs.CL
**저자:** Hongfei Du, Jiacheng Shi, Sidi Lu, Gang Zhou, Ye Gao

### 요약

**문제 정의:**
LLM 기반 TTS(Text-to-Speech) 시스템에서 감정 표현이 개선됐지만, 감정 제어는 여전히 해석 불가능하다(black-box). 기존 방법은 외부 conditioning이나 전역 activation steering에 의존해 내부 표현에 대한 통찰이 없다.

**해결 방법 (제안 기법):**
LLM 기반 TTS 모델의 semantic hidden state에 SAE를 학습해 sparse latent feature를 식별한다. 감정 관련 변화가 여러 sparse feature에 분산됨을 분석하고, 소수의 feature 개입만으로 해석 가능한 감정 제어가 가능함을 확인한다. backbone 파라미터 수정 없이 bidirectional emotion induction/suppression을 위한 feature-level 개입 프레임워크를 제안한다.

**결과 (정확한 수치) 및 장점:**
- sparse latent feature steering이 global steering 및 기존 TTS baseline 대비 comparable하거나 우수한 emotion induction/suppression 성능 달성
- 특정 latent feature가 acoustic attribute(예: pitch)와 연관됨을 규명 — 감정 표현이 단일 전역 shift가 아닌 coordinated latent 기여에서 발생함을 시사
- ICML 2026 accept으로 품질 검증

**단점 및 한계점:**
- TTS 도메인 특화 연구로 일반 LLM interpretability와 직접 연결이 제한적
- emotion의 문화적/언어적 다양성에 대한 검증 부족
- 수치 결과의 구체적 수치(정량적 지표)가 제한적으로 공개됨

**핵심 기술:**
Sparse Autoencoder (SAE), LLM-based TTS, feature-level intervention, emotion induction/suppression, latent feature steering, activation steering

## 4. [Automated Jailbreak Attack Targeting Multiple Defense Strategies (UNIATTACK)](https://arxiv.org/abs/2606.16751)

**분류:** AI Security (Jailbreak)
**arxiv:** 2606.16751 v1 | 2026-06-15
**출처:** arxiv cs.CR / Web Search
**저자:** Qi Wang, Chengcheng Wan, Weijia He, Yanqing Li, Hanqi Sun, Xiaodong Gu, Jiangtao Wang (ECNU/SJTU/Southampton)

### 요약

**문제 정의:**
기존 jailbreak 공격은 static template이나 모델별 iterative tuning에 의존해, 다중 방어 레이어를 갖춘 시스템에 일반화되지 않는다. 다양한 방어 전략을 동시에 우회할 수 있는 one-shot 공격 프레임워크가 필요하다.

**해결 방법 (제안 기법):**
UNIATTACK: defense-oriented 관점에서 설계된 adversarial testing 프레임워크. 기존 다양한 공격에서 high-impact 최소 attack feature를 추출하고, specialized attacker LLM으로 최적화한 후, 자동화된 refinement 과정을 통해 유연한 template으로 조합한다. feature 중심 구성으로 여러 모델과 safety 카테고리에 걸쳐 일반화되는 one-shot 공격을 생성한다.

**결과 (정확한 수치) 및 장점:**
- 다중 방어 메커니즘이 배포된 모델 대비 평균 ASR(Attack Success Rate) 64.63%–248.82% 향상
- baseline 대비 0.03%–4.96%의 비용만으로 달성
- 단일 공격으로 다수 모델과 safety 카테고리에 일반화 가능

**단점 및 한계점:**
- 공격 프레임워크 연구로, 방어 관점의 대응 방안 제시 미흡
- 실험 세부 조건(어떤 방어 시스템, 어떤 모델) 공개 제한 (anonymous artifact)
- white-box 접근 없이 특정 방어 우회 메커니즘의 이론적 설명 부족

**핵심 기술:**
jailbreak attack, adversarial testing, black-box attack, LLM safety, one-shot attack, feature-centric template construction, automated refinement

## 5. [Toward Secure LLM Agents: Threat Surfaces, Attacks, Defenses, and Evaluation](https://arxiv.org/abs/2606.10749)

**분류:** AI Security (LLM Agent Security)
**arxiv:** 2606.10749 v1 | 2026-06-09
**출처:** arxiv cs.CR / Web Search
**저자:** Yuchen Ling, Shengcheng Yu, Zhenyu Chen, Chunrong Fang (Nanjing University)

### 요약

**문제 정의:**
LLM agent는 단순 대화 인터페이스에서 tool 호출, 메모리 유지, 외부 환경 행동으로 진화하면서 보안 위험의 성격이 근본적으로 변화했다. 기존 연구는 공격 유형별로 파편화되어 있으며, 통합된 보안 프레임워크가 부재하다.

**해결 방법 (제안 기법):**
247편 논문을 lifecycle 기반, systems-oriented 프레임워크로 종합한 체계적 survey. information flow, delegated authority, persistent state의 상호작용을 중심으로 agent 보안을 모델링한다. 4가지 핵심 질문(보안 모델링 방법, 위협 표면 및 공격 유형, 방어 방법 및 trade-off, 보안 평가 방법)을 중심으로 문헌을 정리한다.

**결과 (정확한 수치) 및 장점:**
- 247편 논문 종합 — 현존하는 가장 포괄적인 LLM agent 보안 survey 중 하나
- prompt injection과 tool-mediated control-flow hijacking이 여전히 지배적임을 확인
- persistent state corruption과 multi-agent propagation이 부상하는 핵심 우려로 식별
- 기존 방어의 weak compositionality 문제 및 benchmark의 한계(long-horizon, stateful, deployment-sensitive 리스크 과소표현) 지적

**단점 및 한계점:**
- survey 논문 특성상 새로운 기법 제안 없음
- 빠르게 evolve하는 분야 특성상 논문 제출 후 새로운 공격/방어 기법 등장 가능
- 평가 방법론의 표준화 부재 문제는 지적하지만 해결책 제시 없음

**핵심 기술:**
LLM agent security, prompt injection, tool-mediated control-flow hijacking, privilege control, provenance-aware state management, multi-agent propagation, systematic survey
