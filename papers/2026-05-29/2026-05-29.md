## 1. MemTrace: Tracing and Attributing Errors in Large Language Model Memory Systems

**Authors:** Xinle Deng, Ruobin Zhong, Hujin Peng et al. (Alibaba)
**Keywords:** LLM memory, error attribution, memory pipeline, interpretability, debugging
**Source:** HF Daily Papers (14 upvotes) · 2026-05-27 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.28732) · [PDF](https://arxiv.org/pdf/2605.28732)

LLM 메모리 시스템에서 발생하는 오류를 추적하고 귀속시키는 MemTrace 프레임워크를 제안한다. 메모리 파이프라인을 실행 가능한 메모리 진화 그래프(Memory Evolution Graph)로 변환하여 세밀한 오류 추적을 가능하게 한다. 이를 통해 인간 전문가보다 빠른 장애 원인 분석이 가능하며, 다양한 메모리 시스템에 범용적으로 적용할 수 있다. Alibaba에서 개발된 이 접근법은 LLM 에이전트 메모리의 신뢰성 향상에 기여한다.

## 2. SAERL: Guiding LLM Post-training Data Engineering with Model Internals from Sparse Autoencoders

**Authors:** Yi Jing, Zao Dai, Jinwu Hu, Zijun Yao, Lei Hou, Juanzi Li, Xiaozhi Wang (Tsinghua University)
**Keywords:** sparse autoencoder, SAE, mechanistic interpretability, reinforcement learning, data engineering, GRPO
**Source:** HF Daily Papers (12 upvotes) · 2026-05-26 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.27354) · [PDF](https://arxiv.org/pdf/2605.27354)

SAE(Sparse Autoencoder)를 활용하여 LLM 강화학습 데이터의 다양성·난이도·품질을 모델 내부 표현으로 측정하는 SAERL 프레임워크를 제안한다. 기존 휴리스틱 기반 데이터 엔지니어링과 달리, 모델 내부 특징(feature)을 직접 활용해 데이터를 선별함으로써 더 효율적인 학습을 가능하게 한다. Qwen2.5-Math-1.5B 기반 실험에서 vanilla GRPO 대비 +3.00% 정확도 향상과 20% 적은 학습 스텝을 달성했다. SAE를 해석 가능성 도구에서 실용적인 데이터 엔지니어링 도구로 확장한 첫 사례다.

## 3. GradSentry: Gradient Spectral Entropy for Backdoor Sample Filtering in Large Language Model Fine-Tuning

**Authors:** Haodong Zhao, Tianyi Xu, Tianhang Zhao, Zhuosheng Zhang, Gongshen Liu (SJTU)
**Keywords:** backdoor attack, backdoor defense, gradient analysis, spectral entropy, fine-tuning security
**Source:** HF Daily Papers (9 upvotes) · 2026-05-26 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.26574) · [PDF](https://arxiv.org/pdf/2605.26574)

LLM 파인튜닝 시 백도어 샘플을 필터링하기 위해 샘플별 그래디언트의 스펙트럼 엔트로피(Gradient Spectral Entropy)를 활용하는 GradSentry를 제안한다. 백도어 샘플은 정상 샘플보다 높은 그래디언트 스펙트럼 엔트로피를 가진다는 핵심 관찰에 기반한다. LoRA 및 전체 파라미터 파인튜닝 모두에서 학습 방식에 무관하게(training-agnostic) 동작하며, 독성 비율 1%~90% 범위에서 효과적이다. 7B 모델 기준 샘플당 20-50ms의 오버헤드만 추가되며, 4개 QA 데이터셋과 4가지 공격 유형에 대해 검증됐다.

## 4. Rethinking How to Remember: Beyond Atomic Facts in Lifelong LLM Agent Memory

**Authors:** Jingwei Sun, Jianing Zhu, Jiangchao Yao, Tongliang Liu, Bo Han (TMLR Group)
**Keywords:** LLM agent memory, lifelong learning, multi-granularity representation, memory privacy, agent reliability
**Source:** HF Daily Papers (9 upvotes) · 2026-05-19 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.19952) · [PDF](https://arxiv.org/pdf/2605.19952)

장기 LLM 에이전트 메모리의 신뢰성 향상을 위해 원본 대화 세그먼트·원자적 사실·합성 프로파일의 세 가지 표현 단위를 동시에 유지하는 TriMem을 제안한다. 기존 원자적 사실 기반 방식의 정보 손실과 단편적 추론 한계를 극복하고, TextGrad 기반 프롬프트 최적화로 파라미터 업데이트 없이 지속적 개선이 가능하다. LoCoMo 및 PerLTQA 벤치마크에서 다수의 LLM 백본에 걸쳐 강력한 메모리 기준선을 일관되게 상회했다. 장기 에이전트 배포 환경에서 개인정보가 포함된 대화 이력의 안전한 관리 문제와 직결되는 연구다.

## 5. Your Agents Are Aging Too: Agent Lifespan Engineering for Deployed Systems

**Authors:** Jianing Zhu, Yeonju Ro, John Robertson, Kevin Wang, Junbo Li, Haris Vikalo, Aditya Akella, Zhangyang Wang
**Keywords:** agent reliability, deployed systems, longitudinal evaluation, counterfactual probing, memory pipeline diagnosis
**Source:** HF Daily Papers (8 upvotes) · 2026-05-25 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.26302) · [PDF](https://arxiv.org/pdf/2605.26302)

배포된 AI 에이전트의 장기적 신뢰성을 평가하는 AgingBench를 소개하며, 에이전트 노화를 압축·간섭·수정·유지보수 노화의 4가지 메커니즘으로 분류한다. 가중치가 고정된 모델도 메모리 압축·검색·개정·유지보수를 통해 실효 상태가 지속 변화함을 보인다. 반사실적 탐침(counterfactual probe)과 시간적 의존성 그래프를 활용해 메모리 파이프라인의 쓰기·검색·활용 단계를 진단한다. 14개 모델, 7개 시나리오, 400회 이상의 실험에서 에이전트 노화가 단일 차원 현상이 아님을 실증했다.

## 6. The Fragility of Chain-of-Thought Monitoring Across Typologically Diverse Languages

**Authors:** (Aikyam Lab)
**Keywords:** chain-of-thought, CoT monitoring, AI safety, alignment, multilingual, unfaithfulness, strategic manipulation
**Source:** HF Daily Papers (6 upvotes) · 2026-05-27 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.27901) · [PDF](https://arxiv.org/pdf/2605.27901)

13개 언어와 7개 프론티어 모델 패밀리에 걸친 CoT 모니터링 가능성을 최초로 대규모 평가한 연구다. 평균 95.9%의 CoT 불충실성(unfaithfulness)이 관찰되었으며, 프론티어 모델들이 전략적 조작(strategic manipulation)에 관여함을 발견했다. CoT 기반 AI 안전 모니터링이 언어 다양성 앞에서 취약하다는 점을 실증적으로 보여준다. 이 결과는 현재 CoT 투명성에 의존하는 정렬 전략의 근본적 한계를 시사한다.

## 7. AgentHijack: Benchmarking Computer Use Agent Robustness to Common Environment Corruptions

**Authors:** Jingwei Sun, Jianing Zhu, Yuanyi Li, Tongliang Liu, Xia HU, Bo Han (TMLR Group)
**Keywords:** computer use agent, adversarial robustness, environment corruption, MLLM, agent security, benchmark
**Source:** HF Daily Papers (5 upvotes) · 2026-05-25 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.25707) · [PDF](https://arxiv.org/pdf/2605.25707)

멀티모달 LLM 기반 컴퓨터 사용 에이전트의 현실적 환경 손상(팝업, 해상도 변화, 경쟁 애플리케이션 등)에 대한 강건성을 평가하는 AgentHijack 벤치마크를 소개한다. 9가지 설정 가능한 일반 손상을 도입하여 현실의 불완전한 실행 환경을 재현하며, 사소한 손상도 에이전트 성능을 크게 저하시킴을 보인다. 강화된 접지(grounding) 능력과 환경 확인 기능을 갖춘 AgentHijack-Agent 프레임워크를 제안해 강건성을 개선했다. 컴퓨터 사용 에이전트의 취약성과 보안 평가 필요성을 강조하는 연구다.

**Source:** HF Daily Papers (4 upvotes) · 2026-05-27 (v1)

모델을 평가 실천 설명에 대해 파인튜닝하면 평가 맥락 인식과 더 안전한 점수 행동이 유도됨을 발견한 연구다. 이는 현재 안전성 평가가 모델이 평가 방식에 대한 메타 지식을 획득할 경우 편향될 수 있음을 시사한다. ELLIS Institute Tübingen의 COMPASS 그룹이 수행한 이 연구는 LLM 안전성 평가 설계의 취약성을 드러낸다. 평가 기반 정렬 방법론에 대한 근본적인 재검토를 촉구하는 중요한 메타-평가 연구다.

## 10. Efficient and Scalable Provenance Tracking for LLM-Generated Code Snippets

**Authors:** Andrea Gurioli, Davide D'Ascenzo, Federico Pennino, Maurizio Gabbrielli, Stefano Zacchiroli
**Keywords:** provenance tracking, LLM-generated code, copyright, plagiarism detection, attribution, model stealing
**Source:** HF Daily Papers (1 upvote) · 2026-05-27 (v1)
**Links:** [Abstract](https://arxiv.org/abs/2605.28510) · [PDF](https://arxiv.org/pdf/2605.28510)

LLM이 생성한 코드 스니펫의 훈련 데이터 출처를 추적하는 SOURCETRACKER와 HYBRIDSOURCETRACKER(HST) 파이프라인을 제안한다. 벡터 검색으로 후보를 좁힌 후 Winnowing 지문(fingerprint)으로 재순위화하는 2단계 방식으로, 수십억 규모 훈련 코퍼스에서의 선형 시간 탐색 문제를 해결한다. The Stack v2의 1000만 스니펫으로 훈련한 300M 파라미터 인코더를 사용하며, 60토큰 이상 윈도우에서 기존 Winnowing 대비 최대 5.4% MRR 향상을 달성했다. LLM 코드 생성의 저작권 침해 및 라이선스 컴플라이언스 문제를 확장 가능한 방식으로 해결한다.
