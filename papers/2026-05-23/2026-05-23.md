## 1. MAGE: Safeguarding LLM Agents against Long-Horizon Threats via Shadow Memory 🆕

- **저자**: Yuhui Wang, Tanqiu Jiang, Jiacheng Liang, Charles Fleming, Ting Wang
- **키워드**: `agent safety`, `long-horizon threats`, `shadow memory`, `prompt injection`, `agentic security`
- **출처**: arxiv recent (cs.CR)
- **arxiv abstract**: [2605.03228](https://arxiv.org/abs/2605.03228) (v1)
- **PDF**: [arxiv.org/pdf/2605.03228](https://arxiv.org/pdf/2605.03228.pdf)

**핵심 요약** (3-5문장):
LLM 에이전트가 복잡한 실세계 태스크를 처리하면서 단일 턴에서는 불가능했던 악의적 목표를 장기 상호작용을 통해 달성하는 새로운 공격 유형(long-horizon threats)이 등장하고 있다. MAGE(Memory As Guardrail Enforcement)는 시스템 보안의 "shadow stack" 개념에서 영감을 받아, 에이전트의 전체 실행 경로에 걸쳐 안전-critical 컨텍스트를 추출·유지하는 전용 shadow memory를 구축한다. 이 shadow memory를 통해 보류 중인 액션의 위험도를 실행 전에 사전 평가하며, 다양한 long-horizon 위협에 대해 기존 방어법을 크게 뛰어넘는 탐지 정확도를 달성하고, 대부분의 공격을 초기 단계에서 탐지하면서 에이전트 유틸리티에 미미한 오버헤드만 발생시킨다.

## 2. Remembering More, Risking More: Longitudinal Safety Risks in Memory-Equipped LLM Agents 🆕

- **저자**: Ahmad Al-Tawaha, Shangding Gu, Peizhi Niu, Ruoxi Jia, Ming Jin
- **키워드**: `agent safety`, `memory poisoning`, `temporal contamination`, `LLM agent`, `longitudinal evaluation`
- **출처**: arxiv recent (cs.CR)
- **arxiv abstract**: [2605.17830](https://arxiv.org/abs/2605.17830) (v1)
- **PDF**: [arxiv.org/pdf/2605.17830](https://arxiv.org/pdf/2605.17830.pdf)

**핵심 요약** (3-5문장):
기존 메모리 탑재 LLM 에이전트 안전성 평가는 단일 태스크 내에서 에이전트가 안전하게 행동하는지만 측정했지만, 실제 배포 환경에서는 하나의 에이전트가 수많은 독립적 태스크를 장기간 수행하며 이전 태스크에서 축적된 메모리가 이후 무관한 태스크의 행동에 영향을 줄 수 있다. 이 논문은 "temporal memory contamination"이라는 새로운 실패 모드를 정의하고, 다양한 메모리 축적 길이에서 고정된 probe 세트를 평가하는 trigger-probe 프로토콜과 NullMemory 반사실 기준선을 제안한다. 실험 결과 메모리가 누적될수록 에이전트의 안전 프로파일이 체계적으로 저하됨을 보이며, 메모리를 고려한 종단적(temporal) 안전 평가의 필요성을 강조한다.

## 3. Revisiting JBShield: Breaking and Rebuilding Representation-Level Jailbreak Defenses 🆕

- **저자**: Kemal Derya, Berk Sunar
- **키워드**: `jailbreak`, `adversarial attack`, `representation-level defense`, `GCG`, `adaptive attack`
- **출처**: arxiv recent (cs.CR)
- **arxiv abstract**: [2605.03095](https://arxiv.org/abs/2605.03095) (v1)
- **PDF**: [arxiv.org/pdf/2605.03095](https://arxiv.org/pdf/2605.03095.pdf)

**핵심 요약** (3-5문장):
USENIX Security 2025에 발표된 JBShield는 toxic concept과 jailbreak concept 두 가지 신호를 통해 악성 프롬프트를 탐지, 일부 설정에서 공격 성공률 0%를 달성한 강력한 방어법이다. 본 논문은 JB-GCG라는 적응형 공격을 설계하여 JBShield의 방어를 우회하며, GCG의 목적 함수를 수정해 refusal direction 억제와 toxic concept 점수 규제를 결합한다. Llama-3-8B에서 5가지 설정으로 평가한 결과 평균 46.2% ASR을 달성(최대 53.4%)하였으며, JBShield-M에 대해서도 최대 30.7% ASR을 기록, 표현 수준 방어의 근본적 취약성을 드러낸다.

## 5. Dependency-Aware Privacy for Multi-turn Agents 🆕

- **저자**: Divyam Anshumaan, Sarthak Choudhary, Nils Palumbo, Somesh Jha
- **키워드**: `differential privacy`, `multi-turn agents`, `privacy leakage`, `federated privacy`, `RootGuard`
- **출처**: arxiv recent (cs.CR)
- **arxiv abstract**: [2605.03188](https://arxiv.org/abs/2605.03188) (v1)
- **PDF**: [arxiv.org/pdf/2605.03188](https://arxiv.org/pdf/2605.03188.pdf)

**핵심 요약** (3-5문장):
LLM 에이전트는 멀티 서비스 상호작용에 걸쳐 프라이빗 데이터를 릴리즈하는데, 기존 프롬프트 sanitizer들은 각 릴리즈를 독립적으로 처리해 공격자가 여러 턴의 릴리즈를 결합해 프라이빗 속성을 복원할 수 있다. 프라이빗 속성이 computation graph의 루트인 경우, 파생 값을 독립적으로 노이즈 처리하면 Lipschitz 상수 L만큼 구별 가능성이 증폭되어 명목 프라이버시 파라미터를 크게 초과한다. RootGuard는 루트 값을 한 번만 sanitize하고 이후 릴리즈는 노이즈 처리된 루트로부터 결정론적으로 계산함으로써, 적대자의 함수나 턴 수에 관계없이 초기 루트 sanitization에만 프라이버시 보장이 의존하도록 설계된다.

## 10. The Range Shrinks, the Threat Remains: Re-evaluating LLM Package Hallucinations on the 2026 Frontier-Model Cohort 🆕

- **저자**: Aleksandr Churilov
- **키워드**: `package hallucination`, `slopsquatting`, `AI security`, `supply chain attack`, `code generation`
- **출처**: arxiv recent (cs.CR)
- **arxiv abstract**: [2605.17062](https://arxiv.org/abs/2605.17062) (v1)
- **PDF**: [arxiv.org/pdf/2605.17062](https://arxiv.org/pdf/2605.17062.pdf)

**핵심 요약** (3-5문장):
코드 생성 LLM이 PyPI나 npm에 존재하지 않는 패키지 이름을 환각(hallucination)함으로써 공격자가 환각된 이름으로 악성 패키지를 등록하는 "slopsquatting" 공격 표면이 생성된다. 2025년 10월~2026년 3월 출시된 최신 프론티어 모델 5개(Claude Sonnet 4.6, Claude Haiku 4.5, GPT-5.4-mini, Gemini 2.5 Pro, DeepSeek V3.2)에 대해 199,845개 Python·JavaScript 프롬프트로 재평가한 결과, 환각률이 4.62%(Claude Haiku 4.5)~6.10%(GPT-5.4-mini)로 이전 연구 대비 모델 간 격차가 크게 줄었다. 모델 개선으로 범위는 좁혀졌지만 위협 자체는 사라지지 않았으며, 코드 의존성 공급망 보안에 대한 지속적 주의가 필요함을 강조한다.
