## 1. Safety for Whom? Boundary-Aware Self-Distillation for Controlled LLM Safety Refusal  🆕
- **저자**: Alejo López-Ávila, Iker García-Ferrero, Jezabel Garcia, Antonio Tiene, Román Orús
- **키워드**: safety alignment, refusal calibration, self-distillation, over-refusal
- **출처**: HF Daily / arxiv recent
- **arxiv abstract**: [2609.04482](https://arxiv.org/abs/2609.04482) (v1)
- **PDF**: [arxiv.org/pdf/2609.04482](https://arxiv.org/pdf/2609.04482.pdf)
- **핵심 요약**: 동일한 주제 안에서도 서비스별로 허용 범위가 달라, 주제 단위 안전 정렬은 과잉 거부를 만들 수 있다. 저자들은 통제된 주제 생성, 누락 보완, 분포 내 보상 데이터, 유해·무해 경계 쌍을 결합한 자기 증류 절차를 제안한다. Qwen3-8B에서 목표 영역 거부율은 9.47%에서 84.75%로 증가했다. 경계 쌍 데이터는 허용 측 과잉 거부를 32.94%에서 4.16%로 낮추면서 유해 측 거부는 91.88%에서 87.72%로만 감소시켰다.

## 2. Confess What You Know: Forget-Set Misalignment with Model Knowledge in LLM Unlearning  🆕
- **저자**: Miso Kim, Georu Lee, Seungwon Jeong, Woojin Lee
- **키워드**: machine unlearning, training data leakage, forget-set misalignment, model knowledge
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.00605](https://arxiv.org/abs/2609.00605) (v1)
- **PDF**: [arxiv.org/pdf/2609.00605](https://arxiv.org/pdf/2609.00605.pdf)
- **핵심 요약**: 기존 LLM 언러닝은 지정된 삭제 집합이 실제 모델 기억과 일치한다고 가정한다. 논문은 누락된 기억이 남는 과소 언러닝과, 학습하지 않은 지식을 지우려다 효용이 손상되는 문제를 분리한다. CONFS는 원본 학습 데이터 없이 모델이 기억한 지식을 유도해 모델 정렬 삭제 집합을 구성한다. 합성·멀티모달·현실 벤치마크에서 여러 지표상 골드 표준에 근접하고, 다른 데이터 비의존 방식보다 효용을 더 잘 보존했다.

## 3. Detecting Hidden Behaviors in LLMs via Activation-matched Finetuning  🆕

- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.00351](https://arxiv.org/abs/2609.00351) (v1)
- **PDF**: [arxiv.org/pdf/2609.00351](https://arxiv.org/pdf/2609.00351.pdf)
- **핵심 요약**: 백도어와 슬리퍼 에이전트 행동은 좁은 조건에서만 발동해 사전 지식 없이 찾기 어렵다. 제안법은 공개 앵커 모델을 미세 조정해 의심 모델의 정상 입력 활성값을 재현한다. 두 모델의 잔차가 큰 프롬프트를 숨은 행동 후보로 점수화하며, 의미적으로 인접한 트리거도 탐지한다. 제3자 모델과 맞춤 모델 실험에서 숨은 행동을 안정적으로 드러냈고, 방어 인지형 공격도 행동을 유지한 채 탐지를 억제하지 못했다.

## 4. How Does mHC Use Its Residual Streams? Selective Routing and Near-Identity Mixing  🆕
- **저자**: Pengxiang Zhao, Xing Li, Xianzhi Yu, Wei Guo, Zhenhua Dong
- **키워드**: mechanistic interpretability, residual streams, causal intervention, selective routing
- **출처**: arxiv recent
- **arxiv abstract**: [2609.05309](https://arxiv.org/abs/2609.05309) (v1)
- **PDF**: [arxiv.org/pdf/2609.05309](https://arxiv.org/pdf/2609.05309.pdf)
- **핵심 요약**: mHC가 넓힌 네 개 잔차 스트림을 실제 학습 모델이 어떻게 활용하는지는 불명확했다. 저자들은 DeepSeek-V4-Flash에서 유효 스트림 수, 교차 스트림 가중치, 코사인 유사도를 분석하고 개입으로 기능을 검증한다. 전형적인 attention·FFN 지점은 약 두 스트림만 사용하며, 22~42층의 혼합기는 거의 항등 전달로 작동한다. 후기 혼합기를 항등으로 바꾸면 C4 perplexity가 1.9% 증가했지만, 초기 혼합기 교체는 41% 증가시켰다.

- **PDF**: [arxiv.org/pdf/2609.05074](https://arxiv.org/pdf/2609.05074.pdf)
- **핵심 요약**: attention head의 실제 분류 기여를 단일 attention 가중치만으로 판단하기는 어렵다. 논문은 logit 방향 영향과 잔차 스트림 내 구조적 기여를 결합한 influence score를 제안한다. 프롬프트 주입 탐지용 DeBERTa에 적용해 head, layer, network 수준을 함께 분석했다. 정확·오류 예측에서 서로 다른 결정 패턴을 확인해 미세 회로 분석과 전역 출력 분석 사이의 중간 도구를 제시한다.

## 10. Privacy Failure in Split-LLM Training, The Returned Gradient Nullifies the Decoys  🆕
- **저자**: Georgios Politis, Evangelos Pappas
- **키워드**: split learning, gradient leakage, privacy evaluation, data extraction
- **출처**: arxiv recent
- **arxiv abstract**: [2609.04382](https://arxiv.org/abs/2609.04382) (v1)
- **PDF**: [arxiv.org/pdf/2609.04382](https://arxiv.org/pdf/2609.04382.pdf)
- **핵심 요약**: 분할 LLM 학습의 순방향 개인정보 평가가 반환 gradient 채널을 빠뜨리면 실제 노출을 놓칠 수 있다. 손실에서 제외된 decoy 행은 gradient가 정확히 0이어서 실제 행 위치가 드러난다. 아홉 개 seed 모두에서 매 실행 4,096개 중 4,096개 실제 행을 식별했다. 행별 clipping과 noise는 약 0.01 nat의 검증 cross-entropy 비용으로 이 누출을 막았지만, 누적 관측 공격 등은 평가되지 않았다.
