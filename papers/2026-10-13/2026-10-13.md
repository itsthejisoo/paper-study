- **저자**: Andis Draguns, Sumeet Ramesh Motwani, Raymond Douglas, Christian Schroeder de Witt
- **키워드**: backdoor, hidden capabilities, capability auditing, adversarial attacks
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13928](https://arxiv.org/abs/2610.13928) (v1)
- **PDF**: [arxiv.org/pdf/2610.13928](https://arxiv.org/pdf/2610.13928.pdf)
- **핵심 요약**: 기존 능력 평가는 숨겨진 능력을 적절한 입력으로 끌어낼 수 있다고 가정한다. 이 연구는 비밀 트리거에서만 복호화·실행되는 신경망 회로를 호스트 모델 가중치에 삽입한다. 암호학적 가정 아래에서 해당 회로는 가중치를 모두 공개해도 유도하거나 해석하기 어렵다. 작은 화학 반응 과제에서는 미세조정, 가중치 노이즈, 트리거 탐색, 잠재 적대 훈련에도 은닉 능력이 유지됐다. 이는 행동 유도 중심 감사가 완전한 안전 보증이 될 수 없음을 보인다.

## 2. X-AgentRed: Red-Teaming Personal Agents in Evolving Multi-Service Ecosystems  🆕

- **키워드**: red-teaming, agent safety, tool composition, harmful paths
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13886](https://arxiv.org/abs/2610.13886) (v1)
- **PDF**: [arxiv.org/pdf/2610.13886](https://arxiv.org/pdf/2610.13886.pdf)
- **핵심 요약**: 개인 에이전트는 여러 서비스를 연결하면서 개별적으로는 정상인 작업을 위험한 실행 경로로 조합할 수 있다. X-AgentRed는 도구의 의존성, 효과, 전제조건을 방향 그래프로 표현하고 공격 레시피를 자동 확장한다. 실행 피드백을 이용해 실패 경로를 수정하고 새로운 조합을 계속 탐색한다. 네 개 프런티어 에이전트에서 기존 STAC보다 유해 경로 발견률이 1.77배였고, 평균 도구 커버리지는 2.99배였다.

## 3. ToFu: Exploiting and Fuzzing the LLM-Orchestrator-Tool Trust Boundary  🆕
- **저자**: Md Nazmul Islam Ananto, Pierre Prevost-Avenel, Colin Smith, Kyungtae Kim, Taegyu Kim et al.
- **키워드**: agent safety, tool security, fuzzing, MCP
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13651](https://arxiv.org/abs/2610.13651) (v1)
- **PDF**: [arxiv.org/pdf/2610.13651](https://arxiv.org/pdf/2610.13651.pdf)
- **핵심 요약**: LLM 오케스트레이터가 생성한 인자를 도구가 신뢰하면 형식 검사를 통과한 호출도 의미적 보안 규칙을 위반할 수 있다. ToFu는 도구 메타데이터와 CWE 기반 정제기 모음에서 의미적 검사를 도출한다. 런타임 관찰과 결과 정제를 결합해 퍼징 하네스와 판정 오라클을 만든다. 273개 MCP 서버의 3,405개 도구를 검사해 118개 서버에서 검증된 의미적 취약점을 찾았다. 이 결과는 에이전트 보안 검사가 스키마 검증을 넘어 실행 의미를 확인해야 함을 보여준다.

## 4. APEX-Harm: Evaluating Agent Safety in Shared Professional Workspaces  🆕
- **저자**: Ziyi Yang, Adel Bibi, Guohao Li, Bernard Ghanem, Carlos Hinojosa
- **키워드**: prompt injection, agent safety, benchmark, MCP
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13623](https://arxiv.org/abs/2610.13623) (v1)
- **PDF**: [arxiv.org/pdf/2610.13623](https://arxiv.org/pdf/2610.13623.pdf)
- **핵심 요약**: 공유 전문 업무공간에서는 문서와 스크립트가 장기 작업 에이전트의 간접 프롬프트 주입 경로가 된다. APEX-Harm은 금융, 컨설팅, 법률 환경의 대규모 파일 집합과 MCP 도구를 결합한 벤치마크다. 12개 프런티어 모델을 대상으로 여섯 공격 범주를 평가했다. Opus 5와 Sonnet 5의 공격 성공률은 각각 8%와 20%였지만, 작업별 스크립트 교체 공격은 평균 81–84%에 도달했다. 성능이 높은 에이전트도 작업공간 내 실행 아티팩트에는 취약할 수 있음을 보여준다.

## 5. Quantization-Tolerant Gradient Auditing for Active Inference-Attack Detection in Federated Learning  🆕

- **키워드**: federated learning privacy, inference attacks, gradient auditing, differential privacy
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13311](https://arxiv.org/abs/2610.13311) (v1)
- **PDF**: [arxiv.org/pdf/2610.13311](https://arxiv.org/pdf/2610.13311.pdf)
- **핵심 요약**: 연합학습 참여자는 업데이트 프로토콜을 악용해 다른 참여자의 민감 정보를 추론할 수 있다. 이 연구는 신뢰 서버가 비밀 챌린지 배치를 보내고, 클라이언트가 양자화된 그래디언트 체크섬과 시간을 반환하게 한다. 두 능동 추론 공격에서 체크섬 탐지는 참양성률 1.0과 거짓양성 0을 기록했다. 서버 비용은 32ms, 응답 크기는 4.35kB였지만 수동 공격의 시간 신호와 원본 복사 회피에는 취약했다. 따라서 이 감사는 차등프라이버시를 대체하지 않고 보완한다.

## 6. Understanding and Mitigating Cross-Session Attacks via Persistent Artifacts in Agent Skill Composition  🆕
- **저자**: Dianshu Liao, Shidong Pan, Guangdong Bai, Zhenchang Xing, Xiaoyu Sun et al.
- **키워드**: agent safety, skill composition, persistent artifacts, prompt injection
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13227](https://arxiv.org/abs/2610.13227) (v1)
- **PDF**: [arxiv.org/pdf/2610.13227](https://arxiv.org/pdf/2610.13227.pdf)
- **핵심 요약**: 에이전트 기술이 파일, 설정, 캐시를 재사용하면 한 세션의 공격이 다음 세션으로 전파될 수 있다. 연구진은 명령 전파, 데이터 경계 위반, 증거 오염이라는 세 가지 공격 메커니즘을 정의했다. SkillRelayBench는 30개 시나리오와 270개 적대 사례로 일곱 모델을 평가했고, 공격 성공률은 46.7–77.4%였다. 출처 추적과 검토 절차를 추가한 SkillRelayGuard는 공격 성공률을 69.5%에서 10.9%로 낮췄다. 동시에 정상 작업 완료율은 79.6%에서 87.5%로 높아졌다.

## 7. The Limits of Query Monitoring against Distributed Model Extraction  🆕

- **키워드**: model stealing, distributed extraction, query monitoring, anomaly detection
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13083](https://arxiv.org/abs/2610.13083) (v1)
- **PDF**: [arxiv.org/pdf/2610.13083](https://arxiv.org/pdf/2610.13083.pdf)
- **핵심 요약**: 모델 추출 공격이 수천 개의 연결 불가능한 계정으로 분산되면 단일 계정 이상 탐지가 약해진다. 이 연구는 실제 채팅 100만 건과 별도 17주 데이터를 사용해 탐지 한계를 측정했다. 순진한 공격은 0.86–1.00주 안에 탐지됐지만, 자연어 패딩과 분산을 사용한 공격은 탐지 가능성과 추출 효율을 교환했다. 실험 환경에서는 공모 계정 비율이 2.5% 이하일 때 배포 가능한 탐지기가 없었다. 실제 사용자 질의를 중계하는 공격은 통계적으로 정상 트래픽과 구분되지 않을 가능성도 제기한다.

- **키워드**: backdoor, label poisoning, audit, adversarial attacks
- **출처**: arxiv recent
- **arxiv abstract**: [2610.13051](https://arxiv.org/abs/2610.13051) (v1)
- **PDF**: [arxiv.org/pdf/2610.13051](https://arxiv.org/pdf/2610.13051.pdf)
- **핵심 요약**: 레이블 전용 백도어 감사는 어떤 특징 공간을 쓰는지에 따라 탐지 성능이 크게 달라진다. CIFAR-10의 3% 레이블을 바꾼 FLIP 공격은 트리거된 원본 클래스를 목표 클래스로 99.7% 전환했다. 개→고양이 사례의 최근접 이웃 AUROC는 오염 특징에서 0.546, 고정 DINOv2에서 0.967, 깨끗한 오라클에서 0.995였다. 그러나 탐지 점수가 높아도 정제 후 재학습 모델이 반드시 더 안전하지는 않았다. 감사 평가는 순위 지표와 함께 실제 재학습 결과를 확인해야 한다.

- **출처**: arxiv recent

- **핵심 요약**: DP-BandMF의 효용은 프라이버시 회계뿐 아니라 데이터를 배치에 배정하는 방식에도 좌우된다. 연구진은 무작위 할당 원리를 적용한 배치 전략을 제안한다. 이 전략은 기존 방식보다 RMSE를 최대 1.85배 개선했다. GPU 기반 회계 구현은 샘플링과 점수 계산 처리량을 두 자릿수 배수로 높였다. 전략 행렬과 배치 선택을 공동 최적화하면 RMSE가 추가로 최대 13.4% 감소했다.
