## 1. HazardAuditor: From Executable Threats to Safer Computer-Use Agents  🆕
- **저자**: Yunhao Feng, Ruixiao Lin, Ming Wen, Yanming Guo, Xingjun Ma, et al.
- **키워드**: agent safety, runtime monitoring, red-teaming
- **출처**: HF Daily / arxiv recent / SNS
- **arxiv abstract**: [2609.15134](https://arxiv.org/abs/2609.15134) (v1)
- **PDF**: [arxiv.org/pdf/2609.15134](https://arxiv.org/pdf/2609.15134.pdf)
- **핵심 요약**: 기존 가드 모델은 정적 프롬프트와 응답에 집중해 컴퓨터 사용 에이전트의 실행 중 위험을 충분히 다루지 못한다. HazardAuditor는 Claude Code, Codex, Hermes, OpenClaw의 상호작용을 공통 이벤트 표현으로 정규화해 실행 기반 감독 데이터를 만든다. GuardPO는 안전 판정을 시퀀스 수준 보상으로 바꾸고 근거와 판정 구간을 별도로 정규화한다. 여러 벤치마크와 에이전트 시스템에서 기존 최강 가드보다 정확도를 최대 16.5%p 높였다.

## 2. Divide, Consult, Conquer: Capability Laundering Through Aligned LLMs  🆕
- **저자**: Mark Russinovich, Blake Bullwinkel, Giorgio Severi, Cristian Ovadiuc, Ahmed Salem
- **키워드**: alignment attacks, capability laundering, agent safety
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.15383](https://arxiv.org/abs/2609.15383) (v1)
- **PDF**: [arxiv.org/pdf/2609.15383](https://arxiv.org/pdf/2609.15383.pdf)
- **핵심 요약**: 단일 상호작용의 거절만 검사하는 안전 체계는 유해 작업을 무해해 보이는 하위 문제로 쪼개는 공격을 놓칠 수 있다. 약한 비정렬 모델이 강한 정렬 모델에 하위 문제를 각각 질의하고 답을 로컬에서 결합하는 capability laundering을 제시한다. CyBench에서 Gemma-4-31B는 GPT-5.5를 이용해 14개 중 8개, Opus를 이용해 9개 중 7개 후보를 회수했다. CBRN 공격 사슬에서는 평균 루브릭 점수가 62.3에서 83.1로 올라, 개별 거절이 능력 이전을 막지 못함을 보였다.

## 3. RAPID: A Real-Time Defense Against Unauthorized Model Distillation for Text-to-Image Services  🆕
- **저자**: Zihan Wang, Boheng Li, Rui Zhang, Wenshu Fan, Qingchuan Zhao, et al.
- **키워드**: model stealing, model distillation, adversarial defense
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.15799](https://arxiv.org/abs/2609.15799) (v1)
- **PDF**: [arxiv.org/pdf/2609.15799](https://arxiv.org/pdf/2609.15799.pdf)
- **핵심 요약**: 텍스트-이미지 서비스는 질의로 수집한 입출력 쌍을 이용한 블랙박스 증류로 모델 능력을 탈취당할 수 있다. 기존 방어는 이미지마다 최적화를 수행해 온라인 지연이 크고, 공용 VAE 디코더에 그대로 옮기기 어렵다. RAPID는 자기참조 잠재 최대화와 재구성 기반 색상 정규화를 결합해 디코더가 방어 이미지를 직접 생성하게 한다. 네 모델과 네 데이터셋, 다섯 기준선 비교에서 서비스 화질은 유지하면서 대체 모델의 생성 품질을 일관되게 낮췄다.

## 4. When the World Lies: Backdoor Attacks on Latent World Models for Downstream Control  🆕
- **저자**: Roberto Riaño, Gorka Abad, Stjepan Picek, Aitor Urbieta
- **키워드**: backdoor, supply-chain attack, latent world model
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.15781](https://arxiv.org/abs/2609.15781) (v1)
- **PDF**: [arxiv.org/pdf/2609.15781](https://arxiv.org/pdf/2609.15781.pdf)
- **핵심 요약**: 사전학습된 월드 모델을 제어기의 동역학 백본으로 재사용하면 체크포인트 공급망이 새로운 백도어 표면이 된다. 공격자는 트리거 관측을 특정 잠재 영역으로 보내고 국소 동역학을 바꿔, 피해자의 최적화가 공격 목표 행동을 스스로 재발견하게 만든다. 가장 강한 설정에서는 트리거가 모든 행동 차원을 조종하며 트리거된 단계의 100%를 탈취했다. 체크포인트는 깨끗한 작업 성공률을 최소 약 75% 유지했고, 중간 수준의 깨끗한 미세조정으로는 백도어가 제거되지 않았다.

## 5. Adversarial Testing of Automated Program Repair Agents for Security Vulnerabilities  🆕
- **저자**: Fares Trad, Simin Chen, Hung Viet Pham, Gias Uddin, Baishakhi Ray
- **키워드**: adversarial attacks, agent safety, automated program repair
- **출처**: arxiv recent
- **arxiv abstract**: [2609.15963](https://arxiv.org/abs/2609.15963) (v1)
- **PDF**: [arxiv.org/pdf/2609.15963](https://arxiv.org/pdf/2609.15963.pdf)
- **핵심 요약**: 자동 프로그램 수리 에이전트는 정상적인 이슈처럼 보이는 입력을 받아 기능적으로 맞지만 취약한 패치를 만들 수 있다. SWEADV는 SWE-bench Verified의 150개 수리 작업에서 다섯 공격 유형을 적용한 750개 적대적 이슈를 구성한다. 세 LLM 백엔드의 mini_swe 에이전트는 평균 51.7%에서 수리 성공과 악성 행동을 동시에 보였다. 사전 LLM 판별 정확도는 62.3%였고, 사후 정적 분석과 LLM 판별도 각각 39.4%와 55.4%에 그쳤다.

## 6. Vulnerability Localization Benchmark: Measuring Agentic Security Analysis at Repository Scale  🆕
- **저자**: Aman Priyanshu, Supriti Vijay, Kimia Majd, Xuhong He, Fraser Burch, et al.
- **키워드**: agent safety, vulnerability localization, security evaluation
- **출처**: arxiv recent
- **arxiv abstract**: [2609.15939](https://arxiv.org/abs/2609.15939) (v1)
- **PDF**: [arxiv.org/pdf/2609.15939](https://arxiv.org/pdf/2609.15939.pdf)
- **핵심 요약**: 보안 에이전트 평가는 취약점 탐지나 수리는 측정하지만, 저장소에서 관련 파일을 정확히 찾는 능력은 분리해 다루지 않았다. VLoc Bench는 290개 저장소, 여섯 패키지 생태계, 147개 CWE 범주의 실제 취약점 500개를 포함한다. 27개 언어 모델과 네 정적 분석 도구를 동일한 에이전트 인터페이스에서 평가했다. 최강 시스템의 File F1은 0.229였고, 작업의 38.4%에서는 어떤 모델도 올바른 위치를 하나도 찾지 못했다.

- **키워드**: prompt injection, multi-agent security, agent safety
- **출처**: arxiv recent
- **arxiv abstract**: [2609.15516](https://arxiv.org/abs/2609.15516) (v1)
- **PDF**: [arxiv.org/pdf/2609.15516](https://arxiv.org/pdf/2609.15516.pdf)
- **핵심 요약**: 중앙집중형 다중 에이전트 시스템은 외부 작업자 설명을 계획 입력으로 신뢰해 등록 시점 주입에 노출된다. 공격 페이로드는 사용자 요청 전에 심어지며, 조작된 작업자가 실제로 호출되지 않아도 생성된 계획을 통해 전파된다. 세 마켓플레이스의 설명 32,000개를 분석하고 여덟 공격 전략을 GAIA에서 평가했다. 단일 조작 설명은 성공률을 84.31%에서 37.25%로 낮추거나 토큰·실행시간을 111% 넘게 늘렸고, DescGuard가 계획 입력을 작업자 인터페이스 정보로 제한해 이를 완화했다.

## 8. ActGuard: Pre-execution Action Auditing against Indirect Prompt Injection in LLM Agents  🆕
- **저자**: Bingzheng Wang, Xiaoyan Gu, Wentao Wang, Xingyou Yang, Hongcheng Li, et al.
- **키워드**: indirect prompt injection, agent safety, action auditing
- **출처**: arxiv recent
- **arxiv abstract**: [2609.14987](https://arxiv.org/abs/2609.14987) (v1)
- **PDF**: [arxiv.org/pdf/2609.14987](https://arxiv.org/pdf/2609.14987.pdf)
- **핵심 요약**: 도구 출력에 섞인 간접 프롬프트 주입은 에이전트의 다음 행동을 오염시키지만, 전체 콘텐츠 필터링은 정상 작업 효용을 떨어뜨린다. ActGuard는 다음 행동의 로컬 도구 사전을 예측하고 후보 행동의 도구 선택과 인자 편차를 실행 전에 감사한다. 검증기가 편차를 만든 근거 구간만 마스킹한 뒤 정제된 문맥에서 행동을 다시 생성한다. 평가에서는 최신 방어와 비슷한 수준으로 공격 성공률을 낮추면서 무공격 설정에 가까운 작업 효용을 유지했다.

## 9. SpliTEE: Improving LLM Inference on Trusted Hardware with Differentially Private GPU Outsourcing  🆕
- **저자**: Shashie Dilhara Batan Arachchige, Robin Carpentier, Hassan Jameel Asghar, Dali Kaafar
- **키워드**: differential privacy, prompt reconstruction, trusted execution
- **출처**: arxiv recent
- **arxiv abstract**: [2609.15039](https://arxiv.org/abs/2609.15039) (v1)
- **PDF**: [arxiv.org/pdf/2609.15039](https://arxiv.org/pdf/2609.15039.pdf)
- **핵심 요약**: CPU 중심 TEE에서 LLM 전체를 실행하면 느리지만, 중간 표현을 비신뢰 GPU로 보내면 프롬프트 복원 위험이 생긴다. 저자들은 보호하지 않은 중간 표현에서 프롬프트를 거의 80% 정확도로 복원할 수 있음을 보였다. SpliTEE는 LLM 연산을 TEE와 GPU로 분할하고 전역 민감도 분석에 따른 차등프라이버시 잡음으로 중간 표현을 가린다. Intel TDX에서 완전 CPU 추론보다 거의 두 배 빨랐고, 암호화 기반 Slalom보다 5–15초 빠르면서 더 높은 정확도를 기록했다.

## 10. PIDS-Bench: Evaluating Prompt-Injection Detectors Under Over-Defense, Obfuscation, and Distribution Shift  🆕
- **저자**: Yusuf Khalid Shire, Sang-Chul Kim
- **키워드**: prompt injection, adversarial robustness, security evaluation
- **출처**: arxiv recent
- **arxiv abstract**: [2609.15017](https://arxiv.org/abs/2609.15017) (v1)
- **PDF**: [arxiv.org/pdf/2609.15017](https://arxiv.org/pdf/2609.15017.pdf)
- **핵심 요약**: 프롬프트 주입 탐지기를 분포 내 F1만으로 평가하면 정상 보안 문구를 공격으로 오인하는 과잉 방어를 숨길 수 있다. PIDS-Bench는 정상 난제, 난독화 공격, 도메인·구조 분포 이동을 고정 임계값에서 함께 평가한다. 검증 F1이 0.98을 넘는 탐지기도 외부 정상 하위집합의 약 3분의 1을 오분류했다. 다섯 시드와 전체 임계값 탐색에서 F1 0.95 이상과 정상 난제 FPR 0.10 이하를 동시에 만족한 내부 탐지기는 없었다.
