## 1. Why Does Post-Training Quantization Work?  🆕
- **저자**: Yuxiang Chen, Michael Beyer, Jun Zhu, Jianfei Chen
- **키워드**: mechanistic interpretability, quantization, residual interaction, LM-head geometry
- **출처**: alphaxiv / arxiv recent
- **arxiv abstract**: [2609.11716](https://arxiv.org/abs/2609.11716) (v1)
- **PDF**: [arxiv.org/pdf/2609.11716](https://arxiv.org/pdf/2609.11716.pdf)
- **핵심 요약**: 사후 양자화 오차가 층마다 누적되는데도 사전학습 LLM의 성능이 유지되는 이유는 충분히 설명되지 않았다. 연구는 원본과 양자화 모델의 forward pass를 비교해 두 메커니즘을 찾았다. 각 층의 새 오차는 이전 오차와 반대 방향으로 상쇄되며, 이 성질은 사전학습 중 형성된다. LM head의 기하 구조도 상위 토큰 점수를 우선 보존해 최종 출력 변화를 줄인다.

## 2. CS-Guard: Benchmarking LLM Guardrails for Code Generation Security  🆕
- **저자**: Jinyang Li, Mingyu Guo, Hung X. Nguyen
- **키워드**: guardrails, jailbreak, malicious code generation, red-teaming
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.09798](https://arxiv.org/abs/2609.09798) (v1)
- **PDF**: [arxiv.org/pdf/2609.09798](https://arxiv.org/pdf/2609.09798.pdf)
- **핵심 요약**: 코드 생성 LLM의 guardrail이 악성 요청을 얼마나 막는지는 체계적으로 비교되지 않았다. CS-Guard는 악성 프롬프트 1,000개와 jailbreak 7종, 코드 변환 프롬프트 331개를 제공한다. 7개 LLM에서 9개 guardrail을 평가했다. Text-to-code 공격 성공률은 다수 방어에서 약 50%였고, code-to-code는 14.4%에서 거의 100%까지 나타났다.

- **핵심 요약**: 운영 보안 로그는 LLM 처리량을 넘어서며, 제약 없는 에이전트 대응은 새로운 위험을 만든다. BlueSTAR는 대량 telemetry를 침해 지표로 압축하고 대응을 계층화한다. 방어 효과와 핵심 자산 피해, 대응 부작용을 함께 보는 resilience metric도 제안한다. 두 IT/OT cyber range의 7개 공격 chain에서 알려진 공격과 문맥 추론이 필요한 공격을 모두 방어했다.

## 4. LLM Forensics: Where Do Backdoors Hide? Localizing and Controlling Trigger Mechanisms with Sparse Autoencoders  🆕

- **키워드**: sparse autoencoder, backdoor, causal intervention, circuit analysis
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.07746](https://arxiv.org/abs/2609.07746) (v1)
- **PDF**: [arxiv.org/pdf/2609.07746](https://arxiv.org/pdf/2609.07746.pdf)
- **핵심 요약**: Backdoor trigger를 탐지하는 내부 feature가 실제 행동을 제어하는지는 불분명하다. 연구는 1B와 8B 모델의 언어 전환 backdoor에 층별 SAE를 학습했다. Attention과 MLP feature는 trigger를 거의 완벽히 구분하지만, ablation과 activation으로 행동을 바꾸는 경우는 드물었다. 반면 residual-stream feature는 언어 전환을 억제하거나 유도해 탐지와 인과 제어의 분리를 보여준다.

## 5. Subgroup Membership Inference Audits of Differentially Private Synthetic Text  🆕
- **저자**: Yidan Sun, Viktor Schlegel, Srinivasan Nandakumar, Siew Kei Lam, Anil Anthony Bharath
- **키워드**: membership inference, differential privacy, synthetic text, subgroup auditing
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.09848](https://arxiv.org/abs/2609.09848) (v1)
- **PDF**: [arxiv.org/pdf/2609.09848](https://arxiv.org/pdf/2609.09848.pdf)
- **핵심 요약**: 평균 membership risk만 측정하면 취약 subgroup의 잔여 leakage가 가려질 수 있다. 연구는 32개 proxy를 4개 데이터셋과 3개 생성기, 5개 privacy budget에서 감사한다. DP는 평균 leakage를 줄였지만, 상위 10% record가 잔여 leakage의 약 40%를 차지했다. 누가 노출되는지는 record 자체보다 release mechanism에도 의존해 subgroup 중심 감사가 필요하다.

## 7. A2ABreak: Systematic Security Analysis of the A2A Protocol  🆕
- **저자**: Alireza Lotfi, Mirza Masfiqur Rahman, Imtiaz Karim, Elisa Bertino
- **키워드**: agent security, protocol analysis, context injection, data exfiltration
- **출처**: arxiv recent
- **arxiv abstract**: [2609.10871](https://arxiv.org/abs/2609.10871) (v1)
- **PDF**: [arxiv.org/pdf/2609.10871](https://arxiv.org/pdf/2609.10871.pdf)
- **핵심 요약**: 조직 간 AI agent 위임을 지원하는 A2A protocol은 체계적인 보안 분석이 부족했다. A2ABreak는 929개 명세 문장에서 37개 상태와 76개 전이의 검증된 상태 기계를 추출한다. 명세를 준수하는 공격자도 악용할 수 있는 취약점 11개를 발견했다. 전문가 검토 대비 precision은 73.3%, F1은 84.6%였고 zero-shot LLM은 확인된 취약점을 찾지 못했다.

## 8. Detectable Only Where It Is Confounded: What Verified Duplication Counts Say About Membership Evidence in Language Models  🆕

- **키워드**: membership inference, training data exposure, duplication, confounding
- **출처**: arxiv recent
- **arxiv abstract**: [2609.10830](https://arxiv.org/abs/2609.10830) (v1)
- **PDF**: [arxiv.org/pdf/2609.10830](https://arxiv.org/pdf/2609.10830.pdf)
- **핵심 요약**: 낮은 perplexity를 학습 데이터 membership의 증거로 해석하면 문장 품질과 유명세가 혼입될 수 있다. 공개 corpus count를 가진 OLMo-2와 Pythia에서 실제 중복 횟수를 기준으로 시험했다. 일반 중복 구간의 노출 상관은 약 -0.08로 약했고, 천 회 이상에서는 유명세와 노출을 분리하기 어려웠다. Control 문장의 register를 바꾸자 AUC가 0.83에서 0.94로 상승해 평가 구성 자체가 신호를 만들 수 있음을 보였다.

## 10. An Empirical Measurement of Jailbreaking Evaluators  🆕
- **저자**: Yujie Mu
- **키워드**: jailbreak, safety evaluation, LLM judge, benchmark reliability
- **출처**: arxiv recent
- **arxiv abstract**: [2609.10594](https://arxiv.org/abs/2609.10594) (v1)
- **PDF**: [arxiv.org/pdf/2609.10594](https://arxiv.org/pdf/2609.10594.pdf)
- **핵심 요약**: 자동 jailbreak evaluator마다 성공 정의가 달라 공격 강도와 연구 진전의 해석이 달라질 수 있다. 연구는 반복 사용되는 evaluator 6개를 동일한 사람 판정 데이터에서 비교한다. JailbreakQR과 JailMeter-Eva를 사용하고, LLM judge가 필요한 경우 같은 backbone을 적용했다. JADES가 전체적으로 가장 우수했고 HarmBench와 StrongReject도 양호했지만, evaluator 선택 자체가 중요한 실험 변수임을 확인했다.
