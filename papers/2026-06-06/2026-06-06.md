## 1. BraveGuard: From Open-World Threats to Safer Computer-Use Agents 🆕

- **저자**: Yunhao Feng, Xiaohu Du, Xinhao Deng, Yifan Ding, Yixu Wang et al.
- **키워드**: `agent safety`, `computer-use agents`, `guard model`, `trajectory-level safety`, `red-teaming`
- **출처**: HF Daily (5 upvotes)
- **arxiv abstract**: [2606.01166](https://arxiv.org/abs/2606.01166) (v2)
- **PDF**: [arxiv.org/pdf/2606.01166](https://arxiv.org/pdf/2606.01166.pdf)

**핵심 요약**: 컴퓨터-사용 에이전트는 파일·터미널·브라우저와 연속 상호작용하며 위험을 일으키지만, 개별 액션만 보면 benign해 보여 탐지가 어렵다. BraveGuard는 인터넷 상의 최신 위협 신호를 자동 수집·분류하여 실제 에이전트 실행 trace로부터 trajectory-level 감시 데이터를 생성하는 자가진화 방어 프레임워크다. Qwen3-Guard, Llama-Guard 등 다수 가드 모델에 적용한 결과, AgentHazard 벤치마크에서 평균 정확도가 38.79% → 82.38%로 크게 향상되어, 고정된 taxonomy 없이도 진화하는 위협을 지속 방어할 수 있음을 보였다.

## 3. LLMs Can Leak Training Data But Do They Want To? A Propensity-Aware Evaluation of Memorization in LLMs 🆕

- **저자**: Gianluca Barmina, Peter Schneider-Kamp, Lukas Galke Poech (University of Southern Denmark)
- **키워드**: `training data leakage`, `memorization`, `data extraction`, `propensity`, `privacy audit`
- **출처**: HF Daily (7 upvotes)
- **arxiv abstract**: [2606.06286](https://arxiv.org/abs/2606.06286) (v1)
- **PDF**: [arxiv.org/pdf/2606.06286](https://arxiv.org/pdf/2606.06286.pdf)

**핵심 요약**: 기존 암기 평가는 "모델이 학습 데이터를 강제로 유출시킬 수 있느냐"(capability, 적대적 prefix 공격)만 측정했지만, 이 논문은 "일반 사용 중에 얼마나 유출하려 하느냐"(propensity)를 구별하는 PropMe 프레임워크와 SimpleTrace 파이프라인을 제안한다. Comma·DFM Decoder를 Common Pile·Dynaword로 평가한 결과, capability와 propensity 사이에는 큰 격차가 존재했다 — prefix 공격은 강한 암기 신호를 유도하지만, 일반 사용에서의 유출 성향은 낮았다. 향후 감사에서는 worst-case extractability와 ordinary propensity를 모두 보고해야 한다고 권고한다.

## 4. STRIDE: Training Data Attribution via Sparse Recovery from Subset Perturbations 🆕

- **저자**: (7명, 소속 확인 필요)
- **키워드**: `training data attribution`, `feature attribution`, `sparse recovery`, `activation space`, `compressive sensing`
- **출처**: HF Daily (3 upvotes)
- **arxiv abstract**: [2606.05165](https://arxiv.org/abs/2606.05165) (v1)
- **PDF**: [arxiv.org/pdf/2606.05165](https://arxiv.org/pdf/2606.05165.pdf)

**핵심 요약**: 기존 TDA(Training Data Attribution)의 gradient 기반 접근법은 수십억 파라미터에 걸친 추적이 필요해 LLM에 적용하기 어렵다. STRIDE는 파라미터 공간 대신 **activation 공간**에서 TDA를 sparse recovery 문제로 재정의하여, 데이터 서브셋 섭동이 모델 행동에 미치는 기능적 영향을 "steering operators"로 근사한다. compressive sensing 개념의 적용으로 반복 재학습 없이도 훈련 데이터 기여도를 효율적으로 추적할 수 있게 한다.

- **arxiv abstract**: [2606.01317](https://arxiv.org/abs/2606.01317) (v1)
- **PDF**: [arxiv.org/pdf/2606.01317](https://arxiv.org/pdf/2606.01317.pdf)

**핵심 요약**: 기존 코딩 에이전트 안전 벤치마크는 단일 프롬프트 거부 여부만 측정하지만, 실제 위험은 파일 삭제·코드 실행·시스템 변경 등 stateful workspace에서 발생한다. SABER는 에이전트가 수행한 액션 시퀀스 이후 **최종 환경 상태**로 안전을 평가하는 벤치마크로, 위반 원인도 범주화한다. 현존 최고 성능 모델조차 54% 이상의 harmful safety-violation rate(HSR)를 기록하여, 현재 정렬 기술이 실전 개발 환경에 충분하지 않음을 드러냈다.

- **arxiv abstract**: [2605.28116](https://arxiv.org/abs/2605.28116) (v1)
- **PDF**: [arxiv.org/pdf/2605.28116](https://arxiv.org/pdf/2605.28116.pdf)

**핵심 요약**: 모바일 GUI 에이전트는 화면 픽셀 전체를 인식하므로 신뢰된 UI와 사용자 생성 콘텐츠(UGC)를 구분하지 못한다는 근본적 취약점을 공략한다. MIRAGE는 앱을 수정하지 않고 스크린샷 내 UGC 영역에 context-aware 악성 지시를 삽입하는 3단계 파이프라인(Localizer → Generator → Renderer)을 구현했다. 10개 앱·11개 공격 의도로 구성된 1,111샘플 벤치마크에서 평가한 5개 VLM 에이전트 모두 취약하여 공격 성공률 23-30%를 기록했다.

## 10. Aligning Provenance with Authorization: A Dual-Graph Defense for LLM Agents 🆕

- **저자**: Peiran Wang, Ying Li, Yuan Tian (UCLA)
- **키워드**: `prompt injection defense`, `agent security`, `provenance`, `authorization`, `tool-use integrity`
- **출처**: SNS (AI Security Hub blog)
- **arxiv abstract**: [2605.26497](https://arxiv.org/abs/2605.26497) (v1)
- **PDF**: [arxiv.org/pdf/2605.26497](https://arxiv.org/pdf/2605.26497.pdf)

**핵심 요약**: LLM 에이전트의 간접 prompt injection 공격에서 핵심 문제는 외부에서 온 정보(이메일, 웹페이지)가 에이전트의 tool call 파라미터를 오염시킨다는 점이다. 이 연구는 정보의 출처(provenance)와 작업 권한(authorization)을 각각 그래프로 모델링하고 둘을 연결하는 **이중 그래프(Dual-Graph)** 방어 프레임워크를 제안한다. 신뢰할 수 없는 출처에서 유래한 파라미터가 권한을 초과한 작업을 실행하지 못하도록 agent-tool 경계에서 차단하여, 프롬프트 수준이 아닌 데이터 흐름 수준에서 방어한다.
