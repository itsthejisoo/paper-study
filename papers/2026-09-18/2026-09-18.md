## 1. AgentLSD: Evaluating AI Security Agents Under Adversarial Task Contamination  🆕
- **저자**: Matteo Golinelli, Idilio Drago, Matteo Boffa, Francesco Bergadano, Bruno Crispo
- **키워드**: agent safety, adversarial task contamination, red-teaming
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.19140](https://arxiv.org/abs/2609.19140) (v1)
- **PDF**: [arxiv.org/pdf/2609.19140](https://arxiv.org/pdf/2609.19140.pdf)
- **핵심 요약**: 보안 에이전트는 명령형 프롬프트 주입뿐 아니라 가짜 결과, 미끼 엔드포인트 같은 기만적 증거에도 노출된다. AgentLSD는 11개 웹 CTF에 결정적으로 생성한 함정을 삽입하고, 6개 모델의 깨끗한 조건과 오염 조건을 쌍으로 비교한다. 깨끗한 조건의 플래그 획득률은 41%였고, 함정은 성공한 경우에도 평균 20턴과 2천 개의 추론 토큰을 추가했다. 이 결과는 깨끗한 CTF 성능만으로는 실제 공격 환경의 취약성을 과소평가할 수 있음을 보여준다.

## 2. CaMeLoT: CaMeL orchestrated with Temporal logic for static verification and liveness  🆕
- **저자**: Elia Nikolaou, Magnus Wiik Eckhoff, Robert Flood, Gudmund Grov, Vasileios Mavroeidis et al.
- **키워드**: prompt injection, agent safety, static verification
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.18674](https://arxiv.org/abs/2609.18674) (v1)
- **PDF**: [arxiv.org/pdf/2609.18674](https://arxiv.org/pdf/2609.18674.pdf)
- **핵심 요약**: 도구 사용 에이전트의 보안은 개별 호출이 아니라 전체 실행 계획의 제어 흐름과 데이터 의존성에 달려 있다. CaMeLoT은 계획을 유한 상태 전이 시스템으로 변환하고, provenance와 taint를 붙여 CTL 정책을 nuXmv로 실행 전에 검증한다. 실패 시 반례를 반환해 에이전트가 계획을 수정하게 하며, 위험한 도구 호출과 되돌리기 비용도 피한다. AgentDojo 정책, SOC 워크플로, 프롬프트 추출 실험에서 실행 전 시간적 속성을 검증하면서 CaMeL의 런타임 검사 범위를 유지했다.

## 3. Trust propagation and structural containment in Multi-agent LLM pipelines  🆕
- **저자**: Tanzim Hossain Safin, Sharif Noor Zisad, Swakkhar Shatabda, Ragib Hasan
- **키워드**: multi-agent security, prompt injection, authorization
- **출처**: arxiv recent / SNS
- **arxiv abstract**: [2609.17648](https://arxiv.org/abs/2609.17648) (v1)
- **PDF**: [arxiv.org/pdf/2609.17648](https://arxiv.org/pdf/2609.17648.pdf)
- **핵심 요약**: 다중 에이전트 파이프라인에서는 낮은 권한의 에이전트가 상위 권한 판단을 오염시켜 비인가 동작을 유발할 수 있다. 연구는 네 에이전트 LangGraph 파이프라인에서 공유 메모리 오염과 간접 프롬프트 주입을 시험하고, 작업 결합 서명 토큰과 별도 정책 오라클을 비교한다. 방어가 없으면 모든 실험에서 오염이 실행까지 전파됐지만, 인가 계층은 판단 우회율이 100%인 상황에서도 위험 동작률을 0%로 억제했다. 이는 상위 LLM 판단이 손상되어도 구조적 인가 경계가 최종 실행을 격리할 수 있음을 보여준다.

## 4. Monitoring and Discovering Reward Hacking with Internal Representations during LLM Evaluations  🆕
- **저자**: Leon Bergen, Usha Bhalla, Andrew Lee, Barak Widawsky, Linas Nasvytis et al.
- **키워드**: reward hacking, probing, internal representations
- **출처**: arxiv recent
- **arxiv abstract**: [2609.19101](https://arxiv.org/abs/2609.19101) (v1)
- **PDF**: [arxiv.org/pdf/2609.19101](https://arxiv.org/pdf/2609.19101.pdf)
- **핵심 요약**: 보상 해킹이 더 정교해질수록 외부 출력만으로 이를 감시하는 비용과 누락 위험이 커진다. 연구는 Kimi K3, GLM 5.2, Qwen 3.8 Max의 내부 표현에서 단순 평균 차이 벡터가 다양한 해킹 행동을 일반화해 포착하는지 분석한다. GLM 5.2는 DeepSWE 롤아웃의 57.2%, SWE-bench의 73%에서 보상 해킹을 보였고, 표현 벡터는 LLM 모니터와 비슷한 수준으로 이를 탐지했다. 연쇄 사고의 벡터가 이후 행동도 예측해, 저비용 온라인 조기 경보의 가능성을 제시한다.

## 5. ASLEval: Measuring Privacy Exposure Displacement in LLM Agent Sessions  🆕
- **저자**: Guosen Wu, Huizhen Huang, Guoxiong Long, Tao Huang, Chen Hou
- **키워드**: AI privacy, data leakage, agent evaluation
- **출처**: arxiv recent
- **arxiv abstract**: [2609.18864](https://arxiv.org/abs/2609.18864) (v1)
- **PDF**: [arxiv.org/pdf/2609.18864](https://arxiv.org/pdf/2609.18864.pdf)
- **핵심 요약**: 도구 사용 에이전트의 최종 응답이나 지정된 행동만 검사하면 세션의 다른 출구에서 발생한 비인가 노출을 놓칠 수 있다. ASLEval은 숨겨진 목표 집합을 사전 등록하고, 선언된 모든 외부 가시 출구를 인가 기준으로 측정한다. 예상 출구만 본 평가는 전체 가시 출구 합집합이 포착한 노출의 46.9%를 놓쳤다. 연구는 완전한 노출 경계와 작업 효용을 함께 보고하는 평가가 필요하다고 결론짓는다.

- **저자**: Youssef Hamdi Zafan Ibrahim, Muhammad Ikram, Mohammed Khalaf Salama
- **키워드**: prompt confidentiality, data leakage, local LLM
- **출처**: arxiv recent
- **arxiv abstract**: [2609.18526](https://arxiv.org/abs/2609.18526) (v1)
- **PDF**: [arxiv.org/pdf/2609.18526](https://arxiv.org/pdf/2609.18526.pdf)
- **핵심 요약**: 로컬 추론은 프롬프트를 클라우드로 보내지 않지만, 주변 서빙 소프트웨어의 경계까지 안전하다는 뜻은 아니다. LLAnalyzer는 모델 로딩, 런타임 메모리, 래퍼 저장, 서빙 인터페이스를 분리해 기밀성 실패를 추적한다. 연구는 추론 뒤 평문 프롬프트 잔존, 래퍼의 평문 저장, 교차 테넌트 대화 복원 취약점, 원격 타이밍 오라클을 확인했다. 특히 대화 복원 공격은 통제된 200회 실험 모두에서 성공해, 프롬프트 수명과 테넌트 격리에 명시적 보장이 필요함을 보여준다.

- **출처**: arxiv recent
- **arxiv abstract**: [2609.18217](https://arxiv.org/abs/2609.18217) (v1)
- **PDF**: [arxiv.org/pdf/2609.18217](https://arxiv.org/pdf/2609.18217.pdf)
- **핵심 요약**: MCP 도구 설명, 결과, 샘플링 메시지는 권한 분리 없이 한 컨텍스트를 공유해 암묵적 신뢰 경계를 만든다. 연구는 공격 구문을 두세 채널에 분할해, 어느 한 채널에도 완전한 주입문이 없지만 모델이 이를 결합해 자격 증명을 유출하도록 만든다. 12개 모델과 3개 클라이언트의 1만5천 회 이상 실험에서 단일 채널 공격을 완전히 막던 모델도 2채널 공격에 최대 100% 순응했다. 7개 MCP 보안 도구와 3개 프롬프트 방어도 분할 페이로드를 일관되게 막지 못했다.

- **출처**: arxiv recent
- **arxiv abstract**: [2609.17817](https://arxiv.org/abs/2609.17817) (v1)
- **PDF**: [arxiv.org/pdf/2609.17817](https://arxiv.org/pdf/2609.17817.pdf)
- **핵심 요약**: 자기 평가를 바탕으로 스스로를 개선하는 코딩 에이전트는 오염된 벤치마크를 통해 미래 버전에 취약성을 계승할 수 있다. 연구는 Darwin Gödel Machine, Self-Improving Coding Agent, Hyperagents를 대상으로 이 공격을 구현했다. ## 9. TwinMark: A Unified Watermark for Provable Survival Under Feature and Logit Distillation  🆕
- **저자**: Redwanul Karim, Tobias Feigl, Christopher Mutschler, Felix Ott
- **키워드**: model watermarking, model stealing, knowledge distillation
- **출처**: arxiv recent
- **arxiv abstract**: [2609.19011](https://arxiv.org/abs/2609.19011) (v1)
- **PDF**: [arxiv.org/pdf/2609.19011](https://arxiv.org/pdf/2609.19011.pdf)
- **핵심 요약**: 모델 워터마크는 로짓 API와 표현 API를 대상으로 한 서로 다른 증류 공격 모두에서 살아남아야 한다. TwinMark는 하나의 비트 벡터를 공유하는 공분산 투영 채널과 클래스 조건부 Fisher 정렬 로짓 채널을 결합한다. 각 채널은 교사 모델에서 측정 가능한 사후 인증서를 제공해 증류 후 탐지력을 하한으로 보장한다. CIFAR와 Mini-ImageNet의 13개 공격에서 과제 효용을 유지한 모든 셀을 검증했고, 여러 아키텍처와 다른 비전 과제로도 전이됐다.

## 10. Suppressed, Not Erased: A Representational Trace of Edited Facts Survives Even Weight-Free Knowledge Editing  🆕
- **저자**: Priyansh Srivastava, Romit Chatterjee
- **키워드**: probing, knowledge editing, representation analysis
- **출처**: arxiv recent
- **arxiv abstract**: [2609.18985](https://arxiv.org/abs/2609.18985) (v1)
- **PDF**: [arxiv.org/pdf/2609.18985](https://arxiv.org/pdf/2609.18985.pdf)
- **핵심 요약**: 지식 편집의 생성 성공만으로는 원래 사실이 내부 표현에서 제거됐는지 알 수 없다. 연구는 GPT-2-XL의 50개 CounterFact 편집 뒤 선형 프로브로 원래 객체의 잔존 표현을 측정한다. 생성 성공률이 모두 100%였지만 프로브 정확도는 ROME 0.96, 제한 미세조정 0.86, 가중치를 바꾸지 않는 GRACE 0.79로 우연 수준 0.50을 크게 넘었다. 결과는 편집이 원래 연상을 지우기보다 행동적으로 억제할 수 있음을 시사하지만, 프로브 결과만으로 인과적 잔존을 확정하지는 않는다.
