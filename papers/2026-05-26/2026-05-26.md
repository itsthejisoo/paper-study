## 1. REFLECTOR: Internalizing Step-wise Reflection against Indirect Jailbreak  🆕

- **저자**: Jiachen Ma, Jiawen Zhang, Xiangtian Li, Bo Zou, Chaochao Lu, Chao Yang
- **키워드**: `jailbreak defense`, `multi-step jailbreak`, `self-reflection`, `SFT`, `reinforcement learning`
- **출처**: arxiv cs.CR
- **arxiv abstract**: [2605.20654](https://arxiv.org/abs/2605.20654) (v1, 2026-05-20)
- **PDF**: [arxiv.org/pdf/2605.20654](https://arxiv.org/pdf/2605.20654)

**핵심 요약** (3-5문장 한국어):
LLM은 여전히 간접적·다단계 jailbreak 공격에 취약하며, 기존 방어 방법들은 단순 직접 공격에는 효과적이나 복잡한 간접 공격에 쉽게 뚫린다. REFLECTOR는 LLM의 생성 궤적 내에 단계별 자기 반성(self-reflection)을 내재화하는 2단계 프레임워크다: 먼저 교사 모델 유도 생성으로 고품질 반성 데이터를 구축해 SFT로 구조적 패턴을 학습시키고, 이후 결과 기반 및 보상 유효성 지도를 통한 RL로 자율적 자기 반성 능력을 강화한다. 복잡한 간접 공격에 대해 90% 초과 Defense Success Rate(DSR)를 달성하면서도 다양한 위협 시나리오에 걸쳐 강건하게 일반화한다.

**핵심 요약** (3-5문장 한국어):
대조적 활성화 조향(contrastive activation steering)은 jailbreak에 강력한 도구이나, 기존 방법들은 편향된 대조 프롬프트에 의존하고 조향 강도를 수동으로 조정해야 하는 한계가 있다. 이 논문은 모델 추출(model extraction)을 활용해 조향 벡터를 유도하고, 대조 활성화 통계에 기반한 조향 강도 자동 조정을 통해 추가 대조 프롬프트나 수동 튜닝 없이 프로브 기반 조향의 효과성과 견고성을 향상한다. 안전 정렬된 모델에서 평균 해로움 점수를 6%에서 70%로 끌어올려, 현재 프로브 기반 방어의 심각한 취약점을 입증한다.

- **출처**: arxiv cs.CR / cs.CL
- **arxiv abstract**: [2605.12456](https://arxiv.org/abs/2605.12456) (v1, 2026-05-12)
- **PDF**: [arxiv.org/pdf/2605.12456](https://arxiv.org/pdf/2605.12456)

**핵심 요약** (3-5문장 한국어):
TextSeal은 Gumbel-max 샘플링을 기반으로 이중 키 생성, 엔트로피 가중 점수화, 다중 구역 지역화를 도입한 왜곡 없는(distortion-free) LLM 출력 워터마크다. 투기적 디코딩(speculative decoding) 등 서빙 최적화를 지원하고 추론 오버헤드가 없으며, SynthID-text 등 기존 방법 대비 탐지 강도에서 우위를 보이고 희석에 강건하다. 주목할 만한 특성은 "방사성(radioactive)" — 워터마크 신호가 모델 증류(distillation)를 거쳐도 전파되어, 워터마크된 LLM 출력으로 무단 학습된 증류 모델을 탐지할 수 있다. 6,000회 A/B 비교(5개 언어)의 인간 평가에서 텍스트 품질 차이를 인식하지 못함을 확인했다.

## 4. When Efficiency Backfires: Cascading LLMs Trigger Cascade Failure under Adversarial Attack  🆕

- **출처**: arxiv cs.CR
- **arxiv abstract**: [2605.17288](https://arxiv.org/abs/2605.17288) (v1, 2026-05-17)
- **PDF**: [arxiv.org/pdf/2605.17288](https://arxiv.org/pdf/2605.17288)

**핵심 요약** (3-5문장 한국어):
LLM 캐스케이드 시스템은 경량 모델이 쿼리를 처리하고 복잡한 케이스만 강력한 모델로 에스컬레이션해 효율과 성능의 균형을 맞추지만, 이 설계가 새로운 공격 표면을 만든다. 이 논문은 LLM 캐스케이드 시스템이 캐스케이드 의존성 하의 적대적 서픽스(adversarial suffix) 순차적 협력 최적화 프레임워크를 통해 비용 효율과 정확도를 동시에 저하시키는 표적 적대적 조작에 취약함을 최초로 실증한다. 단독 모델을 타겟하는 기존 공격과 달리, 이 접근법은 캐스케이드 구조 자체를 활용해 경량 모델과 라우팅 메커니즘을 동시에 공략함으로써 훨씬 강한 영향을 달성한다. 다양한 데이터셋과 대표적 LLM 캐스케이드 시스템에서 광범위한 실험으로 실용성과 심각성을 검증했다.

**핵심 요약** (3-5문장 한국어):

UCSD의 Kamalika Chaudhuri 등 저명한 프라이버시 연구자들이 참여한 연구로, 클로즈드 API LLM 환경에서도 데이터 사용 감사를 가능하게 하는 실용적 방법론을 제시한다.

## 8. Minimal, Local, Causal Explanations for Jailbreak Success in Large Language Models  🆕

- **저자**: Shubham Kumar, Narendra Ahuja
- **키워드**: `mechanistic interpretability`, `causal explanation`, `jailbreak`, `LOCA`, `representation intervention`
- **출처**: arxiv cs.LG / cs.CR
- **arxiv abstract**: [2605.00123](https://arxiv.org/abs/2605.00123) (v1, 2026-05-01)
- **PDF**: [arxiv.org/pdf/2605.00123](https://arxiv.org/pdf/2605.00123)

**핵심 요약** (3-5문장 한국어):
특정 jailbreak 시도가 왜 성공하는지를 기계적 해석 가능성(mechanistic interpretability) 기법으로 설명하는 LOCA(Local Causal Attribution)를 제안한다. LOCA는 성공한 jailbreak 요청에 대해 모델 거부를 인과적으로 유발하는 최소한의 해석 가능한 중간 표현 변화 집합을 식별한다 — 평균 6개의 해석 가능한 변화만으로 거부를 유도하며, 기존 방법들이 20회 이상 변화를 시도해도 거부를 유도하지 못하는 것과 대조된다. 서로 다른 jailbreak 전략이 서로 다른 중간 개념을 강화하거나 억제하는 방식으로 작동하며, 해악 카테고리(폭력 vs. 사이버 공격 등)마다 동일 전략의 효과가 다른 이유를 설명해 안전 연구에 새로운 해석 가능성 창을 제공한다.

## 9. SL5 Standard for AI Security  🆕

- **저자**: Lisa Thiergart, Yoav Tzfati, Peter Wagstaff, Guy Caspi, Luis Cosio, Philip Reiner
- **키워드**: `AI security standard`, `Security Level 5`, `frontier AI`, `model weight protection`, `nation-state threat`
- **출처**: arxiv cs.CR
- **arxiv abstract**: [2605.08449](https://arxiv.org/abs/2605.08449) (v1, 2026-05-08)
- **PDF**: [arxiv.org/pdf/2605.08449](https://arxiv.org/pdf/2605.08449)

**핵심 요약** (3-5문장 한국어):
세계 최고 수준의 사이버 역량을 가진 국가 행위자(nation-state actor)의 최우선 작전도 저지할 수 있는 AI 시스템을 위한 보안 태세인 SL5(Security Level 5)를 정의한다. RAND Corporation의 "AI 모델 가중치 보안" 보고서에서 유래한 개념으로, AI 랩 의사결정자, 국가 안보 리더, 데이터센터 운영자, 칩 공급업체 등 50여 명의 참여자와 협력해 표준 초안을 개발했다. 1차 표준은 리드 타임이 긴 요건 — 시설 건설, 하드웨어 조달, 조직적 역량 개발 — 에 초점을 맞추며, 2028/2029년까지 SL5 달성 가능성을 보존하기 위해 즉각적 착수가 필요한 항목들을 제시한다.
