## 1. Logit-Contribution Scoring Identifies Non-Literal Retrieval Heads 🆕

- **저자**: Aryo Pradipta Gema, Beatrice Alex, Pasquale Minervini (University of Edinburgh)
- **키워드**: `mechanistic interpretability`, `attention heads`, `OV circuit`, `retrieval heads`, `feature attribution`
- **출처**: HF Daily (11 upvotes)
- **arxiv abstract**: [2607.01002](https://arxiv.org/abs/2607.01002) (v1)
- **PDF**: [arxiv.org/pdf/2607.01002](https://arxiv.org/pdf/2607.01002.pdf)

**핵심 요약** (3-5문장 한국어):
기존 attention head detector들은 생성 토큰과 정확히 일치하는 위치를 탐색하는 literal-copy 기준을 써서, 문맥의 의미를 합성해 답을 도출하는 non-literal retrieval head를 구조적으로 놓친다. 저자들은 OV-circuit 출력을 answer-token unembedding 방향으로 투영하는 쓰기 인식 점수(LOCOS)를 제안하고, needle·off-needle 위치를 단일 forward pass에서 대조해 head를 채점한다. Qwen3-8B에서 상위 50개 head만 ablate해도 ROUGE-L이 0.401→0.000으로 붕괴한 반면, 가장 강한 베이스라인은 0.292를 유지했다. 선택된 head는 retrieval에 특화되어 parametric recall·산술 추론에는 영향을 주지 않으며, MuSiQue(0.55→0.08)와 BABI-Long(0.62→0.20)에서도 동일한 ablation이 성능을 크게 떨어뜨렸다.

## 4. The Binary Tree Mechanism is Optimal for Approximate Differentially Private Continual Counting 🆕

- **저자**: Konstantina Bairaktari, Kasper Green Larsen (Aarhus University)
- **키워드**: `differential privacy`, `continual counting`, `binary tree mechanism`, `privacy lower bound`
- **출처**: arxiv recent (cs.DS/cs.CR) · ECML PKDD 2026
- **arxiv abstract**: [2607.00876](https://arxiv.org/abs/2607.00876) (v2)
- **PDF**: [arxiv.org/pdf/2607.00876](https://arxiv.org/pdf/2607.00876.pdf)

**핵심 요약** (3-5문장 한국어):
연속 스트림에서 running count를 개인 정보를 보호하며 배포하는 문제(private continual counting)에서, binary tree mechanism의 가우시안 노이즈 변형이 Θ(log^{3/2} n) 기대 오차를 달성하지만 이 의존성이 최적인지는 오랫동안 미해결 문제로 남아 있었다. 이 논문은 모든 DP mechanism이 기대 ℓ∞ 오차 Ω(log^{3/2} n)를 반드시 부담해야 함을 증명해, binary tree mechanism이 approximate-DP 설정에서 점근적으로 최적임을 완전히 확립했다. 부수적으로, hereditary discrepancy와 private ℓ∞ 오차 사이의 최대 분리를 도출해 linear query에 대한 기존 상한이 쿼리 수에 최적의 의존성을 가짐도 보인다.

## 6. WARP: Weight-Space Analysis for Recovering Training Data Portfolios 🆕

- **저자**: Tzu-Heng Huang, Aditya Goyal, John Cooper, Frederic Sala (University of Wisconsin-Madison)
- **키워드**: `training data leakage`, `data extraction`, `model merging`, `weight space`, `domain mixture`
- **출처**: HF Daily (2 upvotes) · ICML 2026 Workshop on Weight-Space Symmetries
- **arxiv abstract**: [2607.01686](https://arxiv.org/abs/2607.01686) (v1)
- **PDF**: [arxiv.org/pdf/2607.01686](https://arxiv.org/pdf/2607.01686.pdf)

**핵심 요약** (3-5문장 한국어):
공개된 foundation model의 학습 데이터 조합(domain mixture)은 거의 공개되지 않아, 연구자들이 모델은 연구할 수 있지만 그것을 만든 학습 분포는 볼 수 없는 접근 비대칭이 생긴다. WARP는 base 모델과 fine-tuned 모델 사이를 model merging으로 보간해 pseudo-checkpoint를 생성하고, 이로부터 weight space의 기하학적 발자국을 추출해 도메인 비율을 역추정한다. BERT에서 MAE 0.046, GPT-2에서 MAE 0.104를 달성해 기존 membership inference와 실제 학습 trajectory에 접근한 변형 모두를 능가한다.

## 9. Representation as a Bottleneck for Mechanistic Interpretability: The Manifestation Unit Protocol 🆕

- **저자**: Hussein Chouman, Wataru Sasaki, Tomokazu Matsui, Hirohiko Suwa, Keiichi Yasumoto (NAIST, Japan)
- **키워드**: `mechanistic interpretability`, `circuit analysis`, `representation`, `probing`, `attention heads`
- **출처**: arxiv recent (cs.LG)
- **arxiv abstract**: [2607.00089](https://arxiv.org/abs/2607.00089) (v1)
- **PDF**: [arxiv.org/pdf/2607.00089](https://arxiv.org/pdf/2607.00089.pdf)

**핵심 요약** (3-5문장 한국어):
기계적 해석가능성 연구들이 구성요소 수준 분석을 풍부하게 생산하지만, 결과물(선택성 표, 회로 다이어그램, 특성 목록)이 노트북에 갇혀 재사용·자연어 질의·감사에 활용하기 어렵다는 문제를 다룬다. 저자들은 Manifestation Unit이라는 타입화된 튜플 프로토콜 (E, S, R, D, G)을 제안하고, 트랜스포머 아키텍처용 attention-head 기본 요소(T)를 확장해 구성요소 통계를 자동으로 구조화·검색 가능하게 만든다. beta-VAE·CNN·GPT-2에서 검증한 결과, 타입화 구조가 비구조화 베이스라인 대비 검색 성능에서 크게 우월하고, IOI 회로 멤버 집합 복원도 성공했다.
