## 1. Skill Constellations: Tracing the Supply Chain of Agent Skills on GitHub  🆕
- **저자**: Fahd Seddik
- **키워드**: agent safety, software supply chain, provenance, security audit
- **출처**: HF Daily
- **arxiv abstract**: [2610.11169](https://arxiv.org/abs/2610.11169) (v1)
- **PDF**: [arxiv.org/pdf/2610.11169](https://arxiv.org/pdf/2610.11169.pdf)
- **핵심 요약**: 코딩 에이전트의 스킬 파일은 사용자 권한으로 실행되지만, 복사·배포 과정의 출처와 버전을 추적하기 어렵다. 연구진은 Git 이력에서 219만 건이 넘는 스킬 채택을 연결한 시계열 복사 네트워크를 구축했다. 이 네트워크로 감사 우선순위를 정하면 별점 기준보다 고위험 스킬 확산을 더 효과적으로 포착했다. 결과는 스킬을 복사본이 아니라 버전이 고정된 참조로 배포해야 한다는 보안 설계 근거를 제시한다.

## 2. What Did the Agent Actually Do? Evidence-Grounded Oversight for Long-Horizon Agents  🆕
- **저자**: Zhongxiang Sun, Jiahao Yan, Hongkang Zhao, Haojie Ding, Boheng Zhang et al.
- **키워드**: agent safety, human oversight, behavior monitoring, evidence grounding
- **출처**: HF Daily
- **arxiv abstract**: [2610.06406](https://arxiv.org/abs/2610.06406) (v1)
- **PDF**: [arxiv.org/pdf/2610.06406](https://arxiv.org/pdf/2610.06406.pdf)
- **핵심 요약**: 장기 실행 에이전트에서는 중요한 결정과 근거가 긴 궤적에 흩어져 사용자가 실제 행동을 검증하기 어렵다. 연구진은 요구사항 일치와 중대한 결정 인식을 평가하는 AgentMonBench를 제안한다. 또한 근거를 행동 단위로 묶고 관계를 그래프로 구성하는 학습 없는 EBG 방법을 설계했다. 여덟 모델 실험에서 EBG는 대부분의 설정에서 결정 식별과 근거 위치 찾기를 개선해, 인간 감독의 실용적 기반을 제공한다.

## 3. Learning to Steer, Steering to See: Unveiling the Geometry of RLVR in Large Language Models via Trainable Vectors  🆕
- **저자**: Yuchen Cai, Ding Cao, Qixiang Yin, Xin Xu, Kai Yang et al.
- **키워드**: representation engineering, activation steering, RLVR, causal intervention
- **출처**: HF Daily
- **arxiv abstract**: [2609.34344](https://arxiv.org/abs/2609.34344) (v1)
- **PDF**: [arxiv.org/pdf/2609.34344](https://arxiv.org/pdf/2609.34344.pdf)
- **핵심 요약**: RLVR이 만든 고차원 파라미터 변화가 어떤 내부 표현을 통해 능력 향상으로 이어지는지 분석하기 어렵다. 연구진은 학습 가능한 조향 벡터로 RL 효과를 재현하며 저차원 유효 다양체를 식별한다. 다섯 모델과 여섯 과제에서 효과적 제어 방향이 주성분 부분공간의 저분산 보완 공간에 주로 놓인다는 기하학적 결과를 보고한다. 이 관찰을 이용한 Alpha-Stabler는 붕괴 징후를 감시하고 활성화 기울기를 제어해 2,000단계 학습을 안정화했다.

## 4. RAISED: Self-Distillation for Robustness to Prompt Injection in LLM Agents  🆕
- **저자**: Mohamed Dhouib, Clement Elliker, Alexi Canesse, Maël Jenny, Lucas-Andrei Thil et al.
- **키워드**: prompt injection, agent safety, self-distillation, adversarial robustness
- **출처**: SNS
- **arxiv abstract**: [2610.06401](https://arxiv.org/abs/2610.06401) (v2)
- **PDF**: [arxiv.org/pdf/2610.06401](https://arxiv.org/pdf/2610.06401.pdf)
- **핵심 요약**: 간접 프롬프트 주입 방어를 학습하면 공격 성공률은 줄어도 정상 도구 사용 능력이 함께 저하될 수 있다. RAISED는 모델이 도구 사용 시나리오를 직접 만들고, 깨끗한 궤적과 주입된 궤적에서 같은 정상 행동을 따르도록 자기 증류한다. 특히 정상 도구 출력의 지시를 따라야 완료되는 과제를 학습 데이터에 강조한다. 초록의 실험 결과는 기존 학습 방어와 달리 에이전트 및 범용 벤치마크 효용을 유지하면서 주입 공격 성공률을 크게 낮췄다고 보고한다.

## 5. Poster: A Preliminary Study of LLM Distillation Inference  🆕
- **저자**: Edward Chen, Yuntao Du
- **키워드**: model stealing, unauthorized distillation, hypothesis testing, model audit
- **출처**: arxiv recent
- **arxiv abstract**: [2610.12137](https://arxiv.org/abs/2610.12137) (v1)
- **PDF**: [arxiv.org/pdf/2610.12137](https://arxiv.org/pdf/2610.12137.pdf)
- **핵심 요약**: 독점 LLM의 출력을 이용한 무단 증류는 모델 탈취 위험을 만들지만, 의심 모델의 학습 출처를 판별하기 어렵다. 연구진은 증류 모델과 독립 학습 모델의 행동을 그림자 모델로 추정하는 가설 검정 절차를 제안한다. 교사 모델의 추론 출력을 예측하는 정도를 측정하고 보정된 p값으로 감사를 수행한다. Qwen2.5-7B 교사와 Llama-3.2-3B 의심 모델의 예비 실험에서 유의수준 0.02일 때 진양성률 1.0을 보고했다.

## 6. Could LLM Watermark Detection be Public?  🆕
- **저자**: Georgios Milis, Tom Sander, Tomáš Souček, Heng Huang, Pierre Fernandez
- **키워드**: watermark security, adversarial attacks, public verification, forgery detection
- **출처**: arxiv recent
- **arxiv abstract**: [2610.12106](https://arxiv.org/abs/2610.12106) (v1)
- **PDF**: [arxiv.org/pdf/2610.12106](https://arxiv.org/pdf/2610.12106.pdf)
- **핵심 요약**: LLM 워터마크 탐지기를 공개하면 공격자가 점수 피드백으로 제거와 위조를 최적화할 수 있다는 우려가 있다. 연구진은 공개 키와 비공개 키를 나누고, 두 신호의 불균형을 통계적으로 검사하는 분할 키 워터마킹을 제안한다. 다양한 제거·위조 공격에서 공개 탐지는 작은 편집 예산에서만 제거를 돕지만 위조 가능성은 높였다. 비공개 검증 단계는 이 위조를 식별해, 투명성과 포렌식 안전성을 함께 확보할 수 있음을 보였다.
