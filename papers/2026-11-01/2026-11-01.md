## 1. Elucidating the Design Space of LM Data Attribution  🆕
- **저자**: Steven Yu, Sheng-Yu Wang, Kimia Hamidieh, Antonio Torralba, David Bau
- **키워드**: data attribution, feature attribution, causal tracing, interpretability evaluation
- **출처**: arxiv recent
- **arxiv abstract**: [2610.40655](https://arxiv.org/abs/2610.40655) (v1)
- **PDF**: [arxiv.org/pdf/2610.40655](https://arxiv.org/pdf/2610.40655.pdf)
- **핵심 요약**: 기존 LM 데이터 귀속 평가는 여러 데이터 속성을 동시에 바꿔 실패 원인을 분리하기 어렵다. CATT는 가상 지식으로 명확한 정답을 만들고 문서 중복과 어휘 방해 요소를 하나씩 조절한다. 분석 결과 인과적 증거는 일부 토큰에 집중되지만 문서 전체 평균이 이를 잡음에 묻는 것으로 나타났다. 음의 로그 오즈 그래디언트와 상위 토큰 집계를 결합해 정답 재현율을 35~72%p 높였고, FTRACE-TREX의 반사실적 재학습 성능도 최대 4.9배 개선했다.

## 2. CARI: Cross-Boundary Adversarial Runtime Injection in Coding-Agent Workflows  🆕
- **저자**: Jie Fu, Shuang Wu, Ashish Kundu, Wendy Hui Wang, Yuan Hong
- **키워드**: coding-agent security, runtime injection, prompt injection, tool authority
- **출처**: arxiv recent
- **arxiv abstract**: [2610.38799](https://arxiv.org/abs/2610.38799) (v1)
- **PDF**: [arxiv.org/pdf/2610.38799](https://arxiv.org/pdf/2610.38799.pdf)
- **핵심 요약**: 코딩 에이전트는 백엔드, 테스트, CI가 제공하는 런타임 피드백을 신뢰하지만 해당 구성요소에는 로컬 작업 권한이 없다. CARI는 이 진단 권한과 실행 권한의 불일치를 이용해 정상 오류 메시지 안에 악성 지시를 삽입한다. 네 언어와 다섯 모델의 3,000회 시험에서 2,845회, 즉 94.8%의 공격 성공률을 기록했다. 제품 수준에서는 Codex 61.3%, Claude Code 58.7%였으며, 명시적 방어 정책은 공격을 줄이는 대신 정상 작업을 과도하게 거부했다.

## 3. PrivCode: When Code Generation Meets Differential Privacy  🆕
- **저자**: Zheng Liu, Chen Gong, Terry Yue Zhuo, Kecen Li, Weichen Yu et al.
- **키워드**: differential privacy, code generation, DP-SGD, synthetic data
- **출처**: arxiv recent
- **arxiv abstract**: [2512.05459](https://arxiv.org/abs/2512.05459) (v4)
- **PDF**: [arxiv.org/pdf/2512.05459](https://arxiv.org/pdf/2512.05459.pdf)
- **핵심 요약**: 비공개 코드로 LLM을 미세조정하면 개인 정보와 독점 구현이 노출될 수 있지만, 일반 DP 생성은 코드 문법을 쉽게 훼손한다. PrivCode는 DP-SGD와 구문 정보를 결합해 먼저 차등 프라이버시 합성 코드를 만든다. 이어 더 큰 사전학습 모델을 합성 코드로 조정해 프라이버시 노이즈로 잃은 효용을 회복한다. 네 LLM과 네 벤치마크에서 여러 프라이버시 예산에 걸쳐 민감 정보 보호와 코드 효용을 평가했으며, NDSS 2026에 채택됐다.

## 4. Pre-Crime for Agents, at the Last Second: Probing When a Recruited Agent Gives In  🆕
- **저자**: Leonidas Raghav
- **키워드**: agent safety, linear probing, secret leakage, multi-agent collusion
- **출처**: arxiv recent
- **arxiv abstract**: [2610.40588](https://arxiv.org/abs/2610.40588) (v1)
- **PDF**: [arxiv.org/pdf/2610.40588](https://arxiv.org/pdf/2610.40588.pdf)
- **핵심 요약**: 공유 채널의 에이전트가 반복 압박 끝에 비밀을 누설하기 직전인지 출력 전에 탐지하는 문제를 다룬다. 여섯 시나리오에서 활성값 선형 프로브는 정상 호출의 5%를 경보하도록 맞춘 조건에서 Qwen3-32B 누설 호출의 82%를 잡았다. 비슷한 경보율의 제로샷 결정 모니터는 26%였고, gpt-oss-20b 추론 프로브는 AUROC 0.91을 기록했다. 다만 bag-of-words 분류기도 근접했고 허용된 공개까지 경보해, 프로브가 규칙 위반보다 공개 행동 자체를 읽는다는 한계를 보였다.

## 5. Understanding and Enhancing Backdoor Persistency in LLM Agent Post-Training  🆕
- **저자**: Qiusi Zhan, Nian Lyu, Stephanie Ding, Arnav Mehta, Chris Canal et al.
- **키워드**: agent backdoor, post-training, supply-chain attack, reinforcement learning
- **출처**: arxiv recent
- **arxiv abstract**: [2610.07510](https://arxiv.org/abs/2610.07510) (v3)
- **PDF**: [arxiv.org/pdf/2610.07510](https://arxiv.org/pdf/2610.07510.pdf)
- **핵심 요약**: 제3자 모델에 심은 백도어가 개발자의 정상 SFT와 작업 수준 RL을 통과하는 공급망 위협을 분석한다. 정상 SFT는 공격 성공률을 낮추지만, 후속 RL은 남은 백도어를 유지하거나 다시 강화할 수 있었다. PersistBD는 초기 백도어 강도와 정상 학습 그래디언트의 호환성을 이용해 후속 학습 뒤의 지속성을 높인다. Qwen2.5-Coder-7B에서 공격 성공률은 SFT 뒤 20%에서 74%, SFT-RL 뒤 20%에서 76%로 상승했으며, 논문은 EMNLP 2026 Findings에 채택됐다.

## 6. Judging Before Propagation: Task-Graph Contextual Integrity for Multi-Agent Privacy  🆕

- **키워드**: multi-agent privacy, contextual integrity, information flow, compromised agents
- **출처**: arxiv recent
- **arxiv abstract**: [2610.39532](https://arxiv.org/abs/2610.39532) (v1)
- **PDF**: [arxiv.org/pdf/2610.39532](https://arxiv.org/pdf/2610.39532.pdf)
- **핵심 요약**: 다중 에이전트 시스템에서는 현재 공개가 적절해도 후속 에이전트와 기존 공개 이력이 결합되면 프라이버시 위반이 생길 수 있다. TG-CI는 워크플로를 작업 그래프로 모델링하고 정보의 허용 전파 범위와 수신자의 누적 상태를 함께 판단한다. MAPLE-Bench는 그래프 구조, 공개 이력, 손상 에이전트 위치, 정책을 바꾼 144개 사례로 구성된다. 주 실험에서 로컬 이력 기준선보다 무단 공개를 85.8~94.1% 줄이면서 기준선 작업 정확도의 93.6~96.1%를 유지했다.

- **저자**: Haoran Bu, Yiting Shen, Litian Zhang, Ruihan Hu, Xi Zhang
- **키워드**: agent memory, role grounding, preference poisoning, privacy leakage
- **출처**: arxiv recent
- **arxiv abstract**: [2610.38209](https://arxiv.org/abs/2610.38209) (v1)
- **PDF**: [arxiv.org/pdf/2610.38209](https://arxiv.org/pdf/2610.38209.pdf)
- **핵심 요약**: 소셜 상호작용을 기억하는 에이전트는 대화 속 선호가 누구의 것인지 잘못 연결할 수 있다. Role Grounding Attack은 중첩 대화를 이용해 공격자 사용자의 선호를 피해자 사용자의 선호로 저장하게 만든다. 잘못 저장된 선호는 이후 검색 단계에서 공격자 도구 선택과 민감 정보가 포함된 인자 전송을 유도한다. 다섯 메모리 시스템과 여섯 언어 모델에서 도구 조작과 프라이버시 유출 모두 높은 공격 성공률을 보였지만, 초록에는 구체적 수치가 제시되지 않았다.

## 9. Propose-Filter-Release: Scaling Noise to Typical Sensitivity via Private Filtering  🆕
- **저자**: Moshe Shenfeld, Eliad Tsfadia, Katrina Ligett
- **키워드**: differential privacy, private filtering, sensitivity, privacy mechanism
- **출처**: arxiv recent
- **arxiv abstract**: [2610.40654](https://arxiv.org/abs/2610.40654) (v1)
- **PDF**: [arxiv.org/pdf/2610.40654](https://arxiv.org/pdf/2610.40654.pdf)
- **핵심 요약**: 일반 차등 프라이버시 메커니즘은 드문 최악 사례의 민감도에 노이즈를 맞춰 전형적 데이터의 정확도까지 낮춘다. Propose-Filter-Release는 데이터 적합도를 나타내는 오목한 friendliness 점수로 입력을 비공개 필터링한다. 전형적 레코드에 대해 보호되는 friendly-DP 메커니즘을 모든 입력에 대한 표준 차등 프라이버시로 변환한다. 스칼라 통계, 주성분 부분공간, 사용자 히스토그램 KL 발산, 그래프 유효 저항, 치료 규칙 선택에 적용 가능성을 보였다.

## 10. Preserving Utility in Continual LLM Unlearning via Orthogonal Projections  🆕
- **저자**: Juan Belieni, Ana Carolina Erthal, Eliezer de Souza da Silva, Diego Mesquita
- **키워드**: machine unlearning, continual unlearning, orthogonal projection, utility preservation
- **출처**: arxiv recent
- **arxiv abstract**: [2610.40483](https://arxiv.org/abs/2610.40483) (v1)
- **PDF**: [arxiv.org/pdf/2610.40483](https://arxiv.org/pdf/2610.40483.pdf)
- **핵심 요약**: 순차적 삭제 요청은 새 업데이트가 이전 망각을 되돌리거나 이미 손상된 방향을 더 훼손해 효용을 급격히 낮춘다. COP는 각 망각 세트의 활성 부분공간을 저랭크 기저로 저장하고, 다음 그래디언트를 그 직교 여공간에 투영한다. 이 구성은 이전 삭제에 대한 일차 비간섭을 보장하며 과거 데이터나 그래디언트를 보관하지 않는다. TOFU와 RWKU에서 기존 망각 강도를 약화하지 않으면서 연속 요청의 효용 붕괴를 막았다고 보고했다.
