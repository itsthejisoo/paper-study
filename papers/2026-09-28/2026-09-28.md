- **출처**: arxiv recent

- **핵심 요약**: 사용자가 대화 중 공개한 비밀이 주제가 바뀐 뒤에도 후속 프롬프트로 추출될 수 있는지를 평가한다. PrivDrift는 비밀을 심은 1,000개 다중 턴 대화와 내용이 풍부한 주제 전환, 표준화된 추출 프로브를 제공한다. 세 장문맥 LLM에서 대화 단위 혼합 누출률은 38.7~54.6%였고, 테스트한 범위에서는 주제 전환이 늘어도 누출이 일관되게 줄지 않았다. 활성 대화의 개인정보 위험을 즉시 탈옥이나 학습 데이터 암기와 별개인 지속적 실패로 다뤄야 함을 제안한다.

- **키워드**: model misappropriation, model identity, challenge-response, black-box verification
- **출처**: arxiv recent
- **arxiv abstract**: [2609.29264](https://arxiv.org/abs/2609.29264) (v1)
- **PDF**: [arxiv.org/pdf/2609.29264](https://arxiv.org/pdf/2609.29264.pdf)
- **핵심 요약**: 원격 서비스의 모델 도용 분쟁에서 제3자가 주장자의 모델이나 내부 파라미터에 접근하지 못하는 상황을 다룬다. - **출처**: arxiv recent
- **arxiv abstract**: [2609.28613](https://arxiv.org/abs/2609.28613) (v1)
- **PDF**: [arxiv.org/pdf/2609.28613](https://arxiv.org/pdf/2609.28613.pdf)
- **핵심 요약**: 생성형 에이전트가 아닌 스키마 기반 확률 결정 모델도 프롬프트 인젝션에 취약한지 분석한다. 연구는 InjecAgent 사례 510개를 Jev용으로 재구성해 악성 문맥이 허용된 행동의 확률을 어떻게 바꾸는지 측정한다. 단순 공격은 표적 행동 선택을 거의 만들지 못했지만, 점수 피드백을 쓰는 적응형 공격은 최고 표적 확률을 두 배로 높였고 검증 호출 성공률을 1.8%에서 3.5%로 올렸다. 구조화 출력은 위험을 줄여도 제거하지 않으므로 비신뢰 문맥의 선택 확률 영향까지 검사해야 한다.

- **키워드**: agent safety, approval laundering, transitive effects, permission boundary
- **출처**: arxiv recent
- **arxiv abstract**: [2609.28586](https://arxiv.org/abs/2609.28586) (v1)
- **PDF**: [arxiv.org/pdf/2609.28586](https://arxiv.org/pdf/2609.28586.pdf)
- **핵심 요약**: 코딩 에이전트의 승인 기록이 사용자가 허용한 명령만 남기고, 패키지 훅이나 MCP 호출이 일으킨 연쇄 효과를 누락하는 문제를 approval laundering으로 정의한다. 저자들은 여섯 효과 유형의 폐쇄 경계를 형식화하고 승인 객체, 결정 시점 메타데이터, 실행 후 증거를 연결한 벤치마크를 구축한다. 보류 워크플로에서 효과 예측은 macro recall 0.926과 precision 0.941을 기록했고, 이를 승인 기록에 결속하면 잔여 미기록 효과가 10개에서 3개로 줄었다. 명령 이름이 아니라 예상되는 전체 연쇄 효과를 승인 전에 고정해야 함을 보인다.

## 10. Persistent Billable State: Denial-of-Wallet Attacks and Defenses in Tool-Calling LLM Agents  🆕

- **저자**: Jinqian Zhang, Haojun Xia, Shujiang Wu, Jingkun Yue, Xia Zhang, et al.
- **키워드**: agent security, denial-of-wallet, tool calling, context growth
- **출처**: arxiv recent
- **arxiv abstract**: [2609.28585](https://arxiv.org/abs/2609.28585) (v1)
- **PDF**: [arxiv.org/pdf/2609.28585](https://arxiv.org/pdf/2609.28585.pdf)
- **핵심 요약**: 악성 도구 반환값이 이후 모델 입력에 계속 포함되어 피해자 비용으로 반복 처리되는 persistent billable state를 정의한다. DOW-BENCH의 243회 실행에서 최대 누적 입력은 첫 호출 입력의 14,293배였고, 원시 기록 유지가 평균 실효 세션 비용을 21.2~35.9% 높였다. 저자들은 입력 질량, 문맥 성장, 재귀 기회, 누적 지출을 재주입 전에 제한하는 네 호스트 불변조건을 제안한다. 재생 평가에서는 모든 반복 공격을 차단했고, 진행도 기반 정책은 24개 작업 중 22개를 불필요한 조기 중단 없이 완료했다.
